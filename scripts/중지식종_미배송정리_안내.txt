중지 시작일로 식종을 미배송 정리하기

1. 급식 배송 운영 프로그램을 종료합니다.
2. meal_stop_cleanup.exe를 실행합니다. Python 설치는 필요하지 않습니다.
   기존 앱의 공통 백업 설정을 찾도록 meal_delivery.exe와 같은 폴더에 두세요.
   중지식종_미배송정리.cmd로 실행해도 됩니다.
3. 중지 시작일을 입력합니다.
   2026-09-30: 2026년 9월 30일에 시작한 중지 기록만 찾습니다.
   9/30: 모든 연도의 9월 30일 시작 중지 기록을 찾습니다(기존 방식).
   다른 날짜도 같은 형식으로 입력할 수 있습니다. 빈칸이면 취소합니다.
4. 운영 파일 경로와 비밀번호를 입력합니다. 경로는 파일을 창에 끌어 놓아도 됩니다.
   비밀번호는 화면에 표시되지 않습니다.
5. 날짜 범위·이름·식종과 되돌릴 변경번호를 확인합니다.
   '정리'를 입력해야 저장합니다. 다른 입력은 취소합니다.

현재 작업본의 과거 기록에서 입력한 시작일의 중지를 찾습니다.
현재 중지 상태가 아니거나 이후 배송을 재개한 사람도 대상에 포함됩니다.
해당 사람·식종의 가입 기간과 상태 기록을 현재 자료에서 제거하고,
중식이면 개인 중식 기간도 비워 처음부터 미가입(미배송)으로 처리합니다.
따라서 현재 자료로 과거 문서를 다시 계산하는 결과도 달라집니다.
다른 식종·다른 사람·별도 작업본과 이전 변경번호의 원본은 유지합니다.

기존 운영 파일에 변경 기록 하나를 추가합니다. 파일을 새로 만들거나 교체하지 않습니다.
파일 경로·비밀번호·백업 연결을 유지하며, 같은 운영 파일의 공통 설정을 찾으면 자동 백업합니다.
백업 경로가 없거나 백업이 실패하면 정리 저장 결과와 구분해 안내합니다.
복구하려면 앱의 '이전 자료로 되돌리기'에서 정리 직전 변경번호를 선택하세요.
이미 생성한 Excel 파일은 바뀌지 않으므로 필요한 문서는 다시 만드세요.
완료·취소·오류 뒤에는 Enter를 눌러 창을 닫습니다.

개발 폴더에서는 python scripts/cleanup_september30_stops.py로도 실행할 수 있습니다.
예전 9월30일_중지정리.cmd도 새 날짜 입력 도구를 엽니다.
