이 파일 하나에 HTML 설명서의 모든 사용 절차와 상황별 찾아보기를 담았습니다.
실행 파일·코드·다른 설명서·스크린샷을 함께 첨부하지 않아도 본문을 읽을 수 있습니다.

[사용자가 챗봇에 처음 보낼 말]
첨부한 설명서 기준으로 급식 배송 운영 프로그램 사용법을 알려줘.
내가 하고 싶은 일을 말하면 필요한 메뉴 위치, 누르는 순서, 입력할 값,
저장 후 확인할 내용과 주의점을 쉬운 한국어로 설명해줘.
예: “다음 주 월요일부터 목요일까지 한 사람의 석식만 쉬게 하고 싶어.”

[이 파일을 읽는 챗봇의 답변 지침]
1. 이 문서는 프로그램 사용자 안내 자료다. 코드 수정·개발·빌드 안내로 답하지 않는다.
2. 사용자의 표현을 아래 ‘하고 싶은 일로 찾기’와 본문에서 찾는다. 똑같은 질문이 없더라도 관련 절차를 조합한다.
3. 조작 질문에는 ‘여는 위치 → 번호를 붙인 조작 순서 → 저장 후 확인’ 순으로 답한다. 처음 답변은 보통 3~5단계로 짧게 쓰되 필수 단계는 빼지 않는다. 필요한 주의점만 1~2개 덧붙이고 메뉴·버튼은 본문 이름을 그대로 쓴다. 뜻이나 차이를 묻는 질문은 결론과 짧은 예시부터 답한다.
4. 이미 알려준 정보는 다시 묻지 않는다. 대상자·가구·전체 중 범위, 식종·날짜 또는 급식·행복도시락 양식에 따라 답이 달라지고 아직 알 수 없을 때만 필요한 질문 1~2개를 먼저 한다. 양식 확인 위치는 ‘설정 → 문서 → 문서 양식’이다. 답을 기다리는 동안 공통으로 할 수 있는 단계만 안내한다.
5. 시작일·종료일·조회일·실제 배송일·식사일을 구분한다. 미래 변경을 저장하고 과거 날짜에서 확인하는 실수를 안내한다. 날짜를 임의로 정하지 않는다.
6. 화면만 바꾸는 동작과 실제 명단·일정·출력물을 바꾸는 동작을 구분한다. 삭제·중식 대상자 교체·복구·자동 파일 삭제에서는 관련 영향 범위를 설명한다.
7. 같은 결과에 가까운 기능이라도 서로 대체하지 않는다. 중지는 행 삭제가 아니며, 시트 삭제는 명단 삭제가 아니고, 화면 정렬은 배송순서 변경이 아니다.
8. 사용자 화면이나 실제 저장 자료를 보고 있는 것처럼 말하지 않는다. 사용자가 직접 눌러야 할 절차를 안내하고 저장·생성을 대신 수행했다고 말하지 않는다.
9. 본문에 없는 버튼·기능·자동 처리·복구 방법은 만들지 않는다. 문서로 판단할 수 없으면 확인할 수 없다고 말하고 화면 이름·안내 문구 또는 개인정보를 가린 화면을 요청한다. 코드 제공을 요구하지 않는다.
10. 다른 버전의 화면이면 차이를 알리고 현재 보이는 메뉴를 확인한다. 인터넷의 다른 프로그램 설명보다 이 버전의 본문을 우선한다.
11. 본문의 예시는 실제 대상자가 아니다. 사용법 설명에 전체 명단이나 비밀번호를 첨부하게 하지 않는다.
12. 본문의 ‘[참고: S번호 · 제목]’은 이 파일 안의 관련 절이다. 필요한 절까지 읽어 조건을 확인하고 답변 끝에는 사용한 본문 번호와 제목을 짧게 적는다. 예: ‘근거: S005 · 정해진 기간 일시중지’. 실제 번호는 아래 목차를 따른다.

[기본 용어와 혼동하기 쉬운 구분]
- 식종: 석식·조식·중식. 한 사람이 여러 식종을 받을 수 있고 상태·담당·순서는 식종별일 수 있다.
- 조회일: 명단 화면 왼쪽에서 보고 있는 날짜. 적용일은 변경이 실제로 시작되는 날짜다.
- 식사일: 제공하는 식사의 원래 날짜. 실제 배송일: 묶음배송을 포함해 물건이 나가는 날.
- 가구: 같이 묶어 관리하는 사람들. 공용 칼럼은 해당 가구원이 값을 함께 쓰는 항목이고 공용 예외는 개인별 값을 허용한다.
- 일일식수: 날짜별 집계표. 급식은 실제 배송 식수·가구 수, 행복도시락은 선택일의 가입·상태 기준 인원이다. 행복도시락은 일시중지도 포함하고 3일분 조식도 1명으로 센다. 청구서·확인서의 식사 수와 혼동하지 않는다.
- 배송목록: 기사별 대상 목록. 급식은 실제 배송 대상, 행복도시락은 가입·상태 기준의 1/빈칸 표시다. 일부 화면·양식에서는 배송대타라고 표시한다.
- 변경번호: 저장한 변경 기록의 번호. 과거 원본으로 문서를 만들거나 이전 상태를 조회할 때 사용한다.
- 작업본: 같은 운영 파일 안에서 별도로 이어가는 명단·상태·설정. 전체 변경 이력에서 만들거나 전환하며, 시트는 같은 명단의 화면 배치이므로 작업본과 다르다. 기존 화면 예시에서는 분기라고 표시될 수 있다.
- 불러오기: Excel 등 입력 파일의 내용을 반영. 내보내기: 현재 자료를 Excel로 출력. 기존 화면 예시에는 불러오기가 가져오기로 표시될 수 있다.
- 운영 파일 비밀번호: 앱의 명단 파일을 여는 비밀번호. 생성 Excel 비밀번호: 새로 만드는 보호 Excel의 공통 비밀번호. 원본 Excel의 열기 비밀번호: 받은 파일을 읽을 때 필요하다.
- 생성 후 명단·설정을 수정해도 이미 만든 Excel 파일은 자동으로 바뀌지 않는다. 변경 내용으로 새 파일을 만든다.

S001 · 처음 실행·다시 열기·업데이트
============================================================
비밀번호 확인 실패가 나오면 선택한 운영 파일의 비밀번호와 한/영·Caps Lock을 확인해 다시 입력하세요. 이 안내는 원본 손상을 뜻하지 않습니다. 운영 파일을 읽지 못했습니다 또는 비밀번호 정보 파일의 형식 안내가 나오면 함께 받은 운영 파일과 비밀번호 정보 파일을 확인하거나 정상 백업으로 복원하세요.

처음 실행·다시 열기·업데이트

처음 실행할 때

1. meal_delivery.exe를 실행합니다.
2. 처음 설정에서 새 운영 파일 만들기 또는 기존 운영 파일 열기를 선택합니다.
3. 새로 시작하려면 위치 선택에서 새 파일의 저장 위치를 정하고 새 비밀번호를 입력합니다. 자동 백업 폴더를 고른 뒤 설정 완료하고 명단 옮기기를 누릅니다. 이어서 명단 불러오기 [참고: S041 · 명단 불러오기]의 열 연결·적용일 안내를 따라 Excel 명단을 불러옵니다.
4. 기존 자료를 쓰려면 파일 선택에서 사용하던 운영 파일을 고르고 그 파일의 기존 비밀번호를 입력합니다. 자동 백업 폴더를 지정하고 기존 운영 파일 열기를 누릅니다. 명단이 있으면 바로 운영 화면을 열며, 명단이 없는 파일은 Excel 명단 불러오기로 이어집니다.

기존 운영 파일은 선택한 위치에서 그대로 사용합니다. 예를 들어 운영.sqlite3와 함께 받은 운영.sqlite3.credentials.json을 같은 폴더에 두고 파일 이름을 유지하세요. 파일을 열지 못하거나 취소하면 사용할 경로 설정은 바뀌지 않습니다. 정상적으로 열면 다음 실행부터 이 파일의 로그인 화면이 나옵니다.

다음에 실행할 때

운영 파일 열기 화면의 파일 이름을 확인하고 비밀번호를 입력한 뒤 운영 파일 열기를 누릅니다. 같은 운영 파일을 다른 프로그램에서 사용 중이면 먼저 그 프로그램을 정상 종료해야 합니다.

운영 파일 비밀번호, 생성 Excel 비밀번호, 불러올 Excel의 열기 비밀번호는 용도가 다릅니다. 앱에는 비밀번호를 잊었어요 기능이나 별도 기관 복구 비밀번호 입력 기능이 없습니다. 기존 자료를 이어 쓰려는데 처음 설정 화면이 나오면 기존 운영 파일 열기에서 사용하던 파일을 선택하세요. 위치를 모르면 담당자에게 확인하세요.

업데이트와 자료 보관

실행 파일과 명단이 저장된 운영 데이터 파일은 별개입니다. 프로그램을 종료한 상태에서 새 실행 파일로 교체하고, 기존 운영 데이터·비밀번호 정보 파일·설정·백업을 보존합니다. 다시 열었을 때 파일 이름과 명단을 확인하세요.

백업 파일을 옮길 때는 같은 폴더에 있는 비밀번호 정보 파일도 함께 복사합니다. 일반 메뉴의 이전 자료로 되돌리기는 현재 운영 파일 안의 저장 시점을 되돌리는 기능입니다. 파일 손상·분실로 백업 파일 자체를 복원해야 한다면 담당자에게 요청하세요. 현재 일반 시작 화면에는 백업 파일을 고르는 복원 버튼이 없습니다.

S002 · 명단 화면에서 찾을 위치
============================================================
명단 화면에서 찾을 위치

설정·조회·편집·문서 준비 등 작업창은 Windows 작업 표시줄의 창 목록이나 Alt+Tab으로 각각 선택할 수 있습니다. 작업 표시줄 아이콘이 하나로 묶여 있으면 아이콘에 마우스를 올려 원하는 창을 고르세요. 작업창을 열어 둔 채 메인 명단으로 돌아갈 수 있으며, 메인 창을 닫으면 함께 열린 작업창도 닫힙니다.

화면 위치 | 쓰는 방법
왼쪽 날짜 | 이 날짜를 기준으로 배송 상태와 주소를 보여줍니다. 오늘 명단을 보려면 오늘로 이동을 누릅니다.
위쪽 검색칸 | 이름·학교·전화번호·주소를 입력해 사람을 찾습니다.
석식·조식·중식 칸 | 상태를 바꿀 사람의 식종 칸에서 마우스 오른쪽 버튼을 누릅니다.
오른쪽 위 문서 만들기 | 청구서·확인서·일일식수·배송목록을 만듭니다.
오른쪽 위 더보기 | 명단 불러오기, 기사 관리, 월별 조회, 칼럼 관리, 설정을 엽니다.
명단 아래 시트 이름과 + | 표시할 칼럼이 다른 시트를 만들거나 선택합니다.

이 설명서의 스크린샷은 누르면 크게 볼 수 있습니다. 큰 화면을 닫으려면 닫기 또는 키보드의 Esc를 누르세요.

S003 · 상태를 바꿀 사람과 식종 찾기
============================================================
상태를 바꿀 사람과 식종 찾기

1. 명단 위 검색칸에 이름을 입력합니다. 같은 이름이 있으면 학교·연락처를 함께 확인합니다.
2. 왼쪽 조회 날짜를 확인합니다. 미래 날짜의 변경을 저장해도, 과거 날짜를 보고 있으면 이전 상태가 보입니다.
3. 해당 사람의 석식·조식·중식 중 바꿀 칸에서 우클릭합니다. 이름 칸이 아니라 식종 칸을 누릅니다.
4. 메뉴에서 배송·일시중지·중지 중 필요한 항목을 선택합니다.

할 일 | 선택할 상태
처음 배송을 시작하거나 중지 후 다시 받기 | 배송
시작일과 끝나는 날이 정해진 중단 | 일시중지
장기 중단 또는 다시 받을 날짜가 정해지지 않음 | 중지

이미 배송 중이면 우클릭 메뉴에 배송이 나오지 않고, 중지 중이면 배송이 나옵니다. 이미 같은 상태인 날짜에 같은 상태를 다시 저장할 수 없습니다.

S004 · 배송 시작·재개
============================================================
배송 시작·재개

미가입 중식을 중간에 추가할 때도 이 방법을 사용합니다. 입력한 시작일을 중식 시작일에 저장하고, 종료일을 지정하지 않으면 학교 일정에서 중식 종료일을 채웁니다. 이미 가입된 기간 안에서 배송을 재개할 때는 기존 중식 날짜를 유지합니다. 저장 후 중식 날짜 칼럼 [참고: S017 · 대상자별 중식 시작일·종료일]에서 수정할 수 있습니다.

배송으로 저장하면 해당 식종·기사의 배송순서 맨 아래에 배치됩니다. 같은 배송 행으로 묶인 가구원은 함께 이동하고 같은 번호를 사용합니다. 순서는 날짜 제한 없는 공통 값이므로 미래 배송을 예약해도 저장 즉시 갱신됩니다.

1. 식종 칸을 우클릭해 배송을 선택합니다.
2. 창 위의 이름과 체크된 식종을 확인합니다. 처음 이용하는 식종도 배송으로 시작할 수 있습니다.
3. 시작일에 실제로 다시 받을 날짜를 입력합니다. 계속 받을 예정이면 종료일 없음을 체크한 상태로 둡니다.
4. 필요하면 접수 경로와 비고를 입력합니다. 선택하지 않은 접수 경로는 -로 남습니다.
5. 아래 변경 결과에서 이름·식종·기간을 확인하고 N개 변경 저장을 누릅니다.
6. 명단의 조회 날짜를 시작일로 맞춰 배송 상태를 확인합니다.

날짜 옆의 실제 배송 요일에 맞춰 입력하세요. 예를 들어 조식이 금요일 묶음배송이면 시작일도 금요일을 선택합니다.

S005 · 정해진 기간 일시중지
============================================================
정해진 기간 일시중지

1. 식종 칸을 우클릭해 일시중지를 선택합니다.
2. 중단할 식종을 체크합니다. 한 식종만 바꾸려면 다른 식종은 체크하지 않습니다.
3. 시작일에는 처음 받지 않는 날, 종료일에는 마지막으로 받지 않는 날을 입력합니다.
4. 전화·메일 등 접수 경로와 필요한 비고를 입력합니다.
5. 변경 결과의 기간과 대상자를 확인하고 N개 변경 저장을 누릅니다.

입력한 시작일과 종료일을 모두 포함해 중단합니다. 예를 들어 10월 26일~29일로 입력하면 29일까지 중단합니다. 이후에는 기존 가입·상태와 배송 일정에 따라 다시 계산합니다. 종료일 다음 날이 배송일이 아니면 그날 바로 배송되는 것은 아닙니다.

여러 식종을 선택했으면 각 식종의 날짜를 따로 확인하세요. 석식과 조식의 배송요일이 다를 수 있습니다. 일시중지는 종료일을 비워 둘 수 없습니다.

S006 · 종료일 없이 중지
============================================================
종료일 없이 중지

중지로 저장하면 해당 사람·식종의 배송순서를 비우고, 남은 가구 순서를 1번부터 다시 매깁니다. 같은 가구에 배송 중인 사람이 남으면 그 가구는 목록에 유지됩니다. 다른 기사·식종의 순서는 유지하며, 일시중지는 순서를 바꾸지 않습니다.

1. 식종 칸을 우클릭해 중지를 선택합니다.
2. 중지할 식종과 시작일을 정합니다.
3. 다시 받을 날짜가 정해지지 않았다면 종료일 없음을 그대로 둡니다.
4. 접수 경로·비고를 입력하고, 변경 결과를 확인한 뒤 저장합니다.

다시 받기로 하면 같은 식종에서 배송을 선택해 재개일을 입력합니다. 중지 처리 때문에 명단의 사람 자체를 삭제할 필요는 없습니다.

명단의 중지 식종은 상태 줄이 -로 보일 수 있습니다. 실제 중지 기간은 오른쪽 식종 변경 이력이나 이력보기에서 확인하세요. 사람을 찾을 수 없으면 검색칸 옆 숨긴 행 포함을 체크합니다.

기본 설정에서는 같은 달 안에 종료일 없는 중지와 배송 재개가 이어지면, 그 사이를 일시중지로 계산합니다. 다음 달에 재개하면 중지로 유지합니다. 이 동작은 더보기 → 운영·설정 → 설정 → 일시중지 자동변환에서 바꿀 수 있습니다.

S007 · 여러 사람·식종을 함께 변경
============================================================
여러 사람·식종을 함께 변경

떨어진 칸 선택: 첫 식종 칸을 클릭한 뒤, 키보드의 Ctrl을 누른 채 추가할 칸을 클릭합니다. 선택을 마치면 Ctrl에서 손을 뗍니다.

이어진 범위 선택: 시작할 칸을 클릭한 뒤, Shift를 누른 채 마지막 칸을 클릭합니다. 두 칸 사이의 직사각형 범위가 모두 선택됩니다.

1. 같이 바꿀 식종 칸을 선택합니다. 떨어진 칸은 Ctrl을 누른 채 클릭하고, 이어진 범위는 첫 칸을 누른 뒤 Shift를 누른 채 마지막 칸을 누릅니다.
2. 선택한 칸 안에서 우클릭하고 선택한 식종 N개 · 일시중지 등 필요한 메뉴를 누릅니다.
3. 변경할 상태와 식종별 기간을 입력합니다.
4. 변경 결과에 나온 이름·식종·건수를 확인한 뒤 저장합니다.

한 사람의 여러 식종은 상태 변경창에서 식종을 더 체크해도 됩니다. 같은 가구에도 적용할 때는 창 위의 같은 가구에도 일괄 적용을 체크하고 추가된 대상을 확인하세요.

여러 칸을 선택하면 모두에게 가능한 상태만 메뉴에 나옵니다. 원하는 메뉴가 없으면 서로 다른 현재 상태가 섞였는지 확인하세요.

============================================================
S008 · 저장한 내용 확인·잘못 입력한 기록 취소
============================================================
저장한 내용 확인·잘못 입력한 기록 취소

접수 경로나 비고만 고치려면 개인 이력의 해당 셀을 더블클릭하거나, 오른쪽 식종 변경 이력에서 한 건을 우클릭해 접수 경로·비고 수정을 누릅니다. 현재 값을 수정해 저장하세요. 접수 경로는 미선택·전화·메일·기타 중 고르며 비고는 비워 지울 수 있습니다. 배송 상태와 적용 기간은 그대로 유지되고 수정 전 내용은 전체 변경 이력에 보존됩니다. 다른 창에서 저장한 뒤 충돌 안내가 나오면 입력을 복사하고 창을 다시 열어 최신 내용으로 수정하세요.

여는 위치 · 대상자 칸 우클릭 → 이력보기 / 오른쪽 식종 변경 이력 → 전체 보기

1. 대상자의 이력보기를 열고 식종 변경 탭을 선택합니다.
2. 잘못 등록한 기록을 선택합니다. 여러 건이면 Ctrl·Shift로 함께 선택합니다.
3. 선택한 기록 위에서 우클릭해 선택한 변경 N건 취소를 누릅니다.
4. 확인창의 이름·식종·기간을 다시 확인한 뒤 취소를 진행합니다. 필요한 상태를 올바른 기간으로 다시 입력합니다.

오른쪽 식종 변경 이력에서도 기록을 선택해 우클릭으로 취소할 수 있습니다. 취소된 기록과 취소 내역은 전체 변경 이력에 남습니다.

뒤에 등록한 기록 때문에 취소할 수 없다는 안내가 나오면, 해당 기록과 연결된 후속 기록을 먼저 확인하세요. 선택하지 않은 기록까지 자동으로 지우지는 않습니다.

S009 · 이사 날짜와 새 주소 등록
============================================================
이사 날짜와 새 주소 등록

여는 위치 · 대상자의 도로명주소·상세주소·관할동 칸 우클릭 → 이사 등록

1. 이사할 사람의 주소 칸에서 우클릭해 이사 등록을 엽니다.
2. 적용일에 새 주소로 배송할 첫날을 입력합니다.
3. 이사할 주소에는 도로명주소, 상세주소에는 동·호수 등을 입력합니다. 관할동도 확인합니다.
4. 배송기사가 바뀌면 식종별 배송담당을 선택합니다.
5. 같은 가구가 함께 이사하면 같은 가구 구성원도 함께 이사를 체크하고 표시된 이름을 확인합니다.
6. 저장을 누릅니다. 명단의 조회 날짜를 적용일로 바꿔 주소와 배송담당을 확인합니다.

특정 날짜부터 주소를 바꿀 때는 이사 등록을 사용합니다. 적용일 전 주소는 그대로 남습니다. 주소 글자의 오타만 고치는 경우에는 해당 주소 칸을 더블클릭해 수정합니다.

만들 파일 고르기

여는 위치 · 명단 오른쪽 위 → 문서 만들기

행복도시락 일일식수·배송목록의 인원은 청구 식수가 아닙니다. 배송 형태·식종·기사 선택에 따라 출력 대상도 달라지므로 숫자가 다를 때 이 항목부터 확인하세요. 자세한 기준은 행복도시락 일일식수 [참고: S014 · 행복도시락 일일식수]를 참고하세요.

S011 · 청구서·확인서·일일식수 만들기
============================================================
청구서·확인서·일일식수 만들기

1. 문서 만들기에서 파일 종류를 선택합니다. 청구서·확인서를 처음 만들 때 문서 양식이나 생성 Excel 비밀번호 설정창이 나오면 값을 정해 저장한 뒤 기간 선택으로 진행합니다. 일일식수는 비밀번호 설정 없이 진행합니다.
2. 기간 확인에서 청구서·확인서는 연월, 일일식수는 시작일과 종료일을 정합니다. 확인 버튼을 눌러 다음 화면으로 갑니다.

변경번호는 저장한 기록을 구분하는 번호입니다. 예전에 저장한 상태로 문서를 만들 때만 이전 변경번호 선택을 누릅니다. 변경번호·사유·변경자로 검색해 사용할 기록을 찾습니다.

3. 파일에 넣을 식종을 체크합니다.
4. 일일식수에 배송 형태 선택이 보이면 기본·별도 형태의 체크도 확인합니다. 해제한 형태는 식수와 가구 수에서 빠집니다. 선택을 마치면 선택한 식종 사용을 누릅니다.

5. 저장 위치와 파일명을 확인합니다. 폴더가 정해져 있지 않으면 기본 폴더 선택을 누릅니다. 이번 파일만 다른 곳에 저장하려면 이번만 다른 폴더를 선택합니다.
6. 이 이름으로 만들기를 누릅니다.
7. 완료 안내가 나오면 생성된 파일을 열어 대상 월·식종·식수·주소를 확인합니다.

청구서·확인서는 설정된 생성 Excel 비밀번호로 엽니다. 일일식수는 비밀번호 없이 생성됩니다. 같은 이름의 문서가 있으면 새 재발행 번호가 붙습니다.

명단이나 칼럼 연결을 고쳐도 이미 만든 Excel 파일은 바뀌지 않습니다. 수정한 내용으로 파일을 다시 만드세요.

월중 가구 변경과 문서 기준일

청구서·확인서는 선택한 원본 변경번호의 현재 가구 연결로 묶어 출력합니다. 가구 연결일은 출력 조건으로 사용하지 않습니다. 식수·금액·배송담당·주소는 기존 날짜별 계산을 유지합니다.

소속 기록이 없는 대상자도 1인 가구로 출력합니다. 과거 명단으로 다시 만들 때는 원본 변경번호를 선택하면 그때 저장된 가구와 명단을 사용합니다.

가구 변경 이력은 그대로 보관됩니다. 일일식수·배송목록도 선택한 원본 변경번호의 현재 가구 연결을 사용합니다. 다만 날짜·식종·기사별 출력 대상이 달라 문서마다 표시되는 가구원은 다를 수 있습니다.

완성된 문서에서 확인할 내용

확인서는 월요일~일요일을 한 주로 나누고 기본으로 해당 월 날짜만 표시합니다. 다음 달 1일이 토요일 또는 일요일이면 문서 양식의 날짜 표시 옵션 [참고: S051 · 문서 양식]으로 마지막 주에 포함할 수 있습니다. 날짜 표시 옵션은 식수를 바꾸지 않습니다. 예를 들어 2026년 10월 첫 주는 1~4일입니다. 6주인 달은 양식의 5개 주차 칸에 맞춰 토요일 시작이면 마지막 두 주, 일요일 시작이면 처음 두 주를 합칩니다.

행복도시락 방학 청구서의 학기중 시트에는 조식·석식, 방중 시트에는 중식을 나누어 표시합니다. 여러 식종을 받는 사람은 해당 시트에 각각 나오며 두 시트의 합계는 총괄과 일치합니다.

확인서에서 1식짜리 가구를 먼저 배치하려면 설정 → 문서 → 문서 양식 [참고: S051 · 문서 양식]의 배치 옵션을 선택하고 문서를 새로 만드세요.

일일식수의 배송 형태와 비고 설정

1. 일일식수의 식종 선택 화면에서 포함할 배송 형태를 체크합니다. 제외한 형태는 식수·가구 수에서 빠집니다.
2. 추가 설정 → 비고 설정…을 엽니다.
3. 비고에 추가할 칼럼에서 사용할 칼럼을 체크하고 이름을 드래그하거나 위로·아래로 옮겨 우선순위를 정합니다. 사람마다 값이 있는 첫 칼럼만 이름과 함께 표시하며 모두 빈칸이면 추가하지 않습니다.
4. 기존 비고 위 또는 기존 비고 아래를 선택합니다. BOX 등 따로 표시할 배송 형태도 여러 개 선택할 수 있습니다.
5. 제외한 배송도 표시를 켜면 포함 배송 형태에서 제외한 대상도 선택한 형태의 비고에는 표시합니다. 이 사람들을 식수·가구 수에 더하지는 않습니다.
6. 적용 후 식종 선택을 확정하고 파일을 생성해 비고를 확인합니다.

행복도시락 일일식수는 요일과 관계없이 석식·조식을 기본 체크하며, 중식이 필요하면 추가로 체크합니다. 급식 일일식수와 배송목록의 기본 식종은 선택 날짜(기간이면 시작일)에 따라 월~목은 석식, 금요일은 조식으로 제안합니다. 필요한 식종으로 바꿀 수 있으므로 생성 전에 체크 상태를 확인하세요. 청구서·확인서는 모든 식종이 기본 선택입니다.

뒤로를 누르면 앞 단계로 돌아가 선택을 고칠 수 있습니다. 닫기나 Esc는 문서 만들기를 취소하며, 최종 확정 전에는 문서 파일을 만들지 않습니다.

S012 · 배송목록 만들기
============================================================
배송목록 만들기

새 행복도시락 양식은 플레이스홀더 연결과 복사할 행 [참고: S028 · 배송목록의 플레이스홀더 연결과 행 복사]을 정합니다. 아래의 칼럼 체크·가구별 병합·용지 설정은 기존 배송대타 예시 양식에 적용됩니다.

같은 가구는 하나의 묶음으로 출력합니다. 배송순서가 떨어져 있어도 첫 가구원이 나오는 위치에 함께 배치하며, 출력용 핸드폰이나 주소가 다르다는 이유로 나누지 않습니다.

성명은 사람별로 표시하고, 나머지 선택한 칼럼은 같은 값은 한 번만, 다른 값은 줄바꿈으로 모두 넣습니다. 한쪽만 값이 있으면 그 값을 쓰며, 비고·상세주소·연락처·사용자 칼럼과 대체값에도 적용됩니다. 원본 명단이나 가구 공용 설정은 바뀌지 않습니다.

1. 문서 만들기 → 배송목록을 선택합니다.
2. 배송할 날짜와 기준 식종을 선택합니다. 급식은 한 식종만 선택합니다. 행복도시락에서만 석식·중식은 조식, 조식은 석식을 기본으로 함께 표시하며 체크를 해제할 수 있습니다.
3. 배송담당에서 필요한 기사를 고릅니다.
4. 배송대타에 넣을 항목에서 출력할 칼럼을 체크합니다. 칼럼 이름을 드래그해 순서를 바꿉니다.
5. 용지 방향과 페이지 구분을 정합니다. 가구 수마다 나누거나 관할동별로 나눌 수 있습니다.
6. 저장 위치 선택을 눌러 폴더·파일명을 확인하고 생성합니다.

빈 값 대신 다른 칼럼을 쓰려면 배송대타의 대체 칼럼 설정 [참고: S029 · 기존 배송대타 양식의 출력 칼럼·대체값]을 참고하세요.

각 칼럼의 값이 비어 있으면에서 대체 칼럼을 고르고, 옆에서 가로 정렬(왼쪽·가운데·오른쪽)과 세로 정렬(위·가운데·아래)을 정합니다. 기본은 왼쪽·아래이며 제목과 본문에 적용됩니다. 출력 순서는 칼럼 이름을 드래그해 바꿉니다.

S013 · 지금 보이는 명단을 Excel로 저장
============================================================
지금 보이는 명단을 Excel로 저장

여는 위치 · 더보기 → 명단·파일 → Excel 내보내기

1. 필요한 시트로 이동하고 검색·필터·칼럼 숨김을 맞춥니다.
2. Excel 내보내기에서 현재 시트를 선택합니다.
3. 저장 위치와 파일명을 정합니다. 내보낸 파일에서 보이는 행·칼럼과 순서를 확인합니다.

전체 명단과 이력까지 필요하면 전체 데이터를 선택합니다. 식수를 계산한 청구서나 배송표는 문서 만들기에서 생성하세요.

전체 데이터는 화면 검색·필터·숨긴 칼럼과 관계없이 전체 명단과 이력을 내보냅니다. 조회 기준일을 정한 뒤 파일 저장을 누르세요. 식종별 담당이 서로 다르면 식종별 명단과 한 사람 한 행의 통합 명단을 함께 만들고, 모두 같으면 통합 명단만 만듭니다. 이력은 별도 시트로 저장하며 생성 Excel 공통 비밀번호를 적용합니다. Excel 내보내기는 앱의 운영 파일 백업을 대신하지 않습니다.

S014 · 행복도시락 일일식수
============================================================
행복도시락 일일식수

설정 → 문서 → 문서 양식에서 행복도시락을 선택하고 저장한 뒤 문서 만들기 → 일일식수를 엽니다. 기간·식종·배송 형태와 비고 옵션을 정하고 저장 위치를 선택합니다. 석식·조식은 기본으로 함께 체크되며, 중식은 필요할 때 추가로 체크하세요. 체크하지 않은 식종은 계산하지 않습니다.

기사·지역별 조식·석식 수량은 조식·석식 양식에, 중식 수량은 중식 양식에 작성합니다. 함께 선택하면 같은 통합 문서에 날짜별로 두 시트를 만들며 최근 날짜부터 표시합니다. 중식 시트 이름에는 중식_이 붙습니다.

조식·석식·중식 모두 선택일에 가입한 식종의 상태를 기준으로 한 사람을 1명씩 셉니다. 배송·일시중지는 포함하고 중지·미가입은 집계하지 않습니다. 배송요일·실제 배송일·대체식·학교 일정·개인 중식 기간과 관계없이 배송목록과 같은 기준을 사용합니다. 대상자가 없는 칸은 0 대신 빈칸으로 둡니다.

이 인원 표시는 청구서·확인서의 실제 식사 수와 다릅니다. 예를 들어 금·토·일 3일분을 묶어 받는 사람도 일일식수에는 선택한 날짜마다 1명으로 셉니다. 청구서·확인서는 기존대로 실제 식사 수와 중지·일시중지·학교 일정·대체식 규칙을 적용합니다. 가구별 식수 분포는 DB의 가구 소속을 사용합니다. 기사 또는 지역 값이 없으면 미분류로 모입니다.

중식 시트는 중식 기사 순서, 조식·석식 시트는 석식이 있으면 석식 기사 순서, 조식만 있으면 조식 기사 순서를 사용합니다. 일일식수 기사 순서에서 바꿀 수 있습니다. 일일식수는 기존처럼 Excel 암호 없이 저장합니다.

배송 형태를 제외하면 해당 대상자는 인원·가구 수에서 빠집니다. 기사별 소계와 전체 합계도 한 사람당 1명 기준입니다. 급식·행복도시락 일일식수의 신규·배송·중지·일시중지·복원 제목, 비고 설정에서 추가한 칼럼 값 제목과 BOX 별도 같은 배송 형태 안내 제목은 빨간색으로 표시합니다. 여러 줄짜리 추가 값도 제목 전체를 강조합니다. 아래 대상자 이름·주소와 가구·식수 집계, 나머지 글꼴·셀 서식은 양식을 유지합니다.

기사별 조식·석식 또는 중식 소계와 맨 아래 전체 식수 합계를 표시합니다. 기존 행복도시락 양식의 열 너비·숨긴 보조 열·인쇄 범위를 유지합니다. 식수가 없는 칸과 그 합계에는 0을 표시하지 않습니다.

기사·지역·주소·비고를 바꾸려면 일일식수 항목 연결 [참고: S031 · 급식·행복도시락 일일식수의 공용 항목 연결]을 사용합니다. 이미 만든 Excel은 바뀌지 않으므로 새 파일을 만들어 확인하세요.

행복도시락의 새 배송목록은 플레이스홀더를 연결하고 지정한 행을 복사하는 자유 양식입니다. 연결·행 복사 방법 [참고: S028 · 배송목록의 플레이스홀더 연결과 행 복사]을 확인하세요. 업체별 양식은 따로 수정할 수 있습니다.

S015 · 학교 일정이 없는 중식은 제외하고 출력
============================================================
학교 일정이 없는 중식은 제외하고 출력

학교 일정이 없는 학교나 날짜가 있어도 청구서·확인서 및 급식의 일일식수·배송목록 생성을 전부 취소하지 않습니다. 해당 중식만 제외하고, 일정이 있는 학교·날짜와 조식·석식은 계속 출력합니다. 행복도시락의 일일식수·배송목록은 가입·상태 기준이므로 학교 일정이 없어도 대상자를 셉니다. 학교명이 비어 있는 대상자도 해당 중식만 제외합니다.

완료 화면에 제외된 학교·날짜·인원·식수를 표시하고 문서 생성 기록에도 남깁니다. 누락된 학교 일정을 등록한 뒤 문서를 다시 만들면 반영됩니다. 제외 후 출력할 대상이 하나도 없으면 빈 파일 대신 그 사유를 안내합니다. 저장된 일정 자체가 손상된 경우 등 다른 오류는 계속 확인해야 합니다.

S016 · 용도별 시트 만들기
============================================================
용도별 시트 만들기

시트는 같은 명단을 다른 칼럼 배치로 보는 화면입니다. 예를 들어 연락처 확인용 시트에는 성명·핸드폰·학교·비고를 두고, 배송용 시트에는 식종·주소·배송순서를 둘 수 있습니다.

1. 명단 아래 시트 이름 옆의 +를 누릅니다.
2. 시트 이름을 입력하고 확인합니다. 예: 연락처, 배송용.
3. 새 시트에서 필요 없는 칼럼을 숨기고 순서·너비를 조정합니다.
4. 다른 시트 이름을 눌러 전환합니다.

어느 시트에서 값을 수정하든 같은 사람의 정보가 바뀝니다. 시트별로 다른 명단을 보관하는 기능은 아닙니다. 날짜·검색·필터·정렬도 시트 사이에서 함께 사용합니다.

시트 이름을 우클릭하면 이름 바꾸기와 시트 삭제가 나옵니다. 시트를 삭제해도 대상자 정보는 남고, 마지막 시트 하나는 삭제할 수 없습니다.

S017 · 대상자별 중식 시작일·종료일
============================================================
대상자별 중식 시작일·종료일

학교 일정 기간 파일을 저장하면 기존 중식 대상과 이 두 날짜를 초기화합니다. 새 기간에는 중식 명단을 다시 불러와야 대상이 됩니다. 초기화 기준일 전의 가입·식수 기록과 변경 이력은 남습니다. 1차·2차 중식 명단을 누적하는 동안에는 학교 일정 파일을 다시 저장하지 마세요.

명단의 중식 식종 옆에 중식 시작일·중식 종료일 기본 칼럼이 있습니다. 사용자 칼럼을 따로 만들 필요가 없습니다.

1. 방학 중식 대상자 갱신으로 명단을 불러오면 선택한 방학 기록의 학교·학년별 중식 시작일·종료일을 채웁니다. 학교가 선택 기록에 없거나 해당 학년의 제공일이 없으면 학교명·방학 기록·학년 예외를 확인한 뒤 다시 불러옵니다.
2. 날짜를 바꾸려면 해당 셀을 더블클릭하거나 선택 후 F2를 누르고 YYYY-MM-DD로 입력합니다. 시작일·종료일 당일을 모두 포함하며 종료일은 시작일보다 빠를 수 없습니다.
3. 중간에 중식을 추가할 때는 중식 식종을 우클릭해 배송을 선택하고 실제 시작일을 입력합니다. 미가입 중식은 그 날짜부터 등록하고, 종료일을 지정하지 않으면 학교 일정에서 채웁니다. 이미 가입된 중식의 일시중지 해제는 기존 날짜를 유지합니다.
4. 1차·2차 중식 명단을 불러올 때 같은 방학 기록을 선택하면 대상자를 누적합니다. 빠진 사람의 날짜는 유지됩니다. 다른 방학을 선택하면 그 기간을 추가하며, 기존 유지·업데이트 선택에 따라 기존 정보와 해당 방학 기간을 처리합니다. 다른 방학의 등록 기간과 조식·석식은 유지됩니다.

날짜 수정은 실제 중식 배송·식수·청구 계산에도 적용됩니다. 배송 상태, 가입 기간, 학교 일정·휴무 조건을 모두 만족해야 합니다. 중지·일시중지 상태이면 기간 안이어도 제외됩니다. 반대로 배송 상태여도 시작일 전이나 종료일 후에는 중식이 계산되지 않습니다. 날짜만 바꿔도 중지·일시중지 상태가 배송으로 바뀌지는 않습니다. 같은 가구여도 날짜는 사람별로 수정합니다.

시작일을 지우면 종료일도 함께 비워지고 현재 중식 등록이 해제됩니다. 종료일만 지우면 종료 제한이 없어지지만 학교 일정과 배송 상태 조건은 계속 적용됩니다. 기존 운영 파일은 다음 중식 명단 반영이나 직접 입력 전까지 날짜가 비어 있을 수 있으며, 이때는 기존 가입 기록으로 계산합니다.

배송순서관리 [참고: S038 · 배송순서관리]에서는 중식 기간 표시 체크 하나로 두 날짜를 함께 보이거나 숨깁니다. 기사별 시작·종료만 필요한 파일은 기사 관리의 중식 기간 Excel 내보내기 [참고: S036 · 기사별 중식 시작일·종료일 Excel 내보내기]를 사용하세요.

칼럼 숨기기·다시 보이기

S020 · 새 칼럼 만들기
============================================================
새 칼럼 만들기

여는 위치 · 더보기 → 운영·설정 → 칼럼 관리 → 사용자 항목 추가·삭제

1. 새 항목 이름에 칼럼 이름을 입력합니다. 예: 전달사항.
2. 내용에 맞는 형식을 선택합니다. 메모는 문자, 수량은 숫자, 날짜는 날짜 형식을 고릅니다.
3. 선택형이면 사용할 값들을 쉼표로 나눠 입력합니다. 예: 문 앞, 직접 전달, 전화 후 전달.
4. 추가를 누릅니다. 명단에서 새 칼럼의 셀을 더블클릭해 값을 입력합니다.

새 사용자 항목은 기본 명단 시트에 표시됩니다. 기존에 꾸민 다른 시트에서 보이지 않으면 칼럼 관리에서 그 항목을 체크하세요.

직접 입력하는 칼럼의 제목을 우클릭한 뒤 입력 제한 설정에서 전화번호·날짜 형식이나 최대 글자 수를 정할 수 있습니다. 선택형 항목의 선택지는 사용자 항목을 만들 때 정합니다.

입력 형식 제한·사용자 칼럼 삭제

문자 입력 칼럼의 제목을 우클릭해 입력 제한 설정…에서 제한 없음, 전화번호, 날짜, 최대 글자 수를 선택하고 저장합니다. 생년월일은 형식 설정과 관계없이 실제 날짜로 저장합니다. 기존 값이 잘못되었다고 자동으로 고치는 기능은 아닙니다.

칼럼을 화면에서만 빼려면 숨기기를 사용합니다. 사용자 칼럼 자체를 지우려면 칼럼 관리 → 사용자 항목 추가·삭제에서 해당 항목을 선택해 삭제하고 확인창을 읽습니다. 기본 칼럼은 사용자 항목처럼 삭제할 수 없습니다. 사용자 칼럼 삭제는 그 항목에 입력한 값에도 영향을 줍니다.

S021 · 검색·필터·정렬 사용
============================================================
검색·필터·정렬 사용

식종의 기사·상태를 따로 고르기

석식·조식·중식 칼럼 제목의 필터 버튼을 열면 배송기사와 배송상태가 나뉘어 있습니다. 각 목록에서 여러 값을 체크할 수 있고 두 조건을 모두 만족하는 대상자만 표시합니다. 예를 들어 기사A를 선택하고 배송·일시중지를 체크하면 기사A의 해당 두 상태를 함께 볼 수 있습니다.

기사만 제한하려면 상태를 전체 선택하고, 상태만 제한하려면 기사를 전체 선택합니다. 상태의 -는 현재 배송 상태가 표시되지 않는 행이며, 기사 미지정도 따로 선택할 수 있습니다. 각 목록 맨 위의 (모두 선택)을 체크하거나 해제하면 전체 선택·해제가 됩니다. 일부만 선택하면 부분 체크로 표시됩니다. 두 목록을 모두 선택하고 검색칸의 지우기 버튼으로 검색어를 지운 뒤 적용하면 제한이 해제됩니다. 아래에는 적용·취소 버튼만 있습니다. 기존 전체 검색·다른 칼럼 조건과 함께 적용되고 선택은 기존 화면 기억 설정에 따라 복원됩니다.

1. 이름·학교·전화·주소로 찾을 때는 명단 위의 검색칸에 입력합니다.
2. 특정 칼럼의 값만 보려면 칼럼 제목 옆 ▼를 누르고 필요한 값을 체크한 뒤 적용합니다. 예: 관할동에서 정자동만 선택.
3. 순서를 바꾸어 보려면 칼럼 제목을 누릅니다. 한 번은 오름차순, 두 번은 내림차순, 세 번은 그 칼럼의 정렬 해제입니다.
4. 검색 결과가 너무 적으면 검색어를 지우고 칼럼 필터 해제를 누릅니다. 중지한 사람은 숨긴 행 포함도 체크해 봅니다.

여러 칼럼에 필터를 걸면 모든 조건에 맞는 사람만 보입니다. 시트를 바꿔도 필터는 남습니다. 검색어가 없다고 전체 명단인 것은 아닙니다.

두 칼럼 이상으로 정렬하면 먼저 누른 칼럼이 우선입니다. 예를 들어 학교를 먼저, 성명을 다음에 누르면 학교별로 모은 뒤 이름순으로 볼 수 있습니다.

생일 대상자를 찾으려면 왼쪽 생일 월의 월 선택으로 좁힙니다. 이번 달은 명단 조회일이 아닌 오늘 날짜의 달을 기준으로 합니다. 별도 설정만은 배송 설정이 기본값과 다른 사람만 보여줍니다. 검색·생일·칼럼 필터·숨긴 행 포함·별도 설정 조건은 함께 작용하므로 원하는 사람이 없으면 각각 확인하세요. 상단 인원·식종 집계는 현재 표시한 명단을 기준으로 합니다.

S022 · 같은 가구의 값을 함께 관리
============================================================
같은 가구의 값을 함께 관리

여는 위치 · 칼럼 관리 → 칼럼 가구 공용 설정

1. 공용으로 쓸 칼럼을 고릅니다.
2. 가구원 값이 서로 다르면 표시된 비교 내용을 확인하고 사용할 값을 정합니다.
3. 적용한 뒤에는 해당 공용 칼럼을 수정할 때 같은 가구에 함께 반영됩니다. 다만 가구 묶기 기준인 칼럼은 변경한 값에 따라 먼저 가구를 다시 나누므로, 다른 값으로 바꾼 사람의 값이 이전 가구원에게 복사되지는 않습니다.
4. 한 사람만 다른 값을 써야 하면 그 사람의 해당 셀을 우클릭해 공용 예외를 체크한 뒤 값을 수정합니다.

공용 예외를 켜거나 끄는 것만으로 현재 값이 바뀌지는 않습니다. 해제한 뒤의 공용 값 수정부터 다시 함께 적용합니다. 도로명주소와 상세주소의 공용 설정은 각각 따로 정합니다.

같은 기준의 가구 합치기

가구는 설정 → 데이터 관리 → 가구 묶기 기준 [참고: S070 · 가구 묶기 기준]에서 선택한 칼럼으로 묶습니다. 기본은 핸드폰이며, 여러 칼럼을 선택하면 모든 값이 같아야 합니다. 선택한 값 중 빈칸이 있으면 묶지 않습니다. 기본 핸드폰·전화번호 칼럼의 하이픈·공백은 구분하지 않습니다. 이미 값이 같은 별도 가구는 설정의 저장·기존 명단에 적용으로 합칠 수 있습니다. 이후 명단 불러오기·신규 대상자 등록·기준 칼럼 수정에도 같은 기준을 사용합니다. 공용 예외도 가구 묶기 대상에 포함합니다.

다른 공용 값이 다르면 확인창에서 사용할 값을 고르거나 직접 입력한 뒤 저장합니다. 취소하면 입력 변경과 합치기를 저장하지 않습니다. 가구 기준값을 바꾸거나 지워 서로 달라지면 저장할 때 별도 가구로 나뉩니다. 공용 설정만 해제하고 기준값은 그대로 두면 가구를 유지합니다. 비고 등 칼럼을 공용으로 켜면 현재 가구 기준이 같은 별도 가구도 다시 합칩니다. 합칠 비고가 다르면 사용할 값을 확인하며, 저장 후 배송순서관리도 한 행으로 갱신됩니다. 기사가 다르면 별도 배송 행을 유지하지만 같은 가구·같은 기사이면 주소나 상세주소가 달라도 한 행으로 묶습니다. 비고 자체가 가구 묶기 기준이면 비고 값도 같아야 합쳐집니다.

가구 공용 설정은 같은 운영 파일에 저장됩니다. 공용으로 수정하면 검색·필터로 보이지 않는 같은 가구원에게도 적용됩니다. 한 사람만 다른 값을 유지하려면 그 사람의 해당 셀을 우클릭해 공용 예외를 설정한 뒤 수정하세요. 공용을 해제하면 현재 값은 유지되고 이후 수정부터 개인별로 적용됩니다.

다른 담당자의 화면 배치 불러오기

S024 · 청구서·확인서의 출력 칼럼 연결
============================================================
청구서·확인서의 출력 칼럼 연결

출력 칼럼 연결은 만든 Excel의 어느 칸에 명단의 어떤 값을 넣을지 정하는 기능입니다. 예를 들어 확인서의 전화번호 칸에 명단의 핸드폰 값을 넣을 수 있습니다.

여는 위치 · 더보기 → 운영·설정 → 설정 → 문서 항목 설정

1. 위쪽 양식에서 급식 또는 행복도시락을 선택합니다.
2. 문서에서 청구서 또는 확인서를 선택합니다.
3. 왼쪽 출력 칼럼에서 바꿀 항목을 찾습니다.
4. 그 줄의 1순위에서 가져올 명단 칼럼이나 자동 계산 항목을 고릅니다. 비어 있을 때 다른 값을 쓰려면 2순위도 고릅니다.
5. 저장을 누릅니다. 다른 양식·문서도 바꾸려면 다시 열어 해당 조합을 선택합니다.
6. 문서 만들기에서 파일을 새로 생성하고 값이 들어간 칸을 확인합니다.

급식 청구서, 급식 확인서, 행복도시락 청구서, 행복도시락 확인서는 연결을 각각 설정합니다. 명단 Excel을 다시 가져올 필요는 없습니다.

확인서는 연결한 양식에서 {...}처럼 중괄호로 된 항목 표시를 찾아 그대로 목록에 보여줍니다. 실제 양식에 표시된 항목을 골라 1순위·2순위를 연결하세요. 제목·주차·식수 등은 자동 값이 기본으로 연결됩니다.

S025 · 1순위와 2순위 예시
============================================================
1순위와 2순위 예시

출력 칼럼 | 1순위 | 2순위
전화번호 | 핸드폰 | 전화번호
도로명주소 | 도로명주소 | 사용 안 함

위처럼 연결하면 전화번호 출력 칸에는 우선 핸드폰 값이 들어갑니다. 핸드폰이 빈 사람에게만 전화번호 값을 사용하고, 둘 다 비어 있으면 빈칸으로 나옵니다.

1순위와 2순위를 이어 붙이는 기능은 아닙니다. 도로명주소와 상세주소를 각각 넣으려면 문서에 해당 출력 칼럼이 있는지 확인하고 각각 연결하세요.

비움은 1순위로 가져올 항목이 없는 상태입니다. 사용 안 함은 2순위 대체값을 사용하지 않는 상태입니다. 칸을 비워 두려면 1순위는 비움, 2순위는 사용 안 함으로 정합니다.

S026 · 식수·금액·연번의 연결 바꾸기
============================================================
식수·금액·연번의 연결 바꾸기

식수·청구금액·연번·제공기관·식종 변경 이력도 연결을 바꿀 수 있습니다. 처음에는 프로그램이 사용하던 계산값과 공통 설정이 선택되어 있습니다.

선택할 항목 | 출력하는 값
연번 (자동 계산) | 해당 시트에 출력한 사람의 순서: 1, 2, 3…
조식·석식·중식 식수 (자동 계산) | 선택한 기간에 계산된 해당 식종의 식수
합계 식수 (자동 계산) | 조식·석식·중식을 더한 식수
청구금액 (자동 계산) | 해당 기간의 식수와 단가로 계산한 금액
공통 제공기관 | 프로그램에 설정된 제공기관 이름
식종 변경 이력 | 선택한 문서 원본과 기간의 배송·일시중지·중지 기록
템플릿 값·수식 유지 | 양식 파일에 들어 있는 값이나 Excel 수식

예를 들어 새 양식에서 조식 칼럼 이름이 아침 식수로 바뀌었으면, 그 출력 칼럼의 1순위에 조식 식수 (자동 계산)을 연결합니다. 자동 계산값을 다른 위치에 넣을 때도 같은 방법을 사용합니다.

1. 변경한 양식 파일을 저장한 뒤 문서 항목 설정을 다시 엽니다.
2. 새 출력 칼럼을 찾아 1순위에 넣을 항목을 고릅니다. 기존 칼럼에 같은 값이 필요 없으면 그 칼럼의 연결도 바꿉니다.
3. 저장하고 문서를 새로 만든 뒤 칼럼 위치와 값을 확인합니다.

자동 식수 칸을 이름·메모 등으로 바꾸어도 자동 합계와 청구금액은 원래 계산된 식수를 사용합니다. 기본 연결로 돌아가려면 이 문서 초기화를 누르고 내용을 확인한 뒤 저장하세요. 현재 선택한 양식·문서의 다른 연결과 2순위도 함께 초기화됩니다.

S027 · 청구서에 식종 변경 이력 넣기
============================================================
청구서에 식종 변경 이력 넣기

여는 위치 · 설정 → 문서 항목 설정 → 문서: 청구서

1. 식종 변경 이력을 넣을 출력 칼럼을 찾습니다.
2. 그 줄의 1순위를 식종 변경 이력으로 고릅니다. 개인 메모를 넣으려면 명단의 비고를 고릅니다.
3. 저장한 뒤 청구서를 다시 만듭니다.
4. 지정한 칼럼에 석식: 10/26~10/29 일시중지처럼 기간과 상태가 나오는지 확인합니다.

식수·청구서 설정에서도 이력을 넣을 기본 칼럼을 정할 수 있습니다. 다만 항목 설정에서 따로 저장한 연결이 있으면 그 연결을 먼저 적용합니다. 이력을 빼려면 이력이 연결된 칼럼을 비움으로 바꾸고 2순위도 사용 안 함으로 정하세요.

S028 · 배송목록의 플레이스홀더 연결과 행 복사
============================================================
배송목록의 플레이스홀더 연결과 행 복사

행복도시락 배송목록 기본 양식은 가로 방향으로 인쇄합니다. 기존 배송대타 양식도 처음 용지 방향은 가로이며, 이전에 저장한 방향이 있으면 그 선택을 유지합니다. 별도로 연결한 양식은 그 Excel 파일에 저장된 인쇄 방향을 따릅니다.

여는 위치 · 문서 만들기 → 배송목록 → 날짜·식종 선택 → 담당과 출력 설정

행복도시락의 새 기본 양식은 값을 넣을 셀에 {성명}, {주소}, {배송일자} 같은 플레이스홀더를 사용합니다. 시트 이름과 셀 위치를 바꿀 수 있으며, {학생이름}처럼 이름을 자유롭게 정한 뒤 명단 항목과 연결할 수도 있습니다. 같은 플레이스홀더를 여러 셀에 넣으면 같은 값을 사용합니다.

1. 설정 → 문서 → 문서 양식 → 배송목록 양식 확인/수정에서 Excel 양식을 열거나 다른 양식 파일 선택으로 연결합니다. 값이 들어갈 셀에 중괄호로 둘러싼 플레이스홀더를 적고 저장한 뒤 이 양식 사용을 누릅니다.
2. 문서 만들기 → 배송목록에서 날짜·식종·배송담당을 정합니다.
3. 양식의 플레이스홀더 / 1순위 / 2순위 표에서 각 항목을 연결합니다. 1순위가 비어 있으면 2순위를 사용합니다. 기존 배송목록에 저장한 대응 칼럼의 우선 연결도 처음에 불러옵니다. 날짜는 배송일자, 식종 칸은 조식 제공 여부 (1 / 빈칸) 또는 선택 식종 제공 여부 (1 / 빈칸)를 선택합니다. 제목에는 선택 식종 이름이나 선택 식종 명단 제목을 연결할 수 있습니다. 여러 관할동을 한 칸에 넣으려면 원하는 플레이스홀더의 1순위 또는 2순위에서 관할동 합치기를 선택하세요. 선택한 배송담당의 출력 대상 관할동을 빈값·중복 없이 배송목록 순서대로 가동, 나동처럼 합칩니다. 제목과 본문 어디에나 연결할 수 있으며, {관할동 조인}과 {관할동 합치기}는 처음에 이 항목으로 연결됩니다. 이미 비움 등 다른 연결을 저장했다면 직접 변경하세요.
4. 복사·끼워넣기 범위를 확인합니다. 플레이스홀더가 가장 많은 행을 자동 제안하며 같은 개수이면 위쪽 행을 선택합니다. 한 사람당 한 줄이면 3~3행, 두 줄이면 3~4행처럼 시작·끝 행을 지정합니다. 병합이 두 행에 걸치면 그 두 행을 모두 포함합니다.
5. 저장 위치 선택으로 파일을 만들고 날짜·이름·식종별 1 표시와 인쇄 미리보기를 확인합니다.

대상자마다 지정한 행 블록을 복사해 끼워 넣습니다. 글꼴·색·테두리·정렬·줄바꿈·표시 형식·행 높이·열 너비·용지·여백·배율은 Excel 양식을 그대로 사용합니다. 제목과 뒤쪽 내용은 유지하고 인쇄 영역은 늘어난 행만큼 확장합니다. 날짜는 선택한 배송일로 고정되며, 원하는 날짜 모양은 Excel 셀의 표시 형식으로 지정하세요. 같은 셀에 배송일: {배송일자}처럼 글자를 함께 넣을 수도 있습니다.

연결과 복사 범위는 이 PC의 운영 파일·양식 경로별로 기억합니다. 양식의 플레이스홀더나 행 위치를 바꿨다면 다시 확인하세요. 비움은 빈칸으로 출력하며 플레이스홀더 그대로 유지는 적힌 문구를 남깁니다. 원본 양식과 이미 만든 문서는 생성 과정에서 바뀌지 않습니다.

연번을 연결하면 선택한 기사 명단에서 사람마다 1, 2, 3…으로 매깁니다. 같은 가구도 각자 번호가 붙습니다. 명단에 저장한 배송 순서를 그대로 넣으려면 배송순서를 선택하세요. 예전 양식의 첫 칸이 {배송순서}라면 그 항목의 1순위를 연번으로 바꾸면 됩니다.

양식 하단에 남아 있는 빈 서식 행은 출력할 때 제거하고 인쇄 범위를 마지막 대상자 또는 하단 안내·합계까지 맞춥니다. 복사 범위 안의 빈칸과 내용 있는 병합 셀은 유지합니다. 그림·차트·표가 있는 양식은 배치를 보존하기 위해 자동으로 줄이지 않습니다.

비고에 식종 변경 이력 넣기

1. {비고} 행의 1순위에서 식종 변경 이력을 선택합니다.
2. 이력이 없는 사람에게 명단 비고를 넣으려면 2순위에서 비고를 선택합니다. 이력만 출력하려면 2순위를 사용 안 함으로 둡니다.
3. 파일을 새로 만들어 사람별 비고를 확인합니다.

선택한 원본 변경번호와 날짜를 기준으로 급식 일일식수 비고의 신규·배송·중지·일시중지·복원 규칙을 사용합니다. 함께 표시한 식종까지 석식: 일시중지 11/9~11/11처럼 식종별로 줄바꿈해 넣습니다. 월 전체 이력을 나열하는 기능은 아니며, 해당 비고 규칙에서 이력이 없으면 빈칸 또는 2순위 값을 사용합니다. 배송목록에서 제외된 사람의 행을 이력 때문에 추가하지 않습니다. 긴 비고가 잘리면 Excel 양식의 줄바꿈·행 높이를 조절하세요.

행복도시락 배송목록은 석식·중식에 조식을, 조식에 석식을 기본으로 함께 표시합니다. 필요 없으면 함께 표시 체크를 해제하세요. 행복도시락은 두 식종 중 하나라도 가입 상태가 배송·일시중지인 사람을 포함하고 해당 칸은 숫자 1로 둡니다. 중지·미가입은 빈 셀이며 두 식종 모두 중지·미가입이면 그 사람의 행을 제외합니다. 금·토·일 3일분 조식도 제공 여부는 1입니다.

행복도시락 배송목록의 1/빈칸은 기본 상태 표시입니다. 배송요일·실제 배송일·대체식·학교 급식 일정과 상관없이 선택일의 가입·상태를 사용하며 일시중지도 1입니다. 행복도시락 일일식수도 같은 기준으로 한 사람을 1명씩 셉니다. 청구서·확인서의 실제 날짜별 식수 계산은 그대로 유지합니다. 급식 배송목록은 식종 하나만 선택하며, 선택한 날짜·식종의 실제 배송 대상만 표시합니다. 함께 표시 체크는 행복도시락에서만 제공됩니다. 같은 사람이라도 식종별 기사가 다르면 각 기사 명단에 해당 식종만 표시합니다.

기존 배송대타 예시 양식은 아래의 칼럼 선택·가구 병합 방식을 계속 사용합니다. 자유 양식에서는 한 사람마다 지정한 행 블록을 사용하며 가구별 서식으로 덮어쓰지 않습니다.

S029 · 기존 배송대타 양식의 출력 칼럼·대체값
============================================================
기존 배송대타 양식의 출력 칼럼·대체값

여는 위치 · 문서 만들기 → 배송목록 → 날짜·식종 선택 → 담당과 출력 설정

1. 왼쪽에서 출력할 칼럼을 체크합니다. 체크한 칼럼의 이름이 문서 제목으로 사용됩니다.
2. 칼럼 이름을 드래그해 문서에 나올 순서를 정합니다. 체크와 대체값 설정도 함께 이동합니다.
3. 그 칼럼이 빈 사람에게만 다른 값을 넣으려면 오른쪽 값이 비어 있으면에서 대체 칼럼을 고릅니다.
4. 저장 위치를 선택하고 파일을 생성합니다.

예를 들어 핸드폰의 대체 칼럼을 전화번호로 정하면, 핸드폰이 비어 있는 사람만 전화번호를 사용합니다. 문서의 제목은 핸드폰으로 유지됩니다.

목록에 필요한 칼럼이 없으면 설정 → 배송대타 칼럼 표시를 확인하세요. 기본으로 모든 시트에서 숨긴 칼럼 제외가 선택되어 있습니다. 한 시트에서 다시 보이게 하거나 이 설정을 해제하면 선택할 수 있습니다.

명단의 원래 값 | 1순위·2순위로 고른 칼럼에 해당 사람의 값이 있는지 확인합니다.

이전 변경번호 선택 여부 | 예전 원본에는 새 칼럼이나 값이 없을 수 있습니다. 현재 명단으로 만들려면 최신 변경번호를 사용합니다.
자동 계산·이력 칼럼 | 1순위에 원하는 자동 계산 항목이나 식종 변경 이력이 연결되어 있는지 확인합니다.

S031 · 급식·행복도시락 일일식수의 공용 항목 연결
============================================================
급식·행복도시락 일일식수의 공용 항목 연결

1. 설정 → 문서 → 문서 항목 설정을 엽니다.
2. 양식에서 급식 또는 행복도시락을 고르고, 문서에서 일일식수 · 모든 식종 공용을 선택합니다. 두 양식 모두 일일식수를 선택할 수 있습니다.
3. 기사·지역·비고에 표시할 주소·비고의 1순위와 2순위를 정합니다. 1순위 값이 비어 있을 때만 2순위를 사용합니다. 목록을 마우스로 눌러 선택할 수 있습니다. 기사·지역·주소의 기본값은 배송담당·관할동·도로명주소이며, 비고는 두 양식 모두 식종 변경 이력이 기본입니다. 비고의 1순위·2순위에서 식종 변경 이력이나 개인 비고를 선택할 수 있습니다. 예를 들어 1순위에 식종 변경 이력, 2순위에 비고를 고르면 변경 이력이 없는 대상자는 개인 비고를 사용합니다. 둘 다 비우면 해당 연결의 비고를 출력하지 않습니다.
4. 저장하고 일일식수를 새로 만듭니다. 실제 사용할 양식은 설정 → 문서 → 문서 양식에서 고릅니다. 항목 설정에서 다른 양식을 고르는 것만으로 출력 양식이 바뀌지는 않습니다.

같은 양식 안에서는 조식·중식·석식이 연결을 함께 사용합니다. 식수·기사별 소계·전체 합계·포장 수량은 자동 계산하므로 명단 칼럼으로 연결하지 않습니다. 행복도시락은 선택한 날에 가입 상태가 배송·일시중지인 사람을 식종별로 1명씩 셉니다. 실제 배송 수량과의 차이는 행복도시락 일일식수 [참고: S014 · 행복도시락 일일식수]를 확인하세요. 주소 연결을 바꿔도 가구 소속은 바뀌지 않습니다.

현재 저장한 연결은 이전 변경번호를 원본으로 선택해도 적용합니다. 명단 값과 배송량은 선택한 원본 기준이며, 연결한 사용자 칼럼이 현재 명단이나 원본에서 없어졌다면 다시 연결하라는 안내가 나옵니다. 저장한 연결은 운영 파일의 변경 이력·백업에 포함됩니다.

S033 · 대상자 추가·정보 수정
============================================================
대상자 추가·정보 수정

여는 위치 · 명단 오른쪽 위 → 신규 대상자 등록

1. 신규 대상자 등록을 누르고 성명·학교·연락처·주소 등 필요한 값을 입력합니다.
2. 신규 대상자 등록을 눌러 인적사항을 저장합니다. 이 단계에서는 식종 가입이나 배송담당을 지정하지 않습니다.
3. 명단에서 추가한 사람을 찾아 인적사항을 확인합니다. 배송을 시작하려면 해당 식종 칸을 우클릭해 배송을 선택하고 시작일·접수 경로 등을 입력합니다. 담당 기사는 배송 배정에서 지정합니다.

기존 가구와의 연결은 저장된 가구 묶기 기준을 사용합니다. 별도 기준이 없으면 핸드폰을 기준으로 합니다. 공용값이 다르다는 창이 나오면 항목별 값을 확인하고 입력을 고치거나 예외를 선택합니다.

기존 대상자의 연락처·학교·비고는 명단 셀을 더블클릭하거나 오른쪽 정보 수정에서 고칩니다. 배송을 중단할 때는 행 삭제 대신 해당 식종의 중지를 사용합니다.

여러 셀을 한 번에 바꾸기

이 절은 우클릭 메뉴에 선택 셀 일괄 변경이 있는 실행 파일 기준입니다. 메뉴가 없으면 이 기능이 포함된 실행 파일로 업데이트해야 합니다. 그 전에는 셀 더블클릭이나 정보 수정으로 개별 수정할 수 있습니다.

여는 위치 · 명단에서 셀 선택 → 우클릭 → 선택 셀 일괄 변경

1. 바꿀 셀을 마우스로 드래그하거나 Ctrl·Shift를 눌러 여러 개 선택합니다. 선택한 셀 위에서 마우스 오른쪽 버튼을 누르고 선택 셀 일괄 변경 · N개를 누릅니다.
2. 찾아 바꾸기 또는 같은 값으로 채우기를 고릅니다. 찾아 바꾸기는 완전 일치와 부분 일치를 선택할 수 있습니다. 완전 일치는 셀 전체가 같은 값일 때, 부분 일치는 셀 안의 해당 글자만 바꿉니다.
3. 찾을 내용과 바꿀 내용을 입력합니다. 완전 일치에서 찾을 내용을 비우면 빈 셀을 찾습니다. 바꿀 내용을 비우면 찾은 값이나 채울 셀의 값을 지웁니다.
4. 변경 미리보기를 눌러 성명·칼럼·변경 전·변경 후를 확인한 뒤 변경 저장을 누릅니다. 입력을 바꾸면 다시 미리보기를 눌러야 합니다.

완전 일치와 부분 일치의 차이

찾을 내용을 분당초, 바꿀 내용을 분당초등학교로 입력한 예입니다.

기존 셀 값 | 완전 일치 | 부분 일치
분당초 | 분당초등학교 | 분당초등학교
분당초 3학년 | 변경 없음 | 분당초등학교 3학년

대소문자와 공백을 구분하며, 부분 일치는 셀 안에서 일치하는 모든 부분을 바꿉니다. 부분 일치에서는 찾을 내용을 비울 수 없습니다. 같은 값으로 채우기는 찾을 내용과 관계없이 선택한 셀 전체를 입력한 값으로 채웁니다.

가구 공용 칼럼은 공용 예외를 제외한 같은 가구원에게 별도 확인창 없이 자동 반영됩니다. 미리보기의 함께 반영 행에서 확인할 수 있습니다. 개인별 중식 시작일·종료일은 해당 사람에게만 적용됩니다. 식종은 기존 식종 우클릭 메뉴를 사용하며, 숨긴 셀과 읽기 전용 칼럼은 대상에서 제외합니다.

숫자·날짜·선택 목록·칼럼 입력 제한을 검사합니다. 잘못된 값이나 서로 다른 가구 공용 값이 있으면 모두 저장하지 않으므로 내용을 고쳐 다시 미리보세요. 변경은 한 번의 이력과 자동 백업으로 저장합니다. 취소하거나 바뀌는 값이 없으면 기존 명단을 유지합니다.

잘못 등록한 대상자 삭제

1. 대상자의 이름·학교·연락처를 확인합니다.
2. 그 사람의 셀을 우클릭해 명단 행 삭제를 선택합니다.
3. 확인창에서 삭제할 사람이 맞는지 읽고 삭제를 누릅니다. 잘못 선택했으면 취소합니다.

삭제하면 현재 표시된 식종만이 아니라 그 사람의 모든 식종 가입·가구 연결·배송 배정이 현재 명단에서 제거됩니다. 이전 이력은 보존됩니다. 잠시 쉬거나 배송을 그만두는 경우에는 행 삭제 대신 일시중지·중지를 사용하세요.

정보 수정에서 기존 값이 있는 칸을 비우면 삭제 예정 안내와 최종 확인을 거칩니다. 반면 명단 불러오기의 빈칸은 기존 값을 유지합니다.

S034 · 개인별 배송요일·형태 변경
============================================================
개인별 배송요일·형태 변경

여는 위치 · 대상자 선택 → 오른쪽 배송 설정

1. 설정할 식종에서 식사를 제공할 요일과 실제 배송할 요일을 확인합니다.
2. 필요한 요일·배송 형태를 바꿉니다. 예: 조식 금·토·일분을 금요일에 묶어 배송. 배송 형태는 기존 항목을 선택하거나 직접 입력할 수 있습니다. 새 형태를 추가하려면 입력칸에 BOX처럼 원하는 이름을 입력합니다. 기본 형태로 되돌리려면 배송 형태 입력칸을 비웁니다.
3. 같은 가구 전체를 바꿀 때만 같은 가구 전체에 배송 설정 적용을 체크합니다.
4. 변경 저장을 누릅니다. 명단의 별도 설정만을 체크하면 기본값과 다른 사람을 찾을 수 있습니다.

기본값으로 되돌릴 때는 식종별 초기화 또는 전체 초기화를 사용합니다. 전체 명단의 공통 요일은 설정 → 식종별 배송 기본값에서 바꿉니다.

S035 · 기사 등록·담당 변경·배송순서
============================================================
기사 등록·담당 변경·배송순서

여는 위치 · 더보기 → 기사·배송

할 일 | 방법
기사 등록·연락처 수정 | 기사 관리에서 기사를 추가하거나 선택한 기사의 연락처를 수정합니다.
기사 표시 순서 | 기사 관리에서 행을 드래그한 뒤 순서 저장을 누릅니다. 식종별 순서를 따로 저장하지 않은 일일식수에도 적용됩니다.
일일식수 식종별 기사 순서 | 기사 관리 → 일일식수 기사 순서에서 석식·조식·중식 목록을 각각 드래그합니다. 다른 식종에 순서를 복사할 수도 있으며, 저장을 눌러 적용합니다.

배송순서관리에서 검색·필터로 일부만 보고 옮기면 보이는 행들의 자리 안에서 순서가 바뀝니다. 가려진 행은 제자리를 유지합니다. 명단의 열 제목을 눌러 정렬하는 것은 화면 조회 순서이며, 배송순서 변경과 구분합니다.

기사 등록·일괄 교체 순서

기사 관리에서 이름·전화번호를 입력하고 새 기사 등록을 누릅니다. 기존 기사를 고쳐 쓰려면 목록에서 선택한 뒤 값을 고치고 선택 기사 수정을 누릅니다. 이름이 같은 기사는 전화번호까지 확인합니다.

배정 일괄 교체에서는 적용 시작일·기존 기사·새 기사·변경할 식종을 정하고 변경 대상 수를 확인한 뒤 일괄 교체 저장을 누릅니다. 기사 목록의 순서를 바꾸던 중이면 먼저 순서 저장을 해야 다른 순서 설정이나 일괄 교체를 열 수 있습니다.

배송순서 수정

메인 명단의 순서 칼럼은 조회용입니다. 더블클릭이나 우클릭으로 수정할 수 없습니다. 배송순서관리에서 기사와 식종을 고른 뒤 행을 원하는 위치로 끌어 놓으면 즉시 저장됩니다.

S036 · 기사별 중식 시작일·종료일 Excel 내보내기
============================================================
기사별 중식 시작일·종료일 Excel 내보내기

여는 위치 · 더보기 → 기사·배송 → 기사 관리 → 중식 기간 Excel 내보내기

1. 중식 기간 Excel 내보내기를 누릅니다. 학교 일정이 없으면 운영 일정에서 먼저 불러와 저장합니다.
2. 조회 시작일과 조회 종료일을 확인합니다. 처음에는 명단 조회일과 가까운 학교 일정 범위를 제안하며, 필요한 방학이나 조회 기간으로 바꿀 수 있습니다.
3. Excel 내보내기를 누르고 저장 위치와 파일 이름을 정합니다. 생성 Excel 공통 비밀번호를 사용하며, 같은 파일이 있으면 덮어쓸지 확인합니다.
4. Excel 파일을 열어 배송기사 / 중식 시작일 / 중식 종료일을 확인합니다. 학교명이나 대상자 정보는 출력하지 않습니다.

저장된 전체 명단에서 선택 기간의 중식 배송대상을 계산합니다. 담당 대상자의 학교 일정·학년 예외, 식종 가입·중지·일시중지, 배송요일·휴무·대체식과 날짜별 기사 배정을 반영해 기사별 첫 배송일과 마지막 배송일을 표시합니다. 담당 대상자가 없는 학교는 기간을 늘리지 않습니다. 명단 검색·필터나 기사 관리의 선택 행으로 범위를 제한하지 않습니다.

학교 일정이 없거나 검토 범위 밖인 날짜는 제외합니다. 등록 기사는 저장된 순서로 표시하고, 계산된 중식 배송이 없으면 날짜를 -로 표시합니다. 기존 이름만 있는 기사와 담당 미지정 배송은 별도 행으로 표시합니다. 시작일과 종료일 사이에 배송이 없는 날이 있을 수 있습니다.

내보내기는 저장된 기사 정보와 순서를 사용합니다. 기사 관리에서 아직 입력·수정 중인 내용은 그대로 남으며 자동 저장하지 않습니다. 취소하면 파일을 만들지 않고 명단·기사 배정·학교 일정도 바꾸지 않습니다.

S037 · 학교 일정·휴무·단가
============================================================
학교 일정·휴무·단가

여는 위치 · 더보기 → 운영·설정 → 운영 일정

1. 중식 일정은 학교 일정에서 학교와 기간을 확인하고 입력하거나 Excel에서 가져옵니다.
2. 쉬는 날은 휴무·공휴일에서 정상 운영·미제공·대체식 여부를 확인하고 저장합니다.
3. 단가가 바뀌면 더보기 → 운영·설정 → 단가 관리에서 식종별 금액과 적용일을 정합니다.

청구서·확인서와 급식 일일식수·배송목록의 중식 계산에는 저장된 학교 일정이 필요합니다. 일정이 없거나 저장 범위 밖인 학교·날짜의 중식은 식수와 문서에서 제외하고, 일정이 있는 중식과 조식·석식은 계속 계산합니다. 문서 완료 화면에서 제외 내역을 확인할 수 있습니다. 식수가 빠졌을 때는 개인 중식 시작일·종료일, 가입·상태와 학교 일정을 확인하고, 일정을 저장한 뒤 문서를 다시 만드세요. 행복도시락 일일식수·배송목록은 학교 일정과 관계없이 선택일의 가입·상태로 인원을 표시합니다.

공휴일은 후보를 검토해 저장하기 전까지 자동으로 제외되지 않습니다. 배송일을 미제공으로 정하면 그날 묶어 배송할 식사도 함께 제외되므로 날짜와 식종을 확인합니다.

설정 → 배송·식수 → 식수·청구서 설정의 이번 달에 묶어 배송하는 다음 달 식수 포함을 켜면 청구서·확인서를 실제 배송일 기준으로, 끄면 식사일 기준으로 계산합니다. 급식 일일식수는 선택한 실제 배송일 범위의 식수를, 행복도시락 일일식수는 선택일의 가입·상태에 따른 인원을 표시합니다.

학교 일정 파일 불러오기

1. 운영 일정 → 학교 일정을 엽니다. 저장된 일정이 있으면 다음 방학 일정 추가를 누릅니다.

2. 파일을 선택하고 학교명 · 방학식 · 방학식 급식 제공 여부 · 개학식 · 개학식 급식 제공 여부 열을 연결합니다. 비고 열은 선택 사항입니다. 기본 파일은 2행이 제목, 3행부터 학교 자료입니다.

3. 방학식 급식 제공으로 판단할 값과 개학식 급식 제공으로 판단할 값을 입력합니다. 기본값은 O이며 파일에 맞춰 ‘제공’, ‘급식 실시’, ‘○’ 등으로 바꿀 수 있습니다. 두 날짜에 서로 다른 값을 지정할 수 있습니다.

4. 선택한 열로 다시 읽기로 결과를 확인합니다. 미리보기의 제공 여부는 ○ / × 기호입니다. 앞뒤 공백을 제외하고 입력한 문자열과 정확히 같으면 제공, 다르거나 빈 칸이면 미제공입니다. 대소문자와 서로 다른 기호는 구분합니다. ‘제공’은 학교에서 급식을 준다는 뜻이며 그날 센터 중식은 제외됩니다.

5. 학교 일정 저장을 누릅니다. 별도의 학교별 일정 검토창 없이 현재 열 연결과 판정 값으로 다시 읽어 저장합니다. 날짜 오류나 서로 충돌하는 일정은 수정해야 저장할 수 있습니다. 저장하면 전체 명단의 기존 중식 대상과 개인 중식 시작일·종료일을 초기화합니다. 이번 파일에서 가장 이른 방학식 날짜부터 기존 중식 가입을 해제하며, 그 이전의 가입·식수 기록과 변경 이력, 조식·석식은 보존합니다. 파일에 없는 학교의 기존 중식 대상도 초기화됩니다. 같은 파일을 다시 저장해도 초기화되므로 안내된 날짜를 확인하세요.
6. 저장 후 방학 중식 대상자 갱신에서 방금 저장한 방학 기록을 선택하고 중식 명단을 불러옵니다. 명단을 불러오기 전에는 새 기간의 중식 대상이 없습니다. 명단 반영 뒤 개인 중식 날짜와 해당 기간의 인원을 확인하세요.

방학 기록 누적·학교 검색

1. 다음 방학 파일은 다음 방학 일정 추가로 이어서 불러옵니다. 같은 학교·같은 달이라도 방학식~개학식 밖의 기존 일정은 남고, 겹치는 날짜는 나중에 불러온 일정이 우선합니다. 한 파일 안에서 같은 학교의 날짜가 겹치면 뒤쪽 행이 우선합니다.

2. 위쪽 불러온 방학에서 기간·파일 이름·변경번호를 보고 원하는 기록을 선택합니다. 처음에는 가장 최근에 불러온 기록이 선택됩니다.

3. 왼쪽 학교 이름 검색에 학교명의 일부를 입력합니다. 공백을 넣거나 빼도 검색되며 선택한 기록에 있는 학교만 표시합니다.

4. 학교를 선택하면 센터 중식 시작일·종료일을 방학별 한 행으로 확인할 수 있습니다. 표에는 날짜별 학년 예외와 실제 중식 일수도 표시합니다.

5. 불러온 원본 보기는 불러올 당시의 학교별 날짜·제공 여부·비고와 저장 시각을 보여줍니다. 이후 직접 수정한 값은 현재 일정 표에 표시됩니다. 방학 선택과 검색만으로 저장 자료가 바뀌지는 않습니다.

불러온 일정 한 번분 전체 삭제

1. 불러온 방학에서 삭제할 기간·파일·변경번호를 선택합니다.
2. 선택한 불러오기 전체 삭제를 누릅니다. 이 파일에서 불러온 모든 학교가 대상입니다. 검색 결과나 선택한 학교만 삭제하는 기능이 아닙니다.
3. 확인창의 파일과 학교 수를 확인하고 삭제합니다. 수정 중인 내용이 있으면 먼저 저장하거나 창을 닫고 다시 여세요.

다른 불러오기 기록은 남고, 겹쳤던 날짜는 남은 기록의 일정으로 돌아갑니다. 남아 있는 일정에 직접 수정한 내용도 유지합니다. 삭제한 파일만 있던 학교는 목록에서 사라집니다. 일정 파일을 삭제해도 초기화한 중식 대상과 개인 날짜가 다시 살아나지는 않습니다. 초기화 전 명단까지 되돌리려면 이전 자료로 되돌리기에서 일정 불러오기 전 변경번호를 선택합니다. 구버전에서 날짜만 자동으로 채운 기록은 이후 수정하지 않았을 때 해당 날짜가 이전 값으로 돌아갈 수 있습니다.

삭제도 새 변경 기록으로 저장하므로 이전 자료로 되돌리기에서 삭제 전 변경번호로 복구할 수 있습니다. 일정 불러오기 전으로 되돌렸더라도 같은 학교 파일을 다시 불러올 수 있습니다. 원래 불러온 기록은 전체 변경 이력에 보관되며 현재 방학 선택 목록에서는 제외됩니다.

날짜와 제공 여부 예시

예를 들어 2027-07-22 / x / 2027-08-18 / O를 제공 판정 값 O로 읽으면, 방학식은 미제공·개학식은 제공이므로 센터 중식 기간은 7월 22일~8월 17일입니다. 방학식과 개학식 사이의 평일이 센터 중식 대상이며 주말·휴무·개인별 상태는 실제 배송 계산에서 추가로 반영합니다.

전체 저장 기간에서도 실제 센터 중식 기간만 보여줍니다. 파일에 없던 월초 구간이나 학교 급식 제공일은 표시하지 않습니다. 제공 여부·중식 처리 칼럼도 없으며, 원본의 제공 여부는 불러온 원본 보기에서 ○ / × 기호로 확인합니다.

비고와 학년별 급식 차이

비고는 원본의 특이사항을 참고 기록으로 남기는 열입니다. ‘6학년 미급식’처럼 적혀 있어도 자동으로 날짜나 학년 조건을 만들지 않습니다. 비고 열을 연결하지 않아도 학교 일정을 저장할 수 있습니다.

학년별 차이는 특정 날짜 하루에 지정합니다. 방학식에 6학년만 학교 급식을 못 받으면 그 날짜를 고르고 6학년을 체크합니다. 6학년만 학교에서 먹으면 1~5학년을 체크합니다. 체크한 학년만 그날 센터 중식 대상이며 개인별 가입·배송 상태도 함께 적용합니다.

저장한 학교 일정 직접 고치기

1. 학교와 방학 행을 선택합니다. 중식 시작일·종료일을 수정하고 수정 내용을 표에 반영을 누릅니다. 다른 기간을 추가할 때는 중식 기간 추가를 사용합니다.

2. 학년 예외는 기간 입력과 별개입니다. 학년 예외 날짜에서 평일 하루를 고르고 이 날짜에 중식 받을 학년을 체크한 뒤 선택 날짜에 학년 예외 반영을 누릅니다. 선택한 날짜만 바뀌며 다른 날짜에는 적용하지 않습니다. 모두 해제해 반영하면 그날은 중식에서 제외됩니다.

3. 초등학교는 1~6학년, 중·고등학교는 1~3학년, 이름으로 구분되지 않는 학교는 1~6학년을 선택할 수 있습니다. 날짜를 바꾸면 그 날짜에 저장된 예외가 표시됩니다.

4. 변경 일정 저장을 눌러 확정합니다. 표에 반영만 하면 운영 데이터는 바뀌지 않습니다. 이 학교 원래대로로 저장 전 수정을 되돌릴 수 있습니다.

학교 일정 화면에서 날짜·학년 예외를 직접 수정하는 것은 중식 대상 초기화를 하지 않습니다. Excel 파일을 다시 불러와 저장하면 중식 대상이 초기화되고 이번 파일의 일정 범위를 새 값으로 반영하므로, 중식 명단을 다시 불러오고 해당 범위의 학년 예외도 확인하세요.

공휴일·자체 휴무·대체 배송 등록

1. 운영 일정 → 휴무·공휴일에서 연도를 고르고 검토할 날짜를 체크합니다. 필요하면 미검토 전체 선택을 누릅니다.
2. 적용할 식종과 정상 운영·미제공·대체식을 선택합니다. 미제공은 해당 식수를 청구에서 제외하며 대체식은 원래 식사일의 청구를 유지하고 실제 제공일을 바꿉니다.
3. 대체식은 제안된 날짜를 확인하고 날짜·식종별 실제 제공일을 수정합니다.
4. 공휴일이 아닌 휴무는 공휴일 아닌 휴무 직접 추가에서 기간을 정합니다. 여러 날짜의 대체식을 나누어 제공하려면 날짜별로 다르게 지정을 사용합니다.
5. 대상 기간·식종·실제 제공일을 확인해 저장하고 새 문서를 만들어 확인합니다.

S038 · 배송순서관리
============================================================
배송순서관리

중식 기간 표시 체크 하나로 중식 시작일·종료일을 함께 보이거나 숨깁니다. 선택은 다음에 창을 열어도 유지됩니다. 같은 가구의 날짜가 다르면 이름과 날짜를 줄바꿈으로 구분하며, 두 Excel 내보내기에도 중식 기간 표시 여부를 반영합니다. 날짜 수정은 명단의 중식 시작일·종료일 칼럼 [참고: S017 · 대상자별 중식 시작일·종료일]에서 합니다.

왼쪽 배송순서는 명단 원본에 저장된 번호입니다. 검색·필터·식종 선택으로 일부 행을 숨겨도 번호를 바꾸지 않습니다. 합친 행의 식종별 번호가 다르면 식종 이름과 번호를 함께 표시합니다. 행을 드래그해 저장하면 원본 명단에도 같은 번호가 반영됩니다.

여는 위치 · 더보기 → 기사·배송 → 배송순서관리

1. 위쪽에서 기사를 선택하고 전체 식종 또는 석식·조식·중식을 고릅니다.
2. 명단에서 옮길 행을 누른 채 원하는 자리로 끌어 놓습니다. 변경한 순서가 저장됩니다.
3. 같은 가구를 식종별로 나눠 볼 때는 식종별 분리, 다시 합칠 때는 분리 해제를 사용합니다.
4. 선택한 기사·식종으로 배송 문서를 새로 만들어 순서를 확인합니다.

필터가 걸려 있으면 보이는 행들의 기존 자리 안에서 순서가 바뀝니다. 모든 행을 보려면 전체 필터 해제를 누릅니다.

식종별 분리와 분리 해제는 화면에 보이는 행만 바꿉니다. 가구를 나누거나 배정을 변경하지 않습니다. 숨긴 명단 포함을 켜면 중지·현재 상태가 없는 식종과 장기 미배송 대상자도 조회합니다.

기사별 명단을 Excel로 보내기

Excel 내보내기는 현재 선택한 기사와 화면에 보이는 행·칼럼·필터·분리 상태를 저장합니다. 기사·식종별 Excel 내보내기는 선택한 기사의 자료를 기사-식종별 시트로 나누고 배송순서로 정렬합니다. 이 방식은 열 검색·값 필터·분리 표시를 무시하지만 숨긴 명단 포함 여부는 반영합니다. 파일은 생성 Excel 공통 비밀번호를 사용합니다.

S039 · 단가 관리
============================================================
단가 관리

여는 위치 · 더보기 → 운영·설정 → 단가 관리

1. 현재 단가와 적용 기간을 확인합니다.
2. 변경할 식종을 체크하고 새 단가와 적용일을 입력합니다. 여러 식종을 체크하면 같은 금액을 함께 적용합니다.
3. 단가 변경 저장을 누릅니다. 청구서를 다시 만들어 변경한 날짜 전후의 금액을 확인합니다.

같은 달 안에서 단가가 달라지면 각 제공일에 적용되는 단가로 계산합니다. 이미 만든 Excel 파일은 다시 계산되지 않습니다.

S040 · 월별 조회·민원·전체 변경 이력
============================================================
월별 조회·민원·전체 변경 이력

원하는 연월과 탭을 선택한 뒤 현재 탭 Excel 내보내기를 누르고 저장 위치를 고릅니다. 식수는 선택한 배송일·식사일 기준과 월 합계를, 식종 변경은 현재 필터로 보이는 기록을 정렬된 순서대로 저장합니다. 생성 Excel 공통 비밀번호를 사용합니다. 조회 실패 시에는 내보낼 수 없습니다.

식종 변경 탭의 접수 경로·비고 셀을 더블클릭하거나 기록을 우클릭해 접수 경로·비고 수정을 선택합니다. 현재 값을 고쳐 저장하면 개인 이력과 월별 이력에 반영됩니다. 배송 상태·기간은 바뀌지 않으며 원본과 수정 내용은 전체 변경 이력에 남습니다.

할 일 | 여는 위치·방법
월별 식수 확인 | 더보기 → 조회·기록 → 월별 조회 → 식수 탭. 연월을 정해 일별 식수와 월 합계를 확인합니다.
월별 상태 변경 확인 | 같은 창의 식종 변경 탭. 열 제목 옆 필터로 이름·식종·접수 경로 등을 좁혀 봅니다.
민원 기록 | 대상자 칸 우클릭 → 민원. 접수 경로와 내용을 입력해 저장합니다.
개인 민원·변경 내용 | 대상자 칸 우클릭 → 이력보기. 정보 변경·식종 변경·민원 탭에서 확인합니다.
전체 민원 | 더보기 → 조회·기록 → 전체 민원.
전체 저장 기록 | 더보기 → 조회·기록 → 전체 변경 이력. 변경번호·사유·변경자로 찾고 선택한 기록의 내용을 확인합니다.

월별 조회는 현재 명단의 검색·필터와 관계없이 전체 자료를 읽습니다. 종료일 없는 배송·중지는 시작한 달에 나오고, 기간이 있는 일시중지는 기간이 겹치는 달에 나옵니다.

월별 조회의 식수 탭에서 실제 배송일 기준 (나가는 날)과 식사일 기준을 바꿔 볼 수 있습니다. 예를 들어 10월 30일에 나가는 11월 1일 조식은 배송일 보기에서는 10월, 식사일 보기에서는 11월에 집계합니다. 이 화면의 보기 선택은 청구서 설정을 바꾸지 않습니다.

S041 · 명단 불러오기

명단 불러오기

문서 사용 표시는 청구서·확인서·일일식수·배송목록의 기본 연결과 사용자가 저장한 1·2순위 연결, 일일식수 추가 비고 및 현재 배송목록 양식의 플레이스홀더 연결을 반영합니다. 배송목록은 실제 출력에 체크한 칼럼과 그 칼럼의 우선 연결만 포함합니다. 체크를 해제한 칼럼이라도 다른 문서에서 사용하면 표시를 유지합니다. 원본 Excel 열까지 연결되었다는 뜻은 아니므로 타일 연결도 확인하세요.

제목 옆에 청록색 (가구 묶기 기준)이 붙은 칼럼은 필수 연결입니다. 설정에서 고른 기준 칼럼 모두에 원본 Excel 열을 연결해야 연결 확인과 불러오기를 완료할 수 있습니다. 기본 기준은 핸드폰이며, 기준이 여러 개이면 전부 연결합니다. 개별 행의 기준값이 비어 있으면 다른 사람과 자동으로 묶지 않습니다.

여는 위치 · 더보기 → 명단·파일 → 명단 불러오기

불일치 비교표를 Excel로 저장할 예정이라면 명단 불러오기를 시작하기 전에 설정 → 문서 → 생성 Excel 비밀번호 [참고: S054 · 생성 Excel 비밀번호]에서 공통 Excel 비밀번호가 설정되어 있는지 확인하고, 없으면 먼저 지정하세요.

1. Excel 파일을 선택합니다. 비밀번호가 있으면 열기 비밀번호를 입력합니다. 기본 헤더 직접 선택에서 시트를 고르고 원본 미리보기의 제목 행이나 왼쪽 행 번호를 클릭합니다. 선택한 행은 파란색과 헤더 표시로 구분됩니다. 헤더 범위의 기본값은 두 행 · 병합 헤더입니다. 두 행짜리 제목의 첫 행을 클릭하세요. 제목이 한 행인 파일은 헤더 범위 → 한 행으로 바꿉니다. 새 파일을 선택하면 다시 두 행이 기본으로 선택됩니다. 데이터는 헤더 마지막 행 바로 아래부터 읽습니다. 원하는 행이 보이지 않으면 헤더 시작 행에 번호를 입력합니다. Excel 표의 정해진 범위를 읽으려면 자동 · Excel 표 우선을 선택하고 표 미리보기를 누릅니다.

2. 기존 명단을 갱신할 때는 불러오기 방식에서 일반 명단 반영 또는 방학 중식 대상자 갱신을 선택합니다. 처음 명단을 넣을 때는 이 선택이 없습니다.

3. 열 연결 확인하기를 엽니다. 기존 DB에 일반 명단이나 중식 명단을 불러올 때는 모든 Excel 칼럼이 미연결 상태로 시작합니다. 같은 이름의 칼럼이나 이전에 저장한 연결도 자동으로 넣지 않습니다. 원본 Excel 타일을 해당 칼럼 자리로 끌거나, 타일을 선택한 뒤 연결할 자리를 누릅니다.

4. 일반 명단 반영에서는 문서에 사용하는 칼럼 → 식종 → 나머지 칼럼 순서로 확인하고 식종도 직접 연결합니다. 방학 중식 대상자 갱신에서는 식종 연결 구역이 없으며, 가져올 행 조건에 포함된 사람을 중식 대상으로 반영합니다. 최초 DB 생성은 기존처럼 자동 열 연결과 식종 입력을 사용합니다.

5. 가져오지 않을 타일은 아래의 아직 연결하지 않은 엑셀 칼럼 · 가져오지 않음에 둡니다. 새 문자 칼럼이 필요하면 새 DB 칼럼 추가 (문자)에 놓습니다. 도로명주소는 원본 열 하나를 연결합니다.

6. 연결 확인 완료를 누르고 일반 명단은 적용일, 중식 명단은 방학 기록과 가져올 행 조건을 확인한 뒤 불러오기를 누릅니다. 최초 명단은 이번 달 1일을 기본으로 제안하므로 실제 시작일에 맞춥니다.

7. 오류가 있으면 정정표에서 값을 고치거나 행 제외를 체크하고 수정·제외 적용 후 불러오기를 누릅니다. 같은 원본 행의 여러 오류는 함께 제외됩니다. 원본 Excel 파일은 바뀌지 않습니다.

8. 기존 값과 충돌하면 항목별로 가져온 값 사용 또는 기존 값 유지를 고릅니다. 일부 사람만 다르게 반영하려면 사람별 예외 보기를 펼쳐 값을 고르거나 직접 수정합니다. 사람 연결이 모호할 때는 기존 대상자에 반영할지 새 대상자로 등록할지 정합니다. 일반 명단 반영에서는 이 행 제외도 선택할 수 있습니다.

9. 완료 후 적용일의 명단을 확인합니다. 오류나 확인할 충돌이 없으면 별도의 마지막 전체 명단 확인 없이 저장됩니다.

원본 빈칸은 기존 값을 유지하며, 기존에 비어 있던 값은 채웁니다. 학교·학년은 높은 학교 단계와 학년을 자동으로 선택하되 판단할 수 없는 값은 확인합니다. 같은 학교의 약칭과 정식 명칭이 함께 있으면 성남중보다 성남중학교를 사용합니다. 초/초등학교, 고/고등학교도 같으며, 학년은 별도로 높은 값을 유지합니다. 가구는 설정의 가구 묶기 기준에서 선택한 모든 칼럼이 일치할 때 묶습니다. 기본은 핸드폰이며 선택한 값에 빈칸이 있으면 묶지 않습니다.

사람별 예외로 다른 값 반영하기

1. 다른 값 처리에서 항목별 반영 방향을 먼저 고릅니다. 가져온 값 사용 또는 기존 값 유지를 선택하면 해당 항목의 사람들에게 일괄 적용됩니다.

2. 일부 사람만 다르게 처리하려면 해당 항목의 사람별 예외 보기를 누릅니다. 아래 표에는 이미 예외로 정한 사람만이 아니라 그 항목에서 값이 다른 모든 사람이 표시됩니다.

3. 예외로 처리할 사람의 기존 값 또는 가져온 값 셀을 누르거나 반영할 값을 직접 수정합니다. 여러 사람을 선택한 뒤 선택한 사람: 기존 값 또는 선택한 사람: 가져온 값을 사용할 수도 있습니다.

4. 예외를 되돌리려면 해당 사람을 선택하고 예외 해제를 누릅니다. 먼저 정한 항목별 반영 방향으로 돌아갑니다. 반영 방향을 정하지 않았다면 다시 선택이 필요합니다.

5. 항목별 미선택 건수가 남아 있지 않은지 확인하고 선택한 값으로 불러오기를 누릅니다. 추가 확인창이 나오면 계속 확인한 뒤 적용일의 명단을 확인합니다.

예외 수정 후 항목별 반영 방향을 다시 고르거나 모두 가져온 값 사용·모두 기존 값 유지를 누르면 해당 범위의 예외도 일괄 선택으로 바뀝니다. 먼저 일괄 방향을 정한 다음 예외를 수정하세요. 접기는 표만 접으며 선택한 내용을 지우지 않습니다.

불일치 항목을 Excel로 내보내기

검토 중 비밀번호 미설정 안내가 나오면 필요한 선택·입력 내용을 복사해 둔 뒤 검토창을 취소하고, 생성 Excel 비밀번호 [참고: S054 · 생성 Excel 비밀번호]를 설정한 다음 명단 불러오기를 처음부터 다시 시작하세요. 검토창을 열어 둔 채 비밀번호를 설정한 경우에도 다시 시작해야 합니다. 비밀번호 저장으로 변경번호가 달라지면 기존 검토창에서는 불러오기를 완료할 수 없으며, 반영 방향과 사람별 예외를 다시 선택해야 합니다.

1. 일반 명단 또는 방학 중식의 다른 값 처리 화면에서 불일치 Excel 내보내기를 누릅니다. 반영 방향을 아직 선택하지 않아도 저장할 수 있습니다.
2. 저장할 위치와 파일 이름을 정합니다. 기존 파일과 이름이 같으면 덮어쓸지 확인합니다. 파일에는 미리 설정한 공통 Excel 비밀번호가 적용됩니다.
3. Excel의 불일치 시트에서 원본 파일·시트·원본 행번호·이름·핸드폰·세대주명으로 사람을 찾습니다. 오른쪽의 DB_항목 / 명단_항목을 비교합니다. 다른 값 쌍은 노란색이며, 그 사람에게 불일치가 없는 항목 쌍은 비어 있습니다.
4. 검토 도중 비밀번호 등 설정을 바꾸지 않았고 몇 건만 고칠 때는 열린 검토창에서 가져온 값 사용·기존 값 유지·사람별 예외 보기를 사용해 직접 수정하고 계속 불러옵니다. 내보내기는 현재 선택이나 입력을 지우지 않습니다.
5. 원본 명단을 고칠 때는 검토창에서 취소한 뒤 원본 Excel을 수정하고 명단을 다시 불러옵니다. 비교표는 확인용이며 원본 명단을 대신해 불러오는 파일은 아닙니다.

펼쳐 놓은 항목에 한정하지 않고 검토창의 전체 불일치를 저장합니다. 같은 값·자동 처리 항목·신규 대상자는 제외합니다. GUI에서 직접 수정한 반영 예정값은 비교표의 DB 값·원본 값을 바꾸지 않습니다. 내보내기만으로 운영 DB나 변경 이력을 저장하지 않으며, 저장 취소나 실패 후에도 검토를 계속할 수 있습니다.

동명이인·핸드폰 변경 확인하기

일반 명단과 방학 중식 명단 모두 이름과 빈칸이 아닌 핸드폰이 일치하는 기존 대상자가 한 명이고 원본에 같은 이름·핸드폰의 중복 행이 없으면 그 사람에게 자동 연결합니다. 핸드폰의 하이픈·공백은 구분하지 않습니다. 다른 번호를 쓰는 동명이인이 있어도 정확히 일치하는 사람을 우선합니다.

자동 연결되지 않은 행은 이름과 세대주명이 같으면 핸드폰이 다르거나 없어도 동일인 의심 대상으로 표시합니다. 이름·세대주명은 공백을 구분하지 않으며 빈 세대주명끼리는 일치로 보지 않습니다. 원본 안에서 이름·세대주명이 중복된 행도 확인합니다. 표에는 성명·핸드폰·세대주명과 이번에 연결한 모든 칼럼이 표시됩니다. 학교·주소·사용자 칼럼뿐 아니라 연결한 식종·배송담당·배송순서도 확인할 수 있습니다. 연결한 칼럼에 값이 없으면 미입력으로 표시합니다. 아래 가로 스크롤을 움직여 나머지 칼럼과 오른쪽의 확인 사유·행 반영 방법을 확인하고 기존 후보의 정보와 비교하세요. 칼럼 제목에 마우스를 올리면 연결한 원본 열을 확인할 수 있습니다.

확인 행을 모두 다른 사람으로 넣으려면 확인 행 모두 신규 등록을 누릅니다. 표에 표시된 모든 행이 새 대상자로 등록으로 바뀌며, 이름·핸드폰이 같아 자동 연결된 행은 유지합니다. 필요한 행은 개별 선택을 다시 바꾼 뒤 선택한 내용으로 불러오기를 누릅니다. 필요한 가구 선택이 남아 있으면 먼저 선택해야 합니다. 취소하면 저장하지 않습니다. 사람을 새로 등록해도 가구는 저장된 가구 묶기 기준을 따릅니다.

방학 중식에서는 신규로 선택한 행을 별개의 사람으로 등록합니다. 이번 파일에 연결되지 않은 기존 대상자는 그대로 유지합니다. 같은 사람이면 기존 대상자에 연결해 중복 등록을 피하세요.

방학 중식에서 이름은 같지만 핸드폰이 다르면 번호가 바뀐 같은 사람인지 별개의 동명이인인지 확인합니다. 행 반영 방법에서 같은 사람이면 이름·핸드폰·학교를 확인해 기존 대상자에 반영, 다른 사람이면 새 대상자로 등록을 선택합니다. 후보가 보인다는 것만으로 자동 연결된 상태는 아닙니다. 선택한 내용으로 불러오기를 누른 뒤 서로 다른 값이 있으면 다음 화면에서 반영할 값을 정합니다.

방학 중식에서 핸드폰이 없거나 같은 이름·핸드폰이 원본 또는 기존 명단에 중복되어 있으면 추가 확인이 필요합니다. 일반 명단은 이름·핸드폰으로 연결되지 않을 때 생년월일도 확인합니다. 사람 연결은 기존 누구의 정보를 갱신할지 정하는 과정이고, 가구 묶기 기준 [참고: S070 · 가구 묶기 기준]은 어떤 사람들을 한 가구로 묶을지 정하는 별도 설정입니다.

방학 중식 대상자 갱신

1. 먼저 운영 일정 → 학교 일정 [참고: S037 · 학교 일정·휴무·단가]에서 방학 일정 파일을 불러와 저장합니다.
2. 명단 불러오기에서 방학 중식 대상자 갱신을 선택하고 명단 파일을 읽습니다.
3. 열 연결 단계의 적용할 방학 기록에서 기간·파일명·변경번호를 확인해 해당 방학을 선택합니다. 최근 기록이 먼저 표시됩니다.
4. 기존 대상자는 항상 업데이트로 처리합니다. 가져온 값과 기존 값이 다르면 검토창에서 반영할 값을 고르고, 선택한 방학의 학교·학년별 중식 기간을 적용합니다. 해당 방학에 미등록인 사람과 신규 대상자도 추가합니다.
5. 열 연결을 확인하고 불러오기를 누릅니다. 2차·3차 명단도 같은 방학을 골라 반복하면 됩니다.

각 사람은 선택한 기록 안의 학교·학년별 중식 시작일·종료일에만 등록됩니다. 학교 일정이 선택 기록에 없거나 해당 학년의 중식 제공일이 없으면 학교명과 일정·학년 예외를 먼저 확인하세요. 이번 명단에서 빠진 사람은 그대로 유지하므로 별도로 비활성화할 필요가 없습니다. 다른 방학의 등록 기간과 조식·석식도 유지합니다.

저장 뒤 명단의 중식 날짜 칼럼 [참고: S017 · 대상자별 중식 시작일·종료일]에서 사람별로 수정할 수 있으며 실제 계산에도 반영됩니다.

가져올 중식 명단에서 전체 명단, 선택한 칼럼에 값이 있는 행, 선택한 칼럼이 특정 값인 행 중 하나를 고릅니다. 전체 명단에서는 조건 입력칸이 나오지 않습니다. 선택한 칼럼에 값이 있는 행에서는 조건 칼럼만, 특정 값인 행에서는 조건 칼럼과 일치할 값을 입력합니다. 값 있음에는 숫자 0도 포함되며 공백뿐인 셀은 제외됩니다. 특정 값은 앞뒤 공백을 제외하고 정확히 같은 값만 선택합니다.

선택된 사람은 고른 방학 기간에만 등록합니다. 파일에 없거나 조건·행 제외로 빠진 기존 대상자는 유지합니다. 조건을 사용하면 저장 전 명단과 제외 건수를 확인하세요. 선택된 사람이 0명이거나 해결하지 않은 오류가 있으면 저장할 수 없습니다.

중식 연결은 이름과 핸드폰 번호를 기준으로 합니다. 조식·석식은 유지합니다. 칼럼 관리의 표시 체크는 화면만 바꾸지만 명단 불러오기는 운영 데이터를 바꿉니다.

장기 미배송 보관함

보관함은 대상자를 삭제하는 기능이 아닙니다. 기본 기준은 연속 미배송 365일입니다.

S043 · 전체 민원
============================================================
전체 민원

여는 위치 · 더보기 → 조회·기록 → 전체 민원

1. 전체 대상자의 민원 목록에서 이름·접수일·내용을 확인합니다.
2. 검색칸에 이름이나 내용의 일부를 입력해 필요한 기록을 찾습니다.
3. 목록에서 기록을 선택하면 아래 선택한 민원 전체 내용에서 긴 내용까지 읽고 복사할 수 있습니다.
4. 새 민원을 남길 때는 명단으로 돌아가 대상자 칸을 우클릭하고 민원에서 접수 경로와 내용을 입력해 저장합니다.

메인 명단에 걸린 검색·필터와 관계없이 전체 민원을 조회합니다. 한 사람의 기록은 대상자의 이력보기 → 민원에서도 볼 수 있습니다.

개별 민원 접수창에서 접수 시각·접수 경로·관련 식종·내용을 확인합니다. 같은 가구원에게도 같은 민원을 남길 때는 같은 가구에도 함께 접수를 선택한 뒤 저장합니다. 민원 접수 자체가 배송 상태를 바꾸지는 않으므로 일시중지나 중지가 필요하면 식종 상태도 별도로 변경하세요.

S045 · 이전 저장 시점 확인·복구
============================================================
이전 저장 시점 확인·복구

여는 위치 · 더보기 → 조회·기록 → 전체 변경 이력

1. 되돌아갈 변경번호를 선택하고 내용을 확인합니다.
2. 이전 자료로 되돌리기를 엽니다.
3. 기본 선택인 현재 자료를 이 시점으로 되돌리기를 그대로 두면 현재 명단과 설정을 선택 시점으로 되돌리고 새 변경 기록을 남깁니다. 기존 변경 이력은 보관합니다.
4. 현재 작업을 남기고 따로 이어가려면 이 시점에서 별도 작업본 만들기를 선택하고 이름을 입력합니다. 같은 운영 파일 안에 별도 작업본을 만듭니다.
5. 확인 내용을 읽고 진행합니다. 완료 후 프로그램을 다시 실행해 상태를 확인합니다.

현재 작업본 복구는 선택한 시점의 명단·상태·운영 설정 전체에 적용됩니다. 한 사람의 잘못된 식종 기록만 고칠 때는 먼저 식종 변경 기록 취소 [참고: S008 · 저장한 내용 확인·잘못 입력한 기록 취소]를 확인하세요.

초기 명단 적용일은 최초 명단의 식종 시작일을 정정할 때 사용합니다. 가구 연결일은 실행 조건이 아니므로 가구 소속 기록 복구를 먼저 할 필요가 없습니다.

변경번호를 복구하면 그 시점 이후에 등록한 식종 변경은 선택 정보·개인 식종 이력·월별 이력·청구서 이력에서 제외됩니다. 원본 기록은 전체 변경 이력에 보존됩니다. 그 기록이 있던 시점으로 다시 복구하면 식종 이력도 다시 보입니다.

작업본 바꾸기와 복구 범위

전체 변경 이력에서 표시할 작업본을 고르는 것은 이력 조회만 바꿉니다. 실제 작업 대상을 바꾸려면 이 작업본으로 전환을 누르고 안내에 따라 종료 후 다시 실행합니다. 새 작업본은 선택한 변경번호의 명단·상태·설정에서 시작하며 기존 작업본의 작업은 남습니다. 작업본끼리 자동으로 합치지는 않습니다.

현재 자료를 이 시점으로 되돌리기는 선택 시점으로 복구한 내용을 새 변경 기록으로 남깁니다. 한 사람의 식종 오류만 고치려면 전체 복구보다 해당 식종 변경 기록 취소를 먼저 확인하세요. 복구·전환으로 이미 만들어 외부에 보낸 Excel이 바뀌지는 않으므로 필요한 문서를 다시 생성합니다.

S046 · 작업 중 막힐 때
============================================================
작업 중 막힐 때

오류 안내는 원인과 다음 행동을 설명합니다. 다른 창에서 자료가 바뀌어 저장하지 못했다면 작업 창을 다시 열어 최신 내용을 확인한 뒤 재입력하세요. 자료와 변경 이력이 맞지 않는다는 안내가 계속되면 운영 파일을 보관한 채 담당자에게 점검을 요청하거나 정상 백업을 복원하세요. 저장 완료 후 백업 실패는 별도로 안내되므로 같은 작업을 중복 저장하지 않도록 현재 저장 상태부터 확인하세요.

화면에서 보이는 문제 | 먼저 확인할 곳
검색한 사람이 안 보임 | 검색어·칼럼 필터를 지우고 숨긴 행 포함을 체크합니다. 보관함을 보고 있다면 나가기를 누릅니다.
상태를 저장했는데 그대로 보임 | 왼쪽 조회 날짜가 변경 시작일 전인지 확인합니다. 개인 식종 변경 이력의 기간도 확인합니다.
선택할 수 없는 날짜 | 기간 옆 실제 배송 요일을 확인합니다. 식종마다 허용되는 요일이 다릅니다.
중식이 - 또는 0식 | 학교 일정의 검토 기간, 해당 학교의 급식일, 가입·상태를 확인합니다.
과거 가구 소속이 없거나 연결일이 늦음 | 가구 연결일 때문에 문서 생성을 막지 않습니다. 소속이 없으면 1인 가구로 처리합니다. 다른 대상자와 묶을 때는 설정 → 가구 묶기 기준을 적용하세요.
파일을 만들 수 없음 | 안내된 대상자의 배송담당, 일정, 문서 양식과 저장 폴더를 확인합니다.
다른 창에서 자료가 바뀌었다는 안내 | 입력한 내용이 필요하면 복사해 둡니다. 창을 취소하고 다시 열어 최신 자료로 수정합니다.
다른 사용자가 사용 중이라는 안내 | 같은 운영 파일을 사용 중인 프로그램이 정상 종료된 뒤 다시 엽니다. 잠금 파일을 임의로 삭제하지 않습니다.

S047 · 전체 민원에서 동일 가구 기준 확인

전체 민원에서 동일 가구 기준 확인

더보기 → 조회·기록 → 전체 민원을 열면 성명 바로 뒤에 현재 저장된 가구 묶기 기준 칼럼이 자동으로 표시됩니다. 기본은 핸드폰이며, 세대주 성명·주소·사용자 칼럼 등 여러 기준을 선택했다면 모두 표시합니다. 성명을 기준으로 선택한 경우 기존 성명 칼럼을 사용합니다.

창 최소화·최대화와 크기 기억

S049 · 중지 시작일로 식종을 미배송 정리
============================================================
중지 시작일로 식종을 미배송 정리

배포 폴더의 meal_stop_cleanup.exe는 앱과 별도로 실행하는 정리 도구입니다. Python을 설치하지 않아도 사용할 수 있습니다. 공통 백업 설정을 읽을 수 있도록 meal_delivery.exe와 같은 폴더에 두세요. 앱 메뉴에서 여는 기능은 아닙니다.

1. 급식 배송 운영 프로그램을 종료하고 meal_stop_cleanup.exe를 실행합니다.
2. 찾을 중지 시작일을 입력합니다. 2026-09-30은 해당 연도의 그 날짜만, 9/30은 모든 연도의 같은 월·일을 찾습니다. 다른 날짜도 입력할 수 있으며 빈칸이면 취소합니다.
3. 운영 파일 경로와 비밀번호를 입력합니다. 파일을 창에 끌어 놓아 경로를 입력해도 됩니다. 비밀번호는 화면에 표시되지 않습니다.
4. 날짜 범위·이름·식종과 되돌릴 변경번호를 확인합니다. 맞으면 정리를 입력합니다. 다른 입력은 취소합니다.
5. 저장 결과와 백업 안내를 확인하고 Enter를 눌러 닫습니다. 기존 앱에서 같은 운영 파일을 다시 열어 확인합니다.

현재 작업본의 과거 중지 기록을 찾으므로 이후 배송을 재개한 사람도 대상이 됩니다. 선택된 사람·식종의 가입 기간과 상태 기록을 현재 자료에서 제거하고 중식이면 개인 중식 기간도 비워, 처음부터 미가입(미배송)으로 처리합니다. 현재 자료로 과거 문서를 다시 계산하는 결과도 바뀌므로 저장 전 대상 목록을 확인하세요.

다른 사람·식종·별도 작업본과 이전 변경번호의 원본은 유지합니다. 기존 운영 파일에 변경 기록 하나를 추가하며 파일 경로·비밀번호·백업 연결은 그대로입니다. 잘못 정리했다면 앱의 이전 자료로 되돌리기에서 정리 직전 변경번호를 선택하세요. 이미 만든 Excel 파일은 바뀌지 않으므로 필요한 문서는 다시 생성합니다.

같은 운영 파일의 공통 설정을 찾으면 기존 자동 백업 폴더에도 저장합니다. 백업 경로를 찾지 못하거나 백업이 실패하면 정리 저장 여부와 구분해서 안내합니다. 오류가 나면 안내된 원인을 해결한 뒤 다시 실행하세요. 예전 9월30일_중지정리.cmd도 이 날짜 입력 방식으로 연결됩니다.

S051 · 문서 양식
============================================================
문서 양식

여는 위치 · 설정 → 문서 → 문서 양식

1. 사용할 급식 또는 행복도시락 양식을 선택합니다.
2. 아래 이 양식 사용을 누릅니다. 문서 만들기에서 선택한 양식으로 파일을 새로 생성합니다.

1. 일일식수·배송목록의 양식을 고치려면 해당 문서의 양식 확인/수정을 엽니다.
2. Excel에서 양식 열기를 눌러 글꼴·색·테두리 등을 수정합니다. 파일 안의 수정 안내 시트를 먼저 확인합니다. 따로 받은 양식은 다른 양식 파일 선택으로 고릅니다.
3. Excel에서 저장하고 닫은 뒤 이 창의 이 양식 사용을 누릅니다. 해당 업체 기본 양식으로 돌아가려면 기본 양식 사용을 선택한 뒤 저장합니다. 행복도시락 일일식수는 위에서 조식·석식 양식 또는 중식 양식을 먼저 선택합니다.

배송 양식 파일 연결은 이 PC의 운영 파일·급식/행복도시락별로 기억합니다. 창에서 취소해도 Excel에서 이미 저장한 수정 내용은 되돌아가지 않습니다.

청구서·확인서에 어떤 명단 값을 넣을지는 문서 항목 설정에서 정합니다. 양식 선택과 출력 칼럼 연결은 서로 다른 설정입니다.

파일을 바꾸는 자세한 순서와 수정 가능한 범위는 7. 템플릿 변경을 참고하세요.

확인서: 1식짜리 먼저, 2식·3식 순으로 배치를 체크하고 이 양식 사용을 누르면 관할동별 시트 안에서 1식 가구부터 2식·3식 순으로 배치합니다. 여기서 식수는 확인서 블록의 가구원 수 기준입니다. 같은 식수끼리의 기존 순서와 가구원 내부 순서는 유지합니다. 기본은 해제이며 새로 만드는 확인서부터 적용됩니다.

확인서: 다음 달로 넘어가는 토·일요일을 마지막 주 날짜에 포함을 체크하고 이 양식 사용을 누르면, 월말이 금요일·토요일인 달의 마지막 주를 다음 달 일요일까지 표시합니다. 예를 들어 2026년 10월에는 체크하면 10.26~11.01, 해제하면 10.26~10.31로 표시합니다. 2026년 7월처럼 다음 달 1·2일이 토·일이면 07.27~08.02로 표시합니다. 기본은 해제입니다. 월~일 주차 기준은 유지하며 연말에도 적용합니다. 다른 요일로 끝나는 달은 바뀌지 않습니다.

이 옵션은 날짜 표시만 바꿉니다. 해당 주말의 식수 포함 여부는 식수·청구서 설정 [참고: S059 · 식수·청구서 설정]의 이번 달에 묶어 배송하는 다음 달 식수 포함을 따릅니다. 운영 파일에 저장되어 양식을 바꿔도 유지되며 새로 만드는 확인서부터 적용됩니다. 저장하지 않고 닫으면 기존 선택을 유지합니다.

현재 배송순서는 더보기 → 기사·배송 → 배송순서관리에서 기사와 식종을 고른 뒤 행을 드래그해 바꿉니다. 배송순서관리 사용 방법 [참고: S038 · 배송순서관리]을 따라 진행하세요.

설정 화면에는 식종별로 따로 입력과 한 번 입력해 모든 식종에 적용이 남아 있지만, 현재 배송순서관리의 드래그 변경에는 적용되지 않습니다. 설정을 바꿔도 기존 순서는 그대로이며, 명단에서 숫자를 직접 입력하거나 통합 입력창을 여는 기능은 현재 제공하지 않습니다.

여러 식종의 순서를 바꿀 때는 배송순서관리에서 선택한 식종과 표시된 가구원을 확인하세요. 입력 방식 설정을 바꿨다는 이유로 선택하지 않은 식종까지 함께 바뀌지는 않습니다.

3. 저장한 뒤 월별 식수 또는 새 청구서·확인서에서 결과를 확인합니다.

다음 달 식수 포함을 켜면 청구서·확인서는 실제 배송일 기준으로, 끄면 식사일 기준으로 계산합니다. 월별 조회의 보기 기준은 그 화면에서 따로 선택합니다. 급식 일일식수는 선택한 실제 배송일 범위의 식수를 표시합니다. 행복도시락 일일식수는 선택한 날의 가입·상태에 따른 인원을 표시하며, 이 옵션으로 집계 기준이 바뀌지는 않습니다. 항목 설정에서 따로 연결한 칼럼은 그 연결을 우선 사용합니다.

일시중지 자동변환

여는 위치 · 설정 → 배송·식수 → 일시중지 자동변환

1. 중지 기간을 일시중지로 계산하려면 같은 달 안에서 자동변환을 선택합니다.
2. 중지로 유지하려면 자동변환 안 함을 선택합니다.
3. 저장한 뒤 해당 날짜의 명단과 새로 만든 문서를 확인합니다.

예를 들어 종료일 없이 10월 5일부터 중지하고 10월 12일부터 배송을 재개하면, 기본 설정에서는 5~11일을 일시중지로 계산합니다. 재개일이 11월이면 중지를 유지합니다. 직접 입력한 일시중지는 바뀌지 않습니다.

이미 저장된 중지·배송 원본 기록도 지우지 않습니다. 기존 기록을 조회하고 계산하는 방식에 적용됩니다.

S062 · 배송대타 칼럼 표시
============================================================
배송대타 칼럼 표시

여는 위치 · 설정 → 화면 → 배송대타 칼럼 표시

1. 보이는 칼럼만 고르려면 모든 시트에서 숨긴 칼럼 제외를 체크합니다.
2. 숨긴 칼럼도 필요하면 체크를 해제하고 저장합니다.
3. 문서 만들기 → 배송목록을 다시 열고 출력할 항목을 선택합니다.

한 시트에서라도 보이는 칼럼은 제외되지 않습니다. 이 설정은 선택 목록의 범위이며, 실제 출력 여부·순서·대체값은 배송대타를 만들 때 정합니다.

S063 · 다른 사용자 화면 설정 불러오기
============================================================
다른 사용자 화면 설정 불러오기

여는 위치 · 설정 → 화면 → 다른 사용자 화면 설정 불러오기

1. 같은 운영 파일을 사용하는 사람 중 화면 배치를 가져올 사용자를 고릅니다.
2. 사용자 이름·PC 이름·저장 시각과 시트 목록·숨긴 칼럼 수를 확인합니다.
3. 불러오기를 적용하고 시트 이름·순서·칼럼 배치를 확인합니다.

현재 PC의 시트와 칼럼 순서·너비·숨김·표시 이름이 선택한 사용자의 배치로 바뀝니다. 명단 값과 다른 사용자의 원본 화면 설정은 그대로입니다.

가져올 사람이 없으면 그 담당자가 같은 운영 파일을 이 기능이 있는 버전으로 열었는지 확인합니다. 시트를 직접 꾸미는 방법은 시트·칼럼 활용 [참고: S016 · 용도별 시트 만들기]에서 볼 수 있습니다.

S064 · 운영 데이터 위치
============================================================
운영 데이터 위치

여는 위치 · 설정 → 데이터 관리 → 운영 데이터 위치

1. 저장할 폴더를 준비한 뒤 위치 선택으로 새 운영 데이터 파일의 위치와 이름을 고릅니다.
2. 현재 운영 파일 비밀번호를 입력합니다.
3. 위치 변경 후 종료를 누릅니다. 복사본 확인이 끝나고 프로그램이 종료되면 다시 실행합니다.
4. 새 위치의 운영 파일을 사용하고 있는지 확인합니다.

원본은 보존하며 새 위치에 복사본을 만들어 다음 실행부터 사용합니다. 새 위치에 이미 있는 파일을 덮어쓰지는 않습니다. 문서 저장 폴더·백업 폴더 변경과 구분해서 사용하세요.

프로그램 위치와 연결 설정

운영 파일·자동 백업·문서 저장 경로는 실행 파일 옆 data/settings.ini에 기억합니다. 프로그램을 옮길 때 연결을 유지하려면 이 설정 파일도 함께 옮기세요. 실행 파일 폴더 안의 경로는 함께 옮긴 폴더를 기준으로, 폴더 밖의 경로는 기존 위치를 그대로 사용합니다.

프로그램을 완전히 종료한 뒤 settings.ini만 삭제하면 다음 실행은 처음 설정으로 시작합니다. Windows에 남은 예전 경로를 자동으로 가져오지 않습니다. 기존 운영 파일 열기에서 사용할 파일과 비밀번호, 자동 백업 폴더를 다시 정하세요. 연결 설정을 지워도 운영 DB와 백업 파일은 삭제되지 않습니다. data 폴더에 운영 자료를 직접 저장했다면 폴더 전체를 지우지 마세요.

S065 · 자동 백업 폴더
============================================================
자동 백업 폴더

여는 위치 · 설정 → 데이터 관리 → 자동 백업 폴더

1. 새 백업을 보관할 폴더를 미리 만듭니다.
2. 폴더 선택에서 새 폴더를 고르고 저장을 누릅니다.
3. 새 폴더에 백업을 만들고 읽을 수 있는지 확인하는 과정이 끝날 때까지 기다립니다. 오류가 나오면 폴더 연결과 쓰기 권한을 확인합니다.

이후 백업부터 새 폴더를 사용합니다. 기존 백업은 이전 폴더에 남고, 현재 운영 파일의 위치도 바뀌지 않습니다.

자동 백업은 운영 파일별 암호화 백업 파일 하나(.mealreplica)에 누락된 저장 내용을 반영합니다. 다른 곳에 복사할 때는 함께 있는 비밀번호 정보 파일도 복사하세요. 현재 일반 시작 화면에는 백업 파일을 고르는 복원 버튼이 없습니다. 예전 압축 백업을 포함해 백업 파일 자체를 복원해야 한다면 담당자에게 요청하세요.

저장 직후 자동 백업이 처음 실패하면 팝업 없이 기록하고, 다음에 운영 파일을 열 때 다시 시도합니다. 이전 실패가 계속되면 원인과 해결 방법을 안내합니다. 운영 파일 저장 성공과 백업 실패는 구분되므로 명단을 다시 입력하기 전에 저장된 내용을 확인하세요.

S066 · 운영 파일 비밀번호 변경
============================================================
운영 파일 비밀번호 변경

여는 위치 · 설정 → 데이터 관리 → 운영 파일 비밀번호 변경

1. 현재 운영 파일 비밀번호를 입력합니다.
2. 새 운영 파일 비밀번호와 새 비밀번호 확인에 같은 값을 입력합니다.
3. 비밀번호 변경을 누르고 완료 안내를 확인합니다. 다음에 운영 파일을 열 때 새 비밀번호를 사용합니다.

설정된 백업 폴더의 기존 백업도 새 비밀번호로 바꿉니다. 완료 안내에 백업 갱신 실패가 나오면 표시된 파일을 확인하세요. 그 폴더 밖에 따로 복사한 파일은 기존 비밀번호를 사용합니다.

S067 · 구주소 업데이트
============================================================
구주소 업데이트

여는 위치 · 설정 → 데이터 관리 → 구주소 업데이트

1. 주소 API 키 [참고: S068 · 주소 API 키]를 먼저 설정합니다.
2. 신주소를 읽을 칼럼 하나를 고릅니다. 기본값은 도로명주소입니다. 선택한 주소 앞에 경기도 성남시를 붙여 검색하며 관할동은 자동으로 붙이지 않습니다. 예를 들어 분당구 가상로 1은 경기도 성남시 분당구 가상로 1로 조회합니다. 이미 경기도 성남시가 있으면 중복하지 않고, 성남시로 시작하면 경기도만 붙입니다. 빈 주소는 건너뜁니다.
3. 구주소를 저장할 칼럼을 고릅니다. 구주소 칼럼이 없으면 구주소 (새 칼럼 만들기)를 선택합니다. 입력·저장 칼럼은 서로 달라야 합니다.
4. 빈칸만 채울 때는 구주소가 비어 있는 건만 업데이트를 선택합니다. 기존 구주소도 바꿀 때는 전체 업데이트 · 기존 구주소 덮어쓰기를 선택합니다.
5. 업데이트 실행을 누릅니다. 1초 이상 걸리면 진행창의 막대 위에 처리 인원 / 전체 인원 · 진행률(%)이 표시됩니다. 건너뜀·동일·조회 실패도 처리 인원에 포함됩니다.
6. 조회 처리 100% 뒤 저장·자동 백업이 끝나면 결과창에서 변경·동일·건너뜀·실패 인원과 실패 대상을 확인합니다.

명단의 검색·필터·숨김과 관계없이 전체 명단이 대상입니다. 창을 연 조회 날짜의 주소를 사용합니다. 신주소가 없거나 조회에 실패한 사람의 기존 구주소는 유지합니다.

S068 · 주소 API 키
============================================================
주소 API 키

여는 위치 · 설정 → 데이터 관리 → 주소 API 키

1. 주소정보누리집에서 받은 도로명주소 검색 API 승인키를 입력합니다.

3. 창을 닫고 구주소 업데이트에서 사용할 칼럼·범위를 고른 뒤 실행합니다.

키는 이 PC의 현재 Windows 사용자에게 저장됩니다. 다른 PC나 Windows 계정에서는 따로 입력해야 합니다. 키가 잘못되었거나 사용 기간이 지났으면 새 키로 바꿔 저장합니다. 더 이상 쓰지 않을 때는 저장된 키 삭제를 사용합니다.

S069 · 초기 명단 적용일

초기 명단 적용일

여는 위치 · 설정 → 데이터 관리 → 초기 명단 적용일

1. 화면의 처음 가져온 명단 날짜를 확인합니다.

S070 · 가구 묶기 기준
============================================================
가구 묶기 기준

가구를 합치거나 나누면 기사·식종별 가구 순서를 1부터 다시 매기며, 명단 원본 배송순서와 배송순서관리에서 같은 번호를 사용합니다. 이미 같은 가구인데 원본 번호가 다르면 이 화면에서 기준을 유지한 채 저장·기존 명단에 적용을 누르세요. 조회일에 미가입이거나 학교 일정상 업체 중식 대상이 아니면 해당 식종의 순서를 비웁니다. 학교 일정이 없거나 검토 기간 밖인 경우도 포함하며, 기존 공통 순서가 다시 나타나지 않게 정리합니다. 다른 기사 배정·식종 가입·중지 상태는 유지됩니다.

여는 위치 · 설정 → 데이터 관리 → 가구 묶기 기준

1. 같은 가구로 묶을 칼럼을 하나 이상 선택합니다. 기본은 핸드폰입니다.
2. 여러 칼럼을 선택하면 선택한 값이 모두 같아야 합니다. 빈 값끼리는 묶지 않으며 핸드폰·전화번호의 하이픈과 공백은 무시합니다.
3. 합칠 가구와 별도 가구로 나눌 대상 수를 확인합니다. 별도 적용일은 입력하지 않습니다.
4. 저장·기존 명단에 적용을 누릅니다. 합칠 가구의 공용 값이 다르면 값을 확인한 뒤 함께 저장합니다.

검색·필터로 숨긴 사람을 포함한 전체 명단에 즉시 적용됩니다. 기준값이 같으면 합치고, 달라지거나 비면 별도 가구로 나눕니다. 이후 명단 불러오기·신규 대상자 등록·기준값 수정에도 같은 규칙을 적용합니다.

가구 연결일 때문에 화면이나 문서에서 사람이 빠지지 않습니다. 과거 변경번호를 원본으로 선택하면 그때 저장된 가구를 사용합니다. 개인별 식종 기간과 배송담당은 유지됩니다. 배송순서는 위에서 안내한 대로 기사·식종별로 다시 매깁니다.

============================================================
S071 · 과거 가구 기록과 현재 처리
============================================================
과거 가구 기록과 현재 처리

가구 소속 기록 복구 메뉴는 사용하지 않습니다. 연결일은 이력 보관용이며, 연결 시작일이 늦거나 종료일이 지나도 현재 가구로 처리합니다. 소속 기록이 없는 사람은 1인 가구로 처리하므로 배송·문서 생성을 위해 먼저 복구할 필요가 없습니다.

다른 사람과 묶어야 하면 가구 묶기 기준 [참고: S070 · 가구 묶기 기준]에서 현재 기준을 적용하세요. 이전 기록은 변경 이력에 남습니다.

S072 · 급식·행복도시락 양식 선택
============================================================
급식·행복도시락 양식 선택

여는 위치 · 더보기 → 설정 → 문서 → 문서 양식

1. 문서 양식을 엽니다.
2. 사용할 급식 양식 또는 행복도시락 양식을 선택합니다.
3. 창 아래의 이 양식 사용을 눌러 운영 파일에 저장합니다.

급식·행복도시락 선택은 운영 DB에 저장됩니다. 배송 문서에 연결한 양식 파일의 위치는 이 PC의 운영 파일·양식 종류별로 기억하므로, 다른 PC에서는 양식 파일을 복사한 뒤 다시 연결하세요.

행복도시락도 기본 양식을 제공합니다. 일일식수는 조식·석식과 중식 양식이 따로 있으며, 배송목록은 플레이스홀더를 연결하는 자유 양식으로 시작합니다. 업체별 파일은 분리되어 있어 각각 수정할 수 있습니다.

확인서를 1식 가구부터 배치하려면 확인서: 1식짜리 먼저, 2식·3식 순으로 배치를 선택한 뒤 이 양식 사용을 누릅니다. 배치 순서 설명 [참고: S051 · 문서 양식]을 참고하세요.

마지막 주에 다음 달 토·일요일을 표시할지는 같은 창의 확인서: 다음 달로 넘어가는 토·일요일을 마지막 주 날짜에 포함에서 선택합니다. 날짜 표시와 식수 기준 설명 [참고: S051 · 문서 양식]을 확인하세요.

S073 · 일일식수·배송목록을 Excel에서 수정
============================================================
일일식수·배송목록을 Excel에서 수정

1. 문서 양식에서 사용하는 양식 종류 아래의 일일식수 양식 확인/수정 또는 배송목록 양식 확인/수정을 누릅니다.
2. Excel에서 양식 열기를 누릅니다. 해당 업체 양식을 처음 열면 개인정보가 없는 기본 양식 복사본이 만들어집니다. 이미 연결한 파일이 있으면 그 파일을 엽니다.
3. 기존 예시 양식은 Excel 아래의 수정 안내 시트를 읽고, 본문 시트에서 열 너비·행 높이·글꼴·크기·글자색·채우기·테두리를 바꿉니다. 일일식수는 정렬·줄바꿈과 용지·여백·배율도 수정할 수 있습니다. 아래의 문서별 적용 범위를 확인하세요.
4. Excel에서 저장한 다음 파일을 닫습니다.
5. 프로그램의 양식 편집창으로 돌아와 이 양식 사용을 누릅니다.
6. 문서 만들기에서 일일식수 또는 배송목록을 새로 만들어 변경한 서식을 확인합니다.

수정 전 모양을 보관하려면 파일 복사본을 만든 뒤 다른 양식 파일 선택으로 복사본을 연결해 수정하세요. 편집창에서 취소하면 이번에 바꾼 파일 선택은 저장되지 않고 기존 양식 선택을 유지하지만, Excel에서 이미 저장한 수정 내용까지 되돌리지는 않습니다.

S074 · 급식 일일식수 본문·복사 행 지정
============================================================
급식 일일식수 본문·복사 행 지정

여는 위치 · 문서 양식 → 급식의 일일식수 양식 확인/수정 → 본문·복사 행 설정

1. 사용할 양식을 선택하고 본문·복사 행 설정을 엽니다.
2. 실제 Excel 양식의 행 내용을 보며 본문 시작 행·본문 끝 행·복사 기준 행·합계 행을 지정합니다. 표의 행을 누른 뒤 해당 항목의 선택 행 사용을 누르거나 번호를 직접 입력할 수 있습니다.
3. 행 설정 적용을 누른 뒤 양식 편집창에서 이 양식 사용을 눌러 저장합니다. 편집창에서 취소하면 이번 행 설정은 저장되지 않습니다.

초기값은 본문 4~8행, 복사 기준 6행, 합계 9행입니다. 프로그램이 변경된 양식의 본문을 자동 판단하지 않으므로, Excel에서 행을 옮기면 이 화면에서 위치를 다시 지정하세요. 복사 기준은 지정한 본문 안에, 합계는 본문 뒤에 두며 해당 행의 셀 병합은 해제해야 합니다.

기사가 본문 칸보다 많으면 복사 기준 행 바로 아래에 복사본을 끼워 넣습니다. 기준 행 아래의 기존 본문·굵은 끝 테두리·합계·뒤쪽 문구가 함께 내려갑니다. 예를 들어 기본 6행을 두 번 더 복사하면 기존 7·8행은 9·10행으로, 합계 9행은 11행으로 이동합니다. 행 설정은 이 PC의 운영 파일·양식 파일별로 기억하므로 다른 파일을 연결하면 그 파일의 설정을 확인하세요.

변경사항의 파란색 표시

같은 식종의 이전 실제 배송일보다 가구 수가 늘거나 줄면 변경된 가구 수 칸과 해당 기사 이름을 연한 파란색으로 표시합니다. 0으로 줄어든 칸도 포함합니다. 현재 숫자만 출력하며, 기본·사용자 양식 모두 적용합니다. 변경 없는 칸과 합계는 양식의 채우기를 유지합니다.

S075 · 서식을 바꿀 때 유지할 부분
============================================================
서식을 바꿀 때 유지할 부분

플레이스홀더 배송목록은 시트 이름·셀 위치·행 구성을 자유롭게 바꿀 수 있습니다. {성명}처럼 항목을 적고 프로그램에서 연결·복사 행을 확인하세요. 글꼴·정렬·표시 형식·인쇄 설정도 그대로 반영합니다. 자유 양식 연결 방법 [참고: S028 · 배송목록의 플레이스홀더 연결과 행 복사]을 확인하세요. 아래 고정 구조 제한은 일일식수와 기존 배송대타 예시 양식에 적용됩니다.

급식·행복도시락 일일식수는 내용이 잘려도 템플릿 기준으로 출력합니다. 열 너비·행 높이·글꼴·크기·테두리·정렬·줄바꿈과 용지·여백·배율을 Excel에서 수정하면 그대로 반영합니다. 색과 채우기도 유지하며, 급식의 변경된 가구 수 칸·기사 이름은 파란색으로 강조합니다. 자동으로 행을 늘리거나 글자를 줄이거나 페이지 높이를 채우지 않습니다. 식수 계산·기사별 병합·집계와 실제 출력 행 범위는 프로그램이 처리합니다.

아래 시트 이름·셀 위치·기존 병합을 유지한 채 서식을 수정하세요. 급식 일일식수의 행 위치를 옮겼다면 본문·복사 행 설정을 다시 지정하세요. 다른 고정 양식의 행·열 위치와 기존 병합은 유지하세요. 배송목록의 새 칼럼은 프로그램에서 양식을 열 때 자동으로 추가됩니다.

문서 | 양식에서 유지할 구조 | 서식이 적용되는 부분

급식 일일식수 | aaa 시트의 A~I열 항목 순서와 1~2행 날짜·식종 제목. 지정한 본문·합계 행은 병합하지 않습니다. | 본문·복사 기준·합계 행을 미리보기에서 지정합니다. 기본은 본문 4~8행·복사 6행·합계 9행입니다. 기사가 본문 칸보다 많으면 선택한 기준 행의 높이와 서식을 반복합니다.

행복도시락 일일식수 | 첫 시트의 A1:J5, 제목과 기존 병합을 유지합니다. 중식·조식/석식 파일을 구분합니다. | 1~3행 제목, 4행 기사·지역별 본문, 5행 합계 서식입니다. 본문 높이와 테두리는 4행, 합계 높이와 서식은 5행을 따릅니다. 기사별 병합과 합계 위치는 자동입니다. 인쇄는 I열까지이며 J열에는 가구별 식수 분포가 있습니다.
기존 배송대타 예시 양식 | 배송대타 시트의 1~21행, 2행 제목과 기존 병합을 유지합니다. 기존 A~H 양식도 읽으며, 확장 양식은 현재 칼럼에 맞춰 열이 늘어납니다. 숨겨진 22·23행은 수정하지 마세요. | 1행 제목, 2행 칼럼 제목, 19~21행 집계 서식을 사용합니다. 3행은 1식, 4~5행은 2식, 6~8행은 3식, 9~12행은 4식, 13~17행은 5식 가구 예시입니다. 각 예시의 행 높이·글꼴·색·테두리를 출력에 적용하며 6식 이상은 1식 서식과 높이를 반복합니다. 18행의 바깥 테두리는 BOX 가구에 적용합니다.

기존 예시 양식의 시트 이름은 배송대타로 유지합니다. 플레이스홀더 자유 양식은 시트 이름을 바꿀 수 있습니다. 양식에 적힌 예시 이름·주소·숫자는 생성할 때 운영 자료로 채워집니다.

배송목록의 출력 항목과 순서는 문서 만들기 → 배송목록에서 체크와 드래그로 정합니다. 용지 방향과 페이지 구분도 그 화면에서 선택합니다. 일일식수의 기사 순서는 더보기 → 기사·배송 → 기사 관리 → 일일식수 기사 순서에서 식종별로 바꿉니다.

기존 배송대타 예시 양식에서 수정해도 반영되지 않는 항목: 셀의 가로·세로 정렬, 줄바꿈·들여쓰기·회전, 표시 형식, 인쇄 설정, 샘플 값·수식입니다. 가로·세로 정렬은 배송목록 만들기의 각 칼럼 옆 드롭다운에서 선택하세요. 줄바꿈·가구 병합과 집계는 프로그램이 처리합니다. 열 너비와 본문 행 높이는 템플릿 값을 사용하므로 긴 내용이 잘리면 해당 칼럼 너비와 가구 예시의 높이를 늘리세요. 용지 방향·페이지 구분은 출력 화면에서 정하며 인쇄는 가로 한 페이지 맞춤을 유지합니다.

급식 일일식수는 기본 양식과 사용자가 연결한 양식 모두 지정한 서식을 사용합니다. 긴 메모가 잘리면 템플릿의 해당 열 너비·본문 행 높이·글꼴·줄바꿈을 수정한 뒤 다시 생성하세요. 합계 높이는 9행을 수정합니다. 행복도시락은 중식과 조식·석식 양식 각각에서 본문 4행·합계 5행을 수정하세요. 템플릿을 바꾼 뒤에는 새 일일식수를 만들어 결과를 확인합니다.

배송목록의 가구 색은 식수가 아니라 가구원 수를 기준으로 적용합니다.

S076 · 다른 양식 파일로 변경
============================================================
다른 양식 파일로 변경

1. 사용할 양식을 암호 없는 .xlsx 파일로 준비합니다. 위의 시트·셀 구조를 유지한 파일이어야 합니다.
2. 해당 문서의 양식 확인/수정 → 다른 양식 파일 선택을 누릅니다.
3. 파일을 선택하고 화면에 표시된 경로를 확인합니다.
4. 이 양식 사용을 누릅니다. 상위 창을 닫아도 이 편집창에서 저장한 파일 연결은 유지됩니다.

연결한 파일은 같은 위치에 보관하세요. 파일을 옮기거나 이름을 바꾸면 다시 선택해야 합니다. Excel에서 다른 이름으로 저장했다면 새 파일을 이 방법으로 연결하세요.

S077 · 청구서·확인서는 무엇을 바꿀 수 있나요?
============================================================
청구서·확인서는 무엇을 바꿀 수 있나요?

청구서·확인서는 문서 양식에서 급식·행복도시락 형식을 선택합니다. 칼럼에 들어갈 내용은 설정 → 문서 항목 설정에서 바꿉니다.

1. 문서 항목 설정을 엽니다.
2. 사용 중인 양식 종류와 수정할 문서를 선택합니다.
3. 왼쪽 출력 칼럼에 넣을 1순위와, 값이 없을 때 사용할 2순위를 고릅니다. 청구서는 식수·금액 같은 자동 계산 항목도 선택할 수 있습니다.
4. 저장한 뒤 문서를 다시 만듭니다.

자세한 예시는 4. 생성 파일에 칼럼 연결을 참고하세요. 프로그램에 반영된 청구서 템플릿의 칼럼 이름이 바뀌었다면 이 설정창을 다시 열어 새 칼럼에 항목을 연결합니다.

현재 청구서·확인서에는 다른 Excel 양식 파일을 직접 선택하는 버튼이 없습니다. 표 배치나 서식 파일 자체를 교체해야 한다면 사용할 양식을 프로그램 관리 담당자에게 전달해 반영을 요청하세요.

S078 · 기본 양식으로 돌아가기·결과 확인
============================================================
기본 양식으로 돌아가기·결과 확인

1. 사용하는 업체의 해당 문서 양식 확인/수정에서 기본 양식 사용을 누릅니다.
2. 화면에 현재 선택: 해당 업체 기본 양식이 표시되는지 확인한 뒤 이 양식 사용을 누릅니다.
3. 문서를 새로 생성해 글꼴·색·테두리와 제목·본문·합계가 원하는 대로 출력되는지 확인합니다.

행복도시락도 기본 양식 사용으로 돌아갈 수 있습니다. 일일식수는 선택 중인 중식 또는 조식·석식 양식만 초기화합니다. 식종을 바꾸기 전에 이 양식 사용으로 저장하고 창을 다시 열어 나머지 양식을 설정하세요.

배송목록에 이전 정상 양식을 사용했다는 안내가 나올 때

배송목록 양식의 구조가 잘못되거나 선택한 파일을 읽을 수 없으면, 보관된 이전 정상 저장본으로 양식을 열거나 문서를 만들고 안내합니다. 수정한 원본 파일은 그대로 둡니다. 배송목록 양식 확인/수정에서 사용할 파일과 서식을 확인한 뒤 Excel에서 저장하고 닫아 이 양식 사용을 누르세요. 이전 정상 저장본도 없다면 기본 양식 사용 또는 다른 양식 파일 선택으로 정상 양식을 연결하세요.

템플릿을 수정해도 이미 만든 Excel 문서는 바뀌지 않습니다. 새 문서를 생성한 뒤 Excel의 인쇄 미리보기에서도 글자가 잘리거나 페이지가 나뉘지 않는지 확인하세요.
