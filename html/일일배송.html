TAB 03

일일배송 만들기

조식·석식 또는 중식 명단으로 배송담당·구역별 날짜 시트를 만듭니다.

청구서 생성 없이 일일배송을 만들 수 있습니다.

① 청구서 탭에서 사용할 명단을 불러옵니다. 중식은 중식 명단의 필수 매핑과 학교별 방학 일정까지 준비합니다.

핵심 순서

  1. 사용할 명단 불러오기

    조식·석식은 식종·비고를 매핑합니다. 중식은 필수 개인정보·배송 정보와 학교 일정을 매핑합니다.

  2. ③ 일일배송 탭 이동

    명단 데이터 ○명 로드됨이 표시되는지 확인합니다.

  3. 조식·석식 컬럼 확인

    조식·석식 명단을 쓸 때 배송 담당, 1순위 구역, 주소와 식종 컬럼을 확인합니다. 중식 단독이면 이 선택은 필요 없습니다.

  4. 날짜와 출력 폴더 선택

    시작일·종료일을 고르고 주말·공휴일·배송 제외일 건너뛰기 여부를 확인합니다.

  5. 일일배송 생성

    일반 날짜 시트와 중식_yy.mm.dd 시트를 확인합니다.

필수 컬럼

컬럼필수 여부
배송 담당 컬럼필수 — 중식은 ① 청구서 탭에서 매핑
담당 구역 1순위 컬럼필수 — 중식은 ① 청구서 탭에서 매핑
담당 구역 2순위 컬럼선택 — 1순위 셀이 빈 행에만 사용
세대 구분(주소) 컬럼필수
조식 여부 / 석식 여부조식·석식 명단을 사용할 때 하나 이상
비고/메모 컬럼선택

꼭 확인할 규칙

  • 구역: 1순위 값이 있으면 사용하고, 비어 있을 때만 2순위를 사용합니다.
  • 식종값: 1, 1.0, Y, y, 예, 있음, 0보다 큰 숫자만 대상입니다. O는 대상이 아닙니다.
  • 미분류: 배송담당 또는 적용할 구역 값이 비면 미분류 행에 들어갑니다.
  • 중식 날짜: 학교별 시작일~종료일과 중식 일시중지를 적용해 해당 날짜 대상자만 셉니다.
  • 0건 행: 해당 시트에서 배송 수량이 0인 구역 행은 자동으로 빠지고 필요한 만큼 행 수가 늘거나 줄어듭니다.
  • 날짜: 시작일과 종료일을 모두 포함합니다. 건너뛰기 체크를 풀면 주말·공휴일·제외일도 만듭니다.

비고/메모

석식: 6/13~6/15 또는 중식: 6/13~6/15처럼 적습니다. 날짜 시트가 속한 일요일~토요일 주차와 겹치는 항목만 표시하고 실제 중지 날짜의 수량에서도 제외합니다.

템플릿과 결과

  • 조식·석식 템플릿: assets/일일배송템플릿.xlsx
  • 중식 전용 템플릿: assets/중식일일배송템플릿.xlsx
  • 조식·석식 시트명: yy.mm.dd
  • 중식 시트명: 중식_yy.mm.dd — 전용 템플릿의 중식 수량 칸을 사용
  • 중식 시트는 해당 날짜의 중식 배송 건수가 있을 때만 생성하며 최근 날짜부터 배치
