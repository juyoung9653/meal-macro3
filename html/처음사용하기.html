처음 사용하기

파일, 시트, 컬럼의 차이만 알면 나머지는 각 탭의 순서대로 진행할 수 있습니다.

기본 조작 4단계

  1. main.exe 실행

    프로그램 폴더의 파일을 두 번 누릅니다.

  2. 파일 탐색

    명단이나 일정 엑셀을 고릅니다. .xlsx 사용을 권장합니다.

  3. 시트 선택

    엑셀 아래쪽 탭과 같은 개념입니다. 실제 데이터가 있는 시트를 직접 고릅니다.

  4. 컬럼 매핑

    프로그램 항목과 원본 엑셀의 세로 열을 연결합니다. 별표가 있는 항목은 필수입니다.

컬럼 매핑 예시

프로그램 항목원본 파일에서 고를 수 있는 예
성명이름, 아동명, 학생명
생년월일생년, 생일
학교명학교, 소속학교
배송 담당배송기사, 담당자
비고학기중 비고, 메모, 특이사항
자동 선택을 그대로 믿지 마세요.

프로그램이 비슷한 이름을 먼저 골라 주지만, 각 항목이 올바른 원본 컬럼인지 확인한 뒤 확인을 누르세요.

명단이 0명으로 불러와질 때

  • 실제 명단이 있는 시트를 골랐는지 확인합니다.
  • 위쪽 20행 안에 성명, 이름, 성함, 학생명, 학생 같은 제목이 있는지 확인합니다.
  • 이름 셀이 빈칸이나 숫자만 있는 값인지 확인합니다.

설정은 필요할 때만

파일 → 설정에서 템플릿 경로와 급식별 배송 요일을 바꿀 수 있습니다. 기본 요일은 조식 금~일, 석식 월~목, 중식 월~금입니다.

일일배송 템플릿 위치

조식·석식은 assets/일일배송템플릿.xlsx, 중식은 별도 파일인 assets/중식일일배송템플릿.xlsx를 사용합니다. 설정 화면에는 별도 선택란이 없습니다.
