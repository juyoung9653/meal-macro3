TAB 04

식수현황 보기

선택한 달의 조식·석식·중식 수량을 날짜별 표와 월 합계로 확인합니다.

확인서와 같은 계산 기준을 사용합니다.

급식별 배송 요일, 공휴일·배송 제외일, 비고의 일시중지, 학교별 중식 배송 기간을 반영합니다. 청구서 파일을 생성하지 않아도 현재 불러온 명단으로 조회할 수 있습니다.

조회 순서

  1. ① 청구서 탭에서 명단 준비

    조식·석식 명단의 식종·비고를 연결합니다. 중식은 중식 명단과 학교별 방학 일정까지 준비합니다.

  2. ④ 식수현황 탭 이동

    처음에는 ① 청구서 탭에서 선택한 귀속 연월이 표시됩니다.

  3. 조회 월 선택

    연도와 월을 바꾸면 해당 월의 명단과 일정이 즉시 다시 계산됩니다.

  4. 표와 월 합계 확인

    매일의 조식·석식·중식·합계를 확인하고 마지막 월 합계 행에서 식종별 총량을 확인합니다.

표 읽는 법

열내용
일자·요일선택 월의 1일부터 말일까지 모두 표시
조식·석식·중식해당 날짜에 실제 제공할 식종별 인원 수
합계그 날짜의 세 식종 수량 합계
월 합계선택 월 전체의 식종별 수량과 총합

비고 입력 예시

17일 중지 19일 배송은 19일부터 배송을 재개한다는 뜻입니다. 따라서 선택한 달의 17일과 18일만 일시중지하고 19일 수량은 다시 포함합니다. 8/17 석식 중지 8/19 배송처럼 식종을 적으면 석식에만 적용됩니다.

수량이 예상과 다를 때

  • ① 청구서 탭의 식종·비고 컬럼 매핑을 확인합니다.
  • 중식은 학교명과 학교별 시작일·종료일이 정확히 연결됐는지 확인합니다.
  • 공휴일과 ① 청구서 탭의 배송 제외일은 해당 날짜 수량에서 빠집니다.
  • 수량이 없는 날도 월의 흐름을 확인할 수 있도록 0으로 표시됩니다.
