TAB 02

확인서 만들기

확인서는 계산이 끝난 청구서 데이터를 사용합니다.

청구서를 먼저 생성하세요.

① 청구서 탭에서 생성 완료 후 ② 확인서 탭으로 이동해야 확인서 생성 버튼이 켜집니다.

핵심 순서

  1. 청구서 생성

    ① 청구서 탭에서 청구서 생성 완료창까지 확인합니다.

  2. ② 확인서 탭 이동

    청구서 ○건 로드됨이 표시되는지 확인합니다.

  3. 출력 경로 선택

    폴더 선택으로 저장할 위치를 고릅니다.

  4. 배송담당 정보

    필요하면 배송담당자 컬럼을 고르고 담당자별 연락처를 직접 입력합니다. 필요 없으면 (선택 안 함)을 둡니다.

  5. 확인서 생성

    확인서_YYYYMM.xlsx 파일의 관할동별 시트와 가구 수를 확인합니다.

계산 기준

항목기준
대상자조식·석식·중식 중 하나라도 실제 건수가 1건 이상인 사람
동일인이름 + 생년월일이 모두 같을 때 한 사람으로 합침
시트관할동별로 구분하며 공란은 기타가 될 수 있음
세대같은 관할동에서 주소가 같은 사람을 한 세대로 계산
5명한 주소에 5명 이상이면 5명 가구에 포함

중식 명단 정보도 반영됩니다

중식 명단의 관할동·주소·세대주성명·핸드폰 등은 필수 매핑값을 사용합니다. 조식·석식 명단의 같은 항목이 비어 있으면 중식 값으로 채웁니다.

자동 선택값도 확인하세요.

주소나 관할동을 잘못 연결하면 확인서의 지역·세대 구분도 달라집니다.

배송담당 대표값

현재 확인서에는 청구서 데이터의 첫 번째 대상자에게 연결된 배송담당자와 연락처가 대표값으로 사용됩니다.
