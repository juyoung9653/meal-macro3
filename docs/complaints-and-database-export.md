# 민원과 DB Excel 내보내기

## 민원 등록

명단의 어느 셀이든 우클릭한 뒤 **민원**을 선택합니다. 접수 시각, 접수 경로
(전화/메일/기타), 내용을 입력하고 저장합니다. 관련 식종은 선택 사항이며 조식·중식·석식을 여러 개 체크할 수 있습니다.
**같은 가구에도 함께 접수**를 체크하면 명단 화면의 조회 기준일에 같은 가구인
구성원에게 동일한 민원을 저장합니다. 적용 대상 이름과 인원수를 확인할 수 있으며,
체크하지 않으면 선택한 사람에게만 저장합니다. 가구 전체 저장은 한 번에 처리됩니다.
접수 시각은 수정할 수 있으며 실제 저장 시각과 저장한 사용자는 별도로 기록됩니다.
취소하면 기록을 남기지 않습니다.

배송 상태 변경 화면의 **접수 경로**도 전화/메일/기타 중 선택할 수 있습니다.
미선택 상태로도 저장할 수 있습니다. 기존 기록에 없는 접수 경로를 추정해서 채우지 않습니다.
일괄 변경에서는 선택한 경로가 같은 변경 묶음의 모든 대상에 적용됩니다.

## 이력 조회

어느 셀이든 우클릭한 뒤 **이력보기**를 선택합니다.

- **정보 변경**: 개인정보, 사용자 추가 항목, 주소 등 변경 기록
- **식종 변경**: 가입, 배송 상태, 배송담당 등 식종 관련 변경 기록
- **민원**: 접수 시각, 접수 경로, 내용
- **상태 적용 기간**: 식종별 상태 적용 기간과 원본 상태 기록

일반 셀에서 열면 화면에서 선택한 식종, 식종 셀에서 열면 해당 식종을 기준으로
상태 적용 기간을 표시합니다. 기록 시각은 한국시간입니다.

## Excel 내보내기

명단 위의 **Excel 내보내기**를 선택합니다. 조회 기준일과 출력할 항목을 선택한 후
저장합니다. 작업 중에는 현재 단계, 명단 처리 건수와 경과 시간이 표시됩니다.
암호화·파일 저장처럼 전체 진행량을 알 수 없는 단계는 진행 중 표시를 사용합니다.
전체 명단, 민원, 변경 이력을 함께 내보내거나 항목을 따로 선택할 수 있습니다.
기존 설정의 Excel 공통 비밀번호가 적용됩니다. 파일이 이미 있으면 덮어쓰기 여부를 묻습니다.

명단은 화면의 검색 조건이나 숨긴 칼럼과 관계없이 모든 사람과 기본·사용자 항목을 포함합니다.
조회 기준일에 가입한 식종의 배송담당을 사람별로 비교합니다.

- 모든 사람의 가입 식종별 담당이 같으면 `명단`에 한 사람 한 행, 식종 3개 열로 출력합니다.
- 한 사람이라도 가입 식종별 담당이 다르면 `명단`을 사람·식종별 행으로 출력하고, `명단(통합)`도 한 사람 한 행으로 함께 출력합니다. 통합 명단의 식종별 배송담당·배송순서는 각각 별도 열에 표시합니다.
- 조회일에 가입 식종이 없는 사람도 명단에서 누락하지 않습니다.

각 표의 제목은 첫 행이며 필터와 고정 행을 사용할 수 있습니다. `내보내기 정보` 시트는 마지막에 한 번만 생성되어 조회 기준일, 명단 revision UUID, 변경번호, 시간대, 명단 행 형식을 기록합니다. 명단을 선택하지 않으면 행 형식은 표시하지 않습니다.
명단의 `도로명주소`와 `상세주소`는 조회 기준일에 실제 적용되는 값입니다. 원본 주소 열은 출력하지 않습니다.
`변경 이력`의 대상 종류와 작업은 읽기 쉬운 한국어로 표시합니다.

이력은 조회일 이전만이 아니라 현재 DB에 저장된 전체 기록을 내보냅니다.
전화번호·배송순서의 앞자리 0과 수식처럼 보이는 입력 내용은 문자열로 보존합니다.
이 파일은 업무 조회용이며 암호화 DB 백업을 대신하지 않습니다.


## 배송담당 변경과 기사 일괄 교체

개인 명단을 우클릭해 **배송담당 변경**을 선택합니다. 변경할 식종을 여러 개 체크하고
**적용일**을 지정합니다. 식종마다 다른 기사를 지정하거나, **선택 식종에 같은 기사 지정**으로
체크한 식종에 같은 기사를 넣을 수 있습니다. 체크하지 않은 식종은 유지됩니다.

명단 위 **기사 일괄 교체**에서는 기존 기사, 새 기사, 적용 시작일, 변경할 식종을 선택합니다.
화면 검색과 관계없이 전체 명단에서 적용일 기준 해당 기사의 배정을 찾습니다.
미가입 식종에 남아 있는 배정도 포함하므로 저장 전에 대상 이름과 식종·건수를 확인하세요.
기사 관리에 등록되지 않고 명단에 이름만 입력된 기존 담당자도 선택할 수 있습니다.
새 기사는 **기사 관리**에서 먼저 등록해야 합니다.

두 변경 모두 적용일 당일부터 반영됩니다. 이전 날짜의 배정은 유지되며,
이미 예약된 이후 날짜의 배정 변경은 그 날짜부터 그대로 적용됩니다.
일괄 교체는 하나의 변경 기록으로 저장되고 식종 변경 이력과 날짜별 Excel 명단에 반영됩니다.
기사 이름·전화번호 수정은 기사 관리에서 하며, 담당 배정 교체와 별개의 작업입니다.


## 확인서의 담당 기사·주소 기준

월간 확인서의 담당 기사와 주소는 **선택한 문서 원본의 해당 월 말일** 기준입니다.
예를 들어 16일부터 B기사로 바뀌면 해당 월 확인서의 담당자는 B기사로 표시합니다.
월중 이사한 경우 말일에 적용되는 주소를 사용하고, 다음 달부터 적용되는 변경은 포함하지 않습니다.
여러 식종의 담당자가 다르면 해당 담당자들을 함께 표시합니다.

급식 일수·금액과 주차별 횟수는 기존처럼 해당 월의 날짜별 가입·배송 상태·단가로 계산합니다.
말일의 담당자·주소를 사용한다고 해서 계산 기간이 그 담당자의 배정 기간으로 줄어들지는 않습니다.
청구서도 같은 월간 데이터를 사용합니다. 예전 원본을 선택해 재생성하면 그 원본에 저장된
변경 이력만 반영하며, 생성 결과의 계산 기록에 종료일 기준 적용 정책을 남깁니다.
