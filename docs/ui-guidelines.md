# UI 디자인·상호작용 기준

급식 명단을 관리하는 실무자가 익숙한 조작으로 빠르게 작업할 수 있도록 하는 프로젝트 기준이다.
2026-09-29 사용자 피드백을 반영했다. 사용자의 최신 지시가 우선하며, 아래의 확인 절차는 별도 승인 절차를 뜻하지 않는다.

## 편집 조작의 일관성

- 명단의 성명·생년월일·학교·학년·전화번호·핸드폰·비고·사용자 항목은 셀을 더블클릭해 현재 저장값을 직접 수정한다. Enter와 다른 곳으로의 정상적인 포커스 이동은 저장하고 Esc는 취소한다. 변경 없음·잘못된 값·저장 실패는 revision과 화면 값을 바꾸지 않는다.
- 식종 셀은 더블클릭으로 수정하지 않는다. 주소·관할동은 더블클릭하면 `이사 등록`, 순서는 `순서 수정`, 배송 설정은 기존 배송 설정 수정 흐름을 연다.
- 순서 셀은 **우클릭 → 순서 수정** 또는 더블클릭으로 식종별 수정창을 연다. 인적사항 수정창으로 연결하지 않는다.
- 다른 열의 기존 우클릭 항목과 이력보기·민원 기능은 유지한다.
- 툴팁과 안내 문구는 실제 조작과 일치시킨다. 숨겨진 편집 제스처를 추가하지 않는다.
- 편집창과 셀 편집기는 현재 값을 채워 보여준다. 취소와 변경 없음은 DB 변경 기록을 만들지 않는다.
- 순서 수정은 변경한 식종의 순서만 저장하며 기사 배정은 유지한다. 날짜 제한 없이 적용된다는 점은 수정창에서 안내한다.

## 이사 시 관할동 변경

- `이사 등록`에서 주소와 함께 관할동을 직접 입력한다. 선택 목록으로 제한하지 않는다.
- 관할동은 명단의 현재 조회일 기준 값을 채워 보여주고, 주소와 같은 적용일부터 변경한다. 빈칸으로 저장하면 해당 날짜부터 관할동을 지운다.
- `같은 가구 구성원도 함께 이사`를 선택하면 주소와 관할동을 하나의 revision으로 같이 적용한다. 취소하거나 변경한 내용이 없으면 revision을 만들지 않는다.

## 명단 표시

- 명단은 도로명주소와 상세주소를 서로 붙이지 않고 나란한 별도 열로 표시한다. 각 열의 검색·필터·이름·숨김과 현재 시트 Excel 내보내기도 구분한다. 두 주소 열은 더블클릭하면 기존 이사 등록창을 열며, 행 추가에서도 각각 입력한다.
- 기존 주소 열의 내부 키·사용자 이름·너비·순서를 유지하고 새 상세주소 열은 바로 다음에 배치한다. 이전 주소 열이 숨겨져 있으면 새 상세주소 열도 처음에는 숨긴다. 이전 합친 주소에 적용된 저장 검색·값 선택 필터는 최초 복원 시 해제하며 다른 열의 필터는 유지한다.
- 도로명주소·상세주소의 가구 공용 설정은 기존 주소 묶음을 유지한다. 두 열에서 같은 공용 설정을 열며 메뉴에 함께 적용되는 항목을 명시한다.
- 문서 연결의 `전체 주소 (도로명주소 + 상세주소)`는 기존 전체 주소 연결을 유지한다. 도로명주소와 상세주소도 개별 원본으로 선택할 수 있고, 기존 청구서·확인서 기본 출력은 유지한다.

- 왼쪽의 현재 조회 인원은 `조회 명단`으로 표시한다. 메인 검색 영역에는 `전체 기사` 선택 상자를 두지 않으며, 기사 조건은 열 제목 필터로 선택한다. 메인 화면에서 여는 기사별 가구는 전체 기사를 기본으로 조회한다.
- 왼쪽 식종별 현황은 조회일이 운영 파일의 식종별 기본 배송요일이고, 조회 결과에 배송 또는 일시중지가 한 명 이상인 식종만 표시한다. 기본 제공요일에 연결된 실제 배송요일로 판단하므로 금·토·일 조식을 금요일에 묶어 배송하면 조식 현황은 금요일에만 표시한다. 필터·조회 날짜·명단·배송 기본값이 바뀌면 바로 다시 표시하거나 숨긴다. 명단 칼럼과 오른쪽 같은 가구 목록의 현재 상태 표시는 이 현황 표시 조건과 분리한다.
- 표준 `비고`는 명단 열과 전체 검색에 포함한다. 사용자가 만든 `비고2` 같은 추가 항목은 별도 열과 값으로 그대로 유지하며 표준 `비고`와 합치거나 덮어쓰지 않는다.
- 배송 상태를 선택하거나 이력으로 표시할 때는 `배송`·`일시중지`·`중지`를 사용한다. 명단 식종 칼럼의 현재 상태는 조회일의 가입 기간과 상태 이력으로 판단하며, 반복 제공 요일과 실제 배송요일은 적용하지 않는다. 중식은 추가로 조회일이 검토된 학교 일정 기간 안의 업체 제공 대상일 때만 상태를 표시한다. 학교 일정이 없거나 기간 밖인 날·학교 급식일·주말은 `-`로 표시하되, 학교 급식일에 학교 미급식 학년으로 지정된 대상은 업체 제공 대상으로 본다. 배송 중이면 `배송`, 일시중지면 `일시중지`를 표시하며 중지되었거나 미가입인 식종의 상태 줄은 `-`로 표시하고 배송 담당 줄은 유지한다.
- 오른쪽 선택 정보의 제목은 `같은 가구`로 표시한다. 가구원별 식종은 선택일에 명단 식종 칼럼의 현재 상태가 `배송`인 식종만 표시한다. 배송일이 아니어도 포함하며, 일시중지·중지·미가입 식종은 제외한다. 가구 목록 높이는 현재 글꼴의 행 높이에 맞춰 최대 5명까지 온전히 표시하고, 더 많은 가구원은 목록 안에서 스크롤해 확인한다. 대상자를 바꾸면 목록 맨 위부터 표시하며 식종 변경 이력 공간은 유지한다.
- `중지`를 새로 선택하면 종료일 없음이 기본이다. 일시중지에서 전환할 때도 같으며, 사용자가 종료일을 다시 지정하면 입력한 날짜는 유지한다.
- 배송 상태 변경창의 식종 카드는 체크박스뿐 아니라 현재 상태 문구와 빈 공간을 눌러도 선택을 전환한다. 체크박스의 키보드 조작은 유지하고, 일괄 변경 대상이 아닌 비활성 식종 카드는 어느 영역을 눌러도 선택하지 않는다.

- 식종별 순서가 다르면 `/`로 이어 붙이지 않고 각 값을 별도 줄에 표시한다.
- 식종 이름과 값 사이에는 콜론과 공백을 쓴다. 현재 화면 식종 순서인 석식·조식·중식을 따른다.

```text
석식: 1
조식: 3
중식: 2
```

- 순서가 하나이거나 여러 식종의 순서가 같아도 `석식: 1`처럼 식종을 표시한다. 조회일의 가입 식종과 명시적으로 보존된 식종별 배정만 표시하며, 미가입 상태에서 공통 배정만 남은 값은 `공통/식종 미지정: 1`로 구분한다.
- `001` 같은 앞자리 0과 기존 순서 문자열을 임의로 숫자로 변환하지 않는다.
- 여러 줄 값이 잘리지 않도록 행 높이와 열 너비를 확인한다. 정렬·검색도 함께 확인한다.

## 기존 화면과 어울리는 디자인

- 색상과 글꼴은 `src/desktop_v2/theme.py`의 기존 규칙을 재사용한다.
- 기준 색은 짙은 남색 `#17313D`, 화면 배경 `#EDF3F5`, 경계선 `#CAD8DD`, 강조색 `#16788A`이다.
- 새 편집창의 저장 버튼에는 `primaryAction`, 취소 버튼에는 `quietAction` 등 기존 스타일을 적용한다.
- 기능을 추가할 때 상단에 기본 회색 버튼부터 붙이지 않는다. 조작 대상과 가까운 기존 위치에 배치한다.
- 여백·테두리·버튼 높이를 주변 요소와 맞춘다. 꾸미기 위한 색이나 영역을 추가하지 않는다.

## 접기·펼치기

- 좌우 패널은 각각 접고 펼칠 수 있게 한다. 상단의 글자 버튼 대신 얇은 경계와 중앙의 둥근 화살표 손잡이를 사용한다.
- 좌우 손잡이의 높이를 맞추고, 작은 시각 요소보다 넉넉한 클릭 영역을 제공한다.
- 접힌 상태에서도 손잡이와 화살표가 온전히 보여야 한다. 화살표 방향과 툴팁은 현재 가능한 동작을 나타낸다.
- 마우스 올림·누름·키보드 포커스를 구분한다. 전환은 약 150ms로 짧게 한다.
- 접으면 명단이 빈 공간을 채우고, 펼치면 상세 패널의 이전 너비를 복원한다.
- 날짜·식종·대상자 선택을 유지하며, 연속 클릭과 창 크기 변경에도 상태가 어긋나지 않게 한다.

## 완료 전 확인

- 합성 데이터로 펼침·접힘·수정창을 직접 캡처해서 확인한다. 실제 이용자 정보는 미리보기 자료로 사용하지 않는다.
- 기본 창과 최소 창 크기(현재 1080×680)에서 잘림, 겹침, 빈 공간, 손잡이 접근성을 확인한다.
- 새 수정 기능은 실제 진입 메뉴, 저장, 취소, 값 유지와 관련 회귀 테스트를 확인한다.
- 데이터 수정은 기존 revision·암호화 DB·자동 백업 흐름을 사용한다.

## 운영 데이터 위치 변경

- 기존 운영 파일의 저장 위치는 `설정 → 운영 데이터 위치`에서 변경한다. 새 파일 위치와 현재 비밀번호를 입력하고 완료하면 운영 창을 종료하며, 다음 실행부터 새 위치를 사용한다.
- 열린 DB의 백업과 검증된 복원으로 최신 내용 및 비밀번호 정보를 함께 옮긴다. 기존 파일과 설정은 취소·실패 시 유지하고 대상 파일은 덮어쓰지 않는다.

## 자동 백업 폴더 변경

- `설정 → 자동 백업 폴더`에서 현재 폴더를 확인하고 새 폴더를 지정한다. 저장하면 실행 중인 세션과 다음 실행에 바로 적용하며 운영 창을 닫지 않는다.
- 새 폴더에 검증된 백업을 만든 뒤 설정을 저장한다. 취소·변경 없음·실패는 기존 백업 위치를 유지한다. 운영 데이터 파일의 위치는 바꾸지 않는다.
- 기존 백업은 원래 폴더에 보관한다. 폴더를 변경할 때 기존 백업을 옮기거나 삭제하지 않는다.

## 운영 파일 비밀번호 변경

- `설정 → 운영 파일 비밀번호 변경`에서 현재 비밀번호와 새 비밀번호·확인을 입력한다. 입력 값은 기본으로 가리고 표시 기능을 제공한다.
- 현재 비밀번호 오류·확인 불일치·취소·변경 없음은 자격 정보와 revision, 자동 백업을 바꾸지 않는다. 변경 성공 후에도 운영 창을 유지하고 결과를 안내한다.
- 설정된 자동 백업 폴더의 같은 DB에 속하는 검증된 기존 백업은 새 비밀번호로 갱신한다. 폴더 밖의 복사본과 갱신 실패 백업은 변경 전 상태로 보존하며, 마지막으로 해당 백업을 열던 비밀번호는 파일마다 다를 수 있다. 손상·확인 불가 백업은 유지하고 사용자에게 알린다. 비밀번호 변경 후 백업 갱신이나 새 자동 백업에 실패해도 운영 파일의 변경 완료와 일부 실패를 분명히 안내한다.

## 행 추가·삭제와 기사별 가구

- 명단에서 행을 추가하고 선택한 대상자를 삭제할 수 있는 조작을 제공한다. 빈 명단에서도 행 추가에 접근할 수 있어야 한다.
- 삭제는 대상자를 식별할 수 있는 확인창에서 `삭제`와 `취소` 버튼을 제공하고, `삭제`를 다시 눌렀을 때만 반영한다. 취소하면 데이터와 revision을 변경하지 않는다.
- 기사별 가구의 `식종별 분리` 버튼은 식종마다 해당 가구원·배송순서·연락처를 나누어 표시한다. `분리 해제`로 기존 가구별 표시로 돌아간다.
- 분리·해제는 조회 방식만 바꾸며 가구 구성이나 기사 배정을 저장·변경하지 않는다. 기사 선택과 검색·정렬을 유지하고 가구 수와 표시 행 수를 구분한다.
- 분리·해제 후 값 선택 필터에 더 이상 존재하지 않는 합친 값은 해제한다. 검색어와 유효한 값 선택, 명시적인 전체 선택 해제 상태는 유지한다.
- 기사별 가구의 열별 검색어·값 선택과 식종별 분리 상태는 현재 운영 파일별 PC 화면 설정으로 기억한다. 명시적으로 값을 하나도 선택하지 않은 상태와 현재 표시 데이터에 없는 저장 값도 복원한다. `숨긴 명단 포함`은 다시 열 때 기본 해제 상태로 시작한다.
- `전체 필터 해제`는 기사별 가구의 모든 열 검색과 값 선택 조건을 한 번에 지우고 저장한다. 식종별 분리·정렬·숨긴 명단 포함·처음 연 기사 범위는 유지한다.

## 배송 시작일과 비밀번호

- 행 추가 시 `배송 시작일`을 지정한다. 기본값은 명단에서 선택한 조회일이며, 선택한 식종은 지정한 날짜부터 가입·배송 대상으로 처리한다. 이전 날짜에는 배송 대상으로 표시하지 않는다.
- 배송 시작일 이후에는 식종별 기존 배송 일정과 상태 규칙을 적용한다. 추가 취소 시 데이터와 revision은 변경하지 않는다.
- 새 운영 파일은 비밀번호 하나로 생성·로그인·백업 복원을 진행한다. 별도 기관 복구 비밀번호를 요구하지 않고, 비밀번호 표시 기능으로 입력을 확인한다.
- 기존 두 비밀번호 방식의 파일과 백업도 일반 비밀번호로 계속 사용할 수 있게 한다. 기존 파일 여부와 관계없이 기관 복구 비밀번호 입력과 `비밀번호를 잊었어요` 기능은 제공하지 않는다.

## 행 추가 입력

- 행 추가창은 명단에 등록된 칼럼 중 직접 입력하는 인적사항·사용자 항목만 제공하고, 현재 표시 이름을 사용한다. 명단에 없는 취학유형·세대주 성명·아동과의 관계 등의 내부 입력칸을 따로 만들지 않는다. 도로명주소와 상세주소는 명단과 같이 별도 칸에 입력한다. 화면에서 잠시 숨긴 등록 칼럼은 입력할 수 있다.
- 가입 식종과 배송 시작일, 식종별 배송 담당을 지정한다. 배송 담당은 등록 기사 또는 미지정을 선택하며 가입하지 않은 식종에는 배정하지 않는다. 담당 배정은 배송 시작일부터 적용하고 새 사람·가입·가구 연결과 하나의 revision으로 저장한다. 배송순서·초기 상태는 추가 후 기존 수정 기능을 사용한다.
- 기존 가구를 직접 고르는 항목은 제공하지 않는다. 저장된 가져오기 가구 묶기 기준을 사용하고, 기준이 없으면 핸드폰을 기준으로 삼아 배송 시작일에 유효한 구성원과 자동 연결한다. 빈 값이나 일치하지 않는 값은 연결하지 않으며, 둘 이상의 가구가 일치하면 임의로 고르거나 새 가구를 만들지 않고 오류를 안내한다.
- 입력이 많아도 최소 창 크기에서 전체 항목에 접근할 수 있게 탭이나 스크롤을 사용하고, 추가·취소 버튼은 항상 보이게 한다.
- 새 사람·자동 가구 연결·식종 가입을 하나의 revision으로 저장한다. 잘못된 값이나 취소로 일부 항목만 저장되지 않게 한다.
- 배송 시작일 입력은 마우스 휠로 값이 바뀌지 않게 하며, 키보드 입력과 달력 선택은 유지한다.

## Excel 명단 가져오기

- 학교 유형·세대주 성명·아동과의 관계를 표준 항목으로 연결하면 명단에도 해당 칼럼을 표시한다. 저장된 가져오기 설정으로 빈 칼럼도 유지하며, 예전에 저장한 값이 있으면 재가져오기 없이 표시한다. 가져온 적도 값도 없는 항목은 추가하지 않는다. 이 칼럼도 검색·셀 수정·행 추가·출력 칼럼 연결에서 같은 저장값을 사용한다.
- 위에서 이미 연결한 열은 추가 항목 목록에서 체크 해제·비활성으로 표시한다. 가져오기 대상이라는 뜻이며 제외된 것이 아님을 안내한다.

- `원본 종류`는 사용자가 선택하지 않는다. 기존 가져오기 설정의 출처 정보는 유지하고 새 파일은 자동으로 기록한다.

- 추가 항목에서 체크한 열은 제외한다. 연결하지 않은 열은 기본으로 제외하며, 체크를 해제하면 원래 열 이름의 문자형 추가 항목으로 저장한다. 같은 이름이나 빈 머리글은 원본 열 문자로 구분하고, 같은 사람의 여러 행에 서로 다른 값이 있으면 모두 보존한다. 저장한 가져오기 설정에는 추가 항목 선택도 기억한다.
- 파일 안의 모든 Excel 표를 목록으로 보여주고 가져올 표를 선택한다. 이름이 `명단`인 표를 기본 선택하고, 없으면 목록의 첫 표를 선택한다. 선택 목록에는 표 이름만 표시한다.
- 선택한 표의 머리글과 데이터 범위를 자동으로 사용한다. 시트·헤더 행·데이터 시작 행을 별도로 지정하게 하지 않는다. 합계 행과 표 밖의 셀은 가져오지 않는다.
- Excel 표가 없는 파일은 Excel의 `삽입 → 표`로 명단 범위를 표로 만든 뒤 다시 선택하도록 안내한다.
- 최초 가져오기처럼 목적이 하나뿐이면 `가져오기 목적` 항목을 표시하지 않는다. 기존 명단을 갱신할 때는 일반 명단과 방학 중식 갱신을 구분할 수 있게 한다.
- 적용일은 열 연결 단계에서 선택한다. `가져오기`를 누르면 오류를 검사하고, 오류가 없으면 명단 전체 미리보기나 마지막 확인 없이 저장한다.
- 가져오기를 막는 빨간 오류가 있을 때만 오류 수정 화면을 보여준다. 수정 후에도 전체 명단을 다시 확인하게 하지 않는다. 선택 항목의 빈칸 등 일반 안내는 저장을 막지 않는다.
- 기존 사람·가구와의 연결이 모호하면 선택이 필요한 항목만 보여준다. 자동 연결·신규 등록과 가구 묶기 규칙으로 결정된 행은 마지막 확인 목록에 표시하지 않는다. 해결하지 않은 충돌이나 취소는 명단을 저장하지 않는다.

## 방학 중식 명단 가져오기

- 기존 운영 명단이 있을 때 가져오기 목적에서 `방학 중식 명단 갱신`을 선택할 수 있다. 최초 DB 명단 가져오기와 구분한다.
- 지정한 적용일부터 중식 명단에 있는 사람은 배송, 기존 중식 배송 대상자 중 명단에 없는 사람은 미배송으로 자동 갱신한다. 이후 명단 갱신 때까지 적용한다.
- 누락 대상자를 일일이 확인하게 하지 않는다. 정확히 일치하는 사람은 자동 연결하고 새 사람은 자동 등록한다. 사람 연결이 모호하거나 원본의 필수 행에 오류·제외가 있으면 작업자가 먼저 해결한다.
- 모호한 사람 연결만 필요한 항목으로 보여주며 별도 최종 검토표를 띄우지 않는다. 최종 결과에는 기존 배송 유지·배송 재개·신규·미배송 전환 인원수를 보여준다. 조식·석식과 기존 인적사항·배송 배정은 유지한다.

## 헤더 필터와 조식 설정 정리

- 열별 검색은 엑셀 필터처럼 각 열 제목 옆 버튼으로 통합한다. 헤더 아래 상시 검색행은 표시하지 않는다. 명단 상단 전체 검색창은 별도로 제공하며, 전체 검색과 헤더 필터를 함께 적용한다.
- 헤더 버튼의 팝업에서 검색·값 선택·전체 선택·필터 해제를 제공한다. 적용해야 반영하고 취소하면 이전 조건을 유지한다. 전체 선택 해제는 0행으로 표시한다.
- 열 제목 경계를 더블클릭해 너비를 자동 맞출 때 필터 버튼과 정렬 우선순위 표시 공간을 확보하고, 본문 값이 더 길면 본문에 맞춘다.
- 칼럼 검색어나 값 선택 필터가 적용돼 있으면 검색 영역 아래에 해당 칼럼 이름과 `칼럼 필터 해제`를 보여준다. 한 번에 칼럼 조건을 해제하고 저장하며, 전체 검색어·생일·보관함·조회 날짜 등 다른 조건은 유지한다. 재실행으로 복원된 필터와 전체 선택 해제로 0행이 된 경우도 안내한다.
- 필터가 적용된 열은 버튼에서 구분한다. 열 제목 클릭 정렬과 필터 버튼 동작을 분리하며, 열 이동·크기 변경·가로 스크롤에도 버튼 위치를 유지한다.
- 여러 칼럼을 함께 정렬할 수 있다. 먼저 선택한 칼럼부터 우선순위를 부여하며 각 칼럼은 클릭할 때마다 오름차순·내림차순·해제 순서로 바뀐다. 한 칼럼을 해제해도 다른 정렬은 유지하고, 다시 선택하면 마지막 우선순위로 추가한다. 모든 정렬을 해제하면 원래 명단 순서로 돌아간다. 헤더에 정렬 방향과 우선순위를 표시하고 필터 버튼과 겹치지 않게 한다.
- 별도 `조식 배송 규칙` 설정은 제공하지 않으며, 기존에 저장한 선택도 새 배송 리포트 계산에 적용하지 않는다. 기본 배송 일정과 날짜별 휴무·대체배송 설정을 사용한다. 과거 정책 이력은 삭제하지 않는다.

## 장기 미배송 보관함

- 대상자 테이블을 나누거나 행을 삭제하지 않고 일반 명단과 장기 미배송 보관함을 조회로 구분한다. 보관 여부는 배송·청구 계산이나 이력을 변경하지 않는다.
- 화면에서 선택한 조회 날짜를 기준으로 석식·조식·중식 모두 연속 미배송인 기간을 판단한다. 기준은 기본 365일이며 사용자가 변경할 수 있고 이 컴퓨터의 화면 설정으로 기억한다. 조회일을 포함한 최근 n일을 계산하며 개월 단위를 사용하지 않는다. 조회 날짜를 바꾸면 숨기기와 보관함을 바로 다시 계산한다.
- 1일 기준은 조회일의 세 식종 표시가 모두 `-`인 행을 바로 숨긴다. 중지·미가입 식종과 학교 일정상 중식 업체 제공 대상이 아닌 날은 명단에서 `-`로 표시하므로 숨기기에서는 배송 없음으로 취급한다. 반복 제공 요일·실제 배송요일과 배송 담당자의 지정 여부는 판정에 사용하지 않으며 가져온 다음 날까지 기다리게 하지 않는다.
- 2일 이상은 사용자에게 보이는 식종 변경 이력이 있으면 기간 안에 어느 가입 식종이든 배송 또는 일시중지 상태가 하루라도 있는지 기존 기간 규칙으로 판단한다. 사용자에게 보이는 식종 변경 이력이 전혀 없고 조회일의 세 식종 표시가 모두 `-`이면 기준 일수와 관계없이 보관한다. 일반 Excel 명단 가져오기로 만들어져 화면 이력에서 숨긴 가입·상태 기록도 이 경우에는 보이는 이력으로 간주하지 않는다. 현재 배송 또는 일시중지로 표시되는 식종이 있으면 이 예외를 적용하지 않는다.
- 기본 화면은 보관 대상을 숨긴 일반 명단이다. 상단에 명단 종류·보관 기준·보관 인원을 상시 표시하지 않는다. `더보기 → 장기 미배송 보관함`에서 조회를 전환하고, 보관함을 보는 동안에만 검색창 아래 칼럼 필터 안내 줄에 나타나는 `보관 기준 설정`에서 일수를 변경한다. `칼럼 필터 해제`와 같은 높이로 두고 바로 옆에 일반 명단으로 돌아가는 `나가기`를 둔다. 칼럼 필터가 없어도 보관함에서는 이 줄을 표시하며, 나가기는 검색·필터·조회 날짜·정렬을 유지한다. 보관함에서도 전체 검색·헤더 필터와 이력보기를 사용할 수 있다. 배송 재개나 상태 수정 후 조건을 충족하지 않으면 일반 명단에 자동으로 다시 표시한다.
- 보관 기준 설정 창에서 일수를 바꾸면 일반 명단과 보관함의 표시 대상을 즉시 미리 갱신한다. 저장하면 새 기준을 기억하고, 취소하거나 창을 닫으면 저장된 기준으로 명단을 되돌린다.
- 전체 검색창 옆 `숨긴 행 포함`을 선택하면 검색어 없이도 일반 명단에 장기 미배송 보관 대상까지 함께 표시한다. 해제하면 보관 대상은 다시 숨긴다. 선택 상태는 재실행 후에도 기억하며, 보관함 자체는 계속 보관 대상만 표시한다. 전체 검색·칼럼 필터 등 다른 조회 조건은 유지하고 칼럼 필터의 값 목록에도 표시 대상인 숨긴 행의 값을 포함한다.

## 식종별 배송 기본값

- 공휴일 대체식 제공일 표는 해당 공휴일에 실제 제공 예정인 식종만 입력받는다. 가입 기간과 개인·가구·공통 제공 요일을 적용하며, 원래 제공하지 않는 요일의 식종은 `—`로 표시한다. 조식처럼 제공일과 실제 배송일이 다른 묶음배송은 원래 제공일을 기준으로 포함한다.

- `설정 → 식종별 배송 기본값`에서 석식·조식·중식의 제공 요일과 요일별 실제 배송일을 지정한다. 운영 파일의 공통 설정으로 저장하며, 별도 지정이 없는 기존 대상자와 새 대상자 모두가 상속한다.
- 저장된 공통 설정이 없을 때 석식은 월~목 주 4회 당일 배송을 기본으로 한다. 중식은 월~금 중 학교 일정상 업체 제공 대상일에 제공하고, 조식은 금·토·일분을 금요일에 묶어 배송한다. 명시적으로 저장한 공통·개인·가구 설정은 유지한다.
- 개인·가구의 명시적인 별도 설정은 보존하고, 별도로 지정하지 않은 항목만 공통 기본값을 따른다. 개인 배송 설정의 초기화는 현재 운영 파일의 기본값을 사용한다. 기본값 상속만으로 `별도 설정만`에 포함하지 않는다.
- 저장 후 명단·배송 리포트·식수와 청구 계산이 같은 기본값을 사용한다. 식수는 제공일, 배송 묶음은 실제 배송일을 기준으로 하며 학교 급식 일정과 명시적인 휴무·대체식 규칙을 유지한다.
- 저장은 변경 이력과 기존 자동 백업 흐름을 따른다. 취소·변경 없음은 저장하지 않고, 재실행 후에도 저장값을 유지한다. 기존 이력의 상태를 재구성할 때는 해당 이력의 기본값을 사용한다.

## 개인별 배송 설정과 가구 전체 적용

- 기본 식종은 석식·조식·중식 세 가지를 유지한다. 각 사람의 식종별 제공 요일·배송요일·형태를 각각 지정한다. 기본 적용 범위는 선택한 한 사람이며, `같은 가구 전체에 적용`을 선택한 경우에만 가구원에게 함께 반영한다. 별도 지정 체크 없이 값을 직접 수정하고 기본값과의 차이로 별도 설정을 자동 판정한다. 별도 배송 형태는 `도시락`, `식재료 박스`처럼 직접 입력한다. 형태가 달라도 같은 식종의 급식·청구 기준을 사용한다.
- 별도 요일은 해당 식종의 제공 요일이다. 예를 들어 석식을 월~금으로 지정하면 주말 석식은 제공하지 않고 금요일에 주말분을 묶어 제공하지 않는다. 휴일·대체배송 규칙은 기존 흐름을 따른다.
- 선택 정보의 `정보 수정` 옆 `배송 설정`에서 선택한 사람의 전용 창을 연다. 개인 적용과 가구 전체 적용의 이름·인원을 구분해서 표시한다. 가구에 연결되지 않은 사람도 개인 설정을 수정할 수 있다. 사람 정보 수정창의 배송 설정도 개인 적용이 기본이다.
- 제공 요일과 배송요일은 위아래로 맞춰 배치하고 배송 형태는 바로 입력한다. 식종별 `초기화`와 `전체 초기화`로 기본값을 복원한다. `기본값`·`별도 설정`과 아직 저장하지 않은 변경을 구분한다.
- 기본값과 같아진 항목은 기본값 상속으로 처리한다. 단, 기존 명시적 설정을 열기만 하거나 값을 원래대로 돌린 경우에는 revision을 만들지 않는다. 저장·취소는 기존 revision 및 백업 흐름을 따른다.
- 명단 필터에는 `별도 설정만` 체크 하나를 둔다. 선택하면 개인에게 실제 적용되는 별도 설정이 있는 대상자만 표시하고 배송 설정 상세 열을 보여준다. 해제하면 상세 열을 숨긴다. 같은 가구라도 개인 설정이 다르면 각각 구분한다.


## 선택 정보의 식종 이력과 배송요일

- 오른쪽 선택 정보에는 성명·같은 가구·식종 변경 이력을 표시하고 연락처와 주소는 별도로 반복 표시하지 않는다. 명단의 연락처·주소 열과 정보 수정 기능은 유지한다.
- 한 번 저장한 식종 상태 변경은 상태·적용 기간·사유를 한 항목으로 묶어 표시한다. 선택 정보·개인별 이력 창·Excel 식종 변경 이력에 같은 규칙을 적용하며, 서로 다른 식종이나 상태 기록은 합치지 않는다.
- 선택 정보의 상태 변경은 식종·상태를 첫 줄에 강조하고, 적용 기간·사유·기록 시각을 각각 별도 줄로 표시한다. 새 기록에는 `없음 →`을 붙이지 않으며 자동 생성된 상태·기간 문구를 사유로 반복하지 않는다.
- 개인별 이력의 식종 변경 표는 식종·구분·변경 값·사유를 앞쪽에 둔다. 변경 값은 상태·기간을 줄바꿈하고 행 높이를 맞춘다. 이전 값이 모두 비어 있으면 해당 열을 숨기며, 선택한 기록의 상세 내용도 같은 순서로 표시한다.
- 일반 `Excel 명단 가져오기`로 생성된 변경은 선택 정보·개인별 이력 창과 Excel 변경 이력 시트에 표시하지 않는다. 기존 기록과 새 기록에 동일하게 적용한다. 방학 중식 명단 갱신, 수동 수정, 민원은 표시한다. 가져온 명단과 저장된 revision은 그대로 유지한다.

- 선택 정보의 식종 변경 이력은 식종과 변경 내용을 먼저 보여주고, 적용일·기간과 기록 시각을 별도 줄로 구분한다. 중요한 변경 내용을 한 줄 말줄임이나 툴팁에만 숨기지 않는다.
- 기간은 `2026-10-01 ~ 2026-10-05` 또는 `2026-10-01부터 · 종료일 미지정`처럼 표시한다. 시작일·종료일이 없으면 미지정임을 명시하며 `종료일=;` 같은 내부 키·구분자 표현을 노출하지 않는다. 원본 이력 값은 변경하지 않는다.
- 같은 가구 목록은 불필요하게 빈 공간을 차지하지 않도록 하고, 이력에는 여러 줄을 읽을 수 있는 공간과 스크롤을 제공한다. 제목 옆 `전체 보기`에서 기존 상세 이력 창으로 이동한다.
- 사람 정보 수정창의 식종별 요일 체크 바로 아래에 `배송요일` 줄을 둔다. 식사를 제공하는 요일과 실제 배송하는 요일을 구분하고, 여러 날짜의 식사가 한 배송에 묶이는 관계를 설명한다.
- 조식 기본 제공 요일은 금·토·일이며, 세 날짜의 식사를 금요일에 묶어 배송한다. 묶음배송해도 식수는 원래 제공일별로 계산한다.
- 배송요일 설정도 개인 적용을 기본으로 하는 저장·취소·기본값 복원 흐름을 따른다. 휴무·대체식의 명시적인 날짜별 지정은 유지한다.


## 전체 변경 이력

- `더보기 → 전체 변경 이력`에서 최근에 저장한 변경번호부터 조회한다. 변경번호·사유·변경자로 검색하고, 변경번호를 선택하면 당시 바뀐 대상·식종·항목·내용을 함께 보여준다.
- 전체 이력에는 일반 Excel 명단 가져오기와 운영 설정 변경도 포함한다. 개별 이력의 가져오기 표시 규칙은 유지한다.
- 동일하게 표시되는 변경번호가 있어도 각각의 저장 기록을 구분한다. 이력 조회는 현재 명단·설정·저장 기록을 변경하지 않는다.
- 내보내기 비밀번호 변경은 변경 사실만 표시하고 비밀번호 값은 표·상세 내용·툴팁에 노출하지 않는다.

## 앱 전체 긴 글 표시

- 앱 전체의 표·목록·트리·열 제목·선택 상자 등에서 긴 글을 `…` 또는 `...`로 바꾸지 않는다. 원문을 유지하고 공간이 부족하면 영역 경계에서 그대로 잘려 보이게 한다. 기존 줄바꿈·스크롤·전체 내용 툴팁은 유지할 수 있다.
- 메뉴와 안내 문구에도 불필요한 말줄임표를 붙이지 않는다. 표시 규칙 변경으로 저장 데이터나 복사할 원문을 바꾸지 않는다.


## Excel DB 내보내기 표시

- 가입 식종별 배송담당이 한 사람 안에서 다르면 기존 식종별 `명단`과 한 사람 한 행의 `명단(통합)`을 함께 출력한다. 통합 시트에는 식종별 배송담당과 순서를 별도 열로 두고, 미가입자도 포함한다. 모두 같으면 통합 시트를 중복 생성하지 않는다.
- 표 제목은 각 시트의 첫 행에 두고, 내보내기 기준일·revision UUID·변경번호·시간대·행 형식은 마지막 `내보내기 정보` 시트에 한 번만 기록한다. 명단을 선택하지 않으면 행 형식은 기록하지 않는다.
- 명단 주소는 조회 기준일에 적용되는 도로명주소·상세주소만 출력한다. 변경 이력의 대상 종류와 추가·수정·삭제 작업은 읽기 쉬운 한국어로 표시한다.

## 출력 템플릿 칼럼 연결

- 명단을 가져온 뒤에도 `설정 → 출력 칼럼 연결`에서 출력 연결을 수정할 수 있다. 원본 Excel을 다시 가져오게 하지 않는다.
- 양식(급식·행복도시락)과 문서(청구서·확인서)를 선택하고 `템플릿 칼럼`에 넣을 `명단 항목`을 지정한다. 지원하는 표준 항목·사용자 항목을 실제 이름으로 보여준다.
- `명단 항목`은 현재 명단 칼럼의 표시 이름을 사용한다. 학교·주소·전화번호1·핸드폰1과 사용자가 바꾼 칼럼 이름을 반영하되 저장된 연결은 표시 이름과 독립된 항목 키로 유지한다. 같은 뜻의 이전 명칭은 선택 목록에 중복 나열하지 않는다. 기본 항목과 추가 항목의 이름이 같으면 구분 문구를 붙이고, 추가 항목 값이 기본 항목의 출력값을 덮어쓰지 않게 한다.
- 새로 연결할 항목은 명단에 등록된 칼럼 중 문서 출력이 지원하는 칼럼만 보여준다. 명단에 없는 항목을 가리키는 기본값·저장값은 `비움`으로 표시하고 저장 시 빈 연결로 반영한다. `기존 연결`이나 사용할 수 없는 항목을 선택지에 남기지 않는다. 초기화도 없는 항목은 `비움`으로 처리하며 취소는 저장하지 않는다. 왼쪽의 템플릿 칼럼 이름과 확인서 가구 묶음 처리는 변경하지 않는다.
- 식수·청구금액·연번처럼 자동으로 생성하는 칼럼은 자동 계산임을 명시하고 임의의 명단 항목으로 바꾸지 못하게 한다. 확인서의 주소·관할동은 가구 묶음 기준으로 구분하여 수정 제한 이유를 표시한다.
- 별도 지정 체크 없이 기본 연결과의 차이를 판정한다. 현재 양식·문서의 초기화와 저장·취소를 제공하며, 양식 전환 때 저장하지 않은 변경을 조용히 버리지 않는다.
- 저장한 연결은 이후 새로 생성하는 문서에 적용한다. 기존 명단 값과 이미 만든 Excel은 변경하지 않는다. 연결 설정도 revision·자동 백업으로 보존하며 변경 없음과 취소는 기록을 만들지 않는다.
- 청구서의 `아동과의 관계`는 명단 항목을 직접 연결할 수 있게 한다. `계`는 식수 합계를 자동 계산하고, `제공기관`은 공통 제공기관 설정을 자동 사용하며 둘 다 연결을 수정할 수 없게 한다.

## 설정 화면 배치와 날짜 입력

- 설정 첫 화면의 모든 항목은 같은 너비의 반폭 카드로 두 열에 배치한다. 관련 항목은 용도별 제목 아래 모으고, 마지막 항목이 홀수여도 한 줄 전체로 늘리지 않는다. 작은 창에서도 스크롤로 모든 항목과 닫기 버튼에 접근할 수 있게 한다.
- 앱 전체 날짜·날짜와 시간 입력은 포커스 여부와 관계없이 마우스 휠로 값이 바뀌지 않게 한다. 키보드 입력과 달력에서 날짜를 선택하는 동작은 유지한다.

## 명단 화면 설정 기억

- 명단의 열 너비와 순서·표시 여부는 이 컴퓨터의 화면 설정으로 기억한다. `별도 설정만`을 켰을 때 나타나는 배송 설정 열의 너비도 다시 켰을 때 복원한다.
- 표준 칼럼은 필수 항목을 포함해 헤더 우클릭에서 화면 표시 이름을 바꿀 수 있다. 이름 변경은 이 컴퓨터의 현재 운영 파일에만 적용하며 내부 칼럼 키와 명단 데이터는 바꾸지 않는다. 빈 이름과 변경 없음·취소는 저장하지 않는다.
- 칼럼 표시 여부는 각 헤더의 우클릭 `숨기기`와 `숨기기 해제`에서 바꾼다. 성명을 포함해 모든 칼럼을 숨길 수 있으며, 모두 숨긴 상태에서도 `더보기 → 칼럼 설정 → 숨기기 해제`로 복구할 수 있다. 숨긴 칼럼 목록에는 사용자가 바꾼 표시 이름을 쓴다.
- 전체 검색어, `숨긴 행 포함`, `별도 설정만`, 헤더의 열별 검색어와 선택한 값은 창을 닫고 다시 열어도 복원한다. 헤더에서 전체 선택 해제한 상태는 빈 선택으로 유지하고, 필터 해제는 저장된 조건도 지운다.
- 검색 조건은 운영 파일별로 구분하고, 현재 명단에 없는 열은 적용하지 않는다. 저장된 선택 값이 현재 명단에 없더라도 해당 선택을 유지한다.

## 명단 시트

- 시트 추가 `+` 버튼은 마지막 시트 바로 옆에 둔다. 시트를 삭제하거나 이름을 바꿔도 빈 탭 너비가 남지 않게 하며, 시트가 많으면 탭 스크롤과 추가 버튼에 계속 접근할 수 있게 한다.

- 선택한 시트는 짙은 남색 배경·흰 글자·청록색 밑줄로 표시한다. 나머지 시트는 밝은 배경으로 구분하고, 선택 전환으로 탭 크기가 바뀌지 않게 한다.

- 명단 아래의 시트는 같은 대상자 데이터를 보여주는 화면 구성이다. 시트를 추가하거나 삭제해도 대상자와 변경 이력은 복제하거나 삭제하지 않는다.
- `+`에서 이름을 정해 시트를 추가하면 기본 열 구성을 표시한다. 시트 탭의 우클릭 메뉴에서 이름 바꾸기·시트 삭제를 제공하며 마지막 시트는 삭제할 수 없다. 추가한 시트의 표시 열은 각 칼럼 헤더의 우클릭 메뉴에서 조정한다.
- 시트별 열 표시 여부·순서·너비와 시트 이름·순서·현재 선택은 운영 파일별 PC 화면 설정으로 기억한다. 새 사용자 항목은 기본 `명단` 시트에 표시하고 이미 꾸민 다른 시트에는 자동으로 추가하지 않는다. `명단` 시트를 삭제했다면 남은 첫 시트가 새 항목의 기본 표시 대상이 된다.
- 날짜·검색·필터·정렬은 시트 사이에서 공유한다. 시트를 바꾸면 배치 수정에 쓰이던 셀 선택은 지워 숨긴 식종 셀이 수정 대상에 남지 않게 한다.


## 공통 경로 설정과 중복 실행

- 운영 DB·자동 백업·문서 출력 위치는 사용자가 직접 지정하고, 경로 설정만 실행 파일 옆 `data/settings.ini`에 공통으로 저장한다. 기존 DB·백업·출력 파일을 자동 이동하지 않는다. 기존 PC 경로는 INI가 없을 때 한 번만 가져오며 개인별 열·검색·필터 설정은 PC에 유지한다.
- 프로그램 폴더의 실행 잠금은 최초 설정·로그인부터 종료까지 유지한다. 다른 실행 폴더를 사용해도 같은 운영 DB에는 동시에 접근하지 못하게 한다. 사용 중이거나 공유 폴더 연결·권한 문제가 있으면 한국어로 안내하고 진행을 중단한다. 잠금 오류를 비밀번호 오류나 DB 손상으로 안내하지 않는다.
- 운영 위치 변경 후 새 DB도 창과 세션을 닫을 때까지 예약한다. 생성·복원 성공 뒤 경로 설정 저장에 실패하면 생성 파일 보존 여부를 분명히 안내하고 세션을 닫는다. 경로 설정 저장 실패를 완료로 표시하지 않는다.
- 남아 있는 `.lock` 파일은 정상이며 사용자에게 삭제를 요구하지 않는다. 같은 공유 폴더의 모든 사용자가 잠금 기능이 포함된 버전을 사용해야 한다.


## 식종별 순서 필터와 여러 셀 수정

- 명단의 순서 헤더 필터는 식종별 순서 체크 목록으로 조건을 조합한다. 특정 식종만 있는 경우를 위한 별도 선택 상자나 `다른 식종에는 순서 없음` 체크박스를 두지 않는다. 식종 목록은 명단의 식종 정의와 제공된 필터 값에서 구성한다.
- 서로 다른 식종의 조건은 **AND**로 적용한다. 중식 번호만 선택하면 중식 순서가 선택한 번호와 일치하고 석식·조식 순서는 모두 없는 사람을 표시한다. 두 식종의 번호를 선택하면 두 조건을 모두 만족해야 한다. 다른 열의 필터 조건도 함께 적용한다.
- 한 식종에서 선택한 번호들은 허용할 값의 목록이다. `1`과 `2`를 선택하면 해당 식종 순서가 둘 중 하나여야 한다. 식종 전체 체크는 해당 식종의 번호들을 선택하며 `(빈 값)`은 별도로 선택한다.
- `(빈 값)`은 해당 식종에 순서가 없다는 뜻이다. 번호와 함께 체크하면 그 번호이거나 순서가 없는 경우를 허용한다. 아무 값도 선택하지 않은 식종도 순서 없음 조건으로 적용한다. 미가입 식종이라도 명시적으로 남은 순서가 있으면 빈 값으로 보지 않는다.
- 모든 식종을 선택 해제하면 순서가 전부 없는 사람만 표시한다. 공통 순서가 남은 사람은 제외한다. `필터 해제`는 순서 유무를 제한하지 않고 전체를 표시한다. 현재 표시된 값을 모두 체크한 상태를 필터 해제로 바꾸지 않는다.
- 기존에 저장한 식종별 번호·순서 유무 조건에도 같은 AND 규칙을 적용한다. 검색·적용·취소를 제공하고, 현재 없는 저장 값도 유지한다. 이전 버전의 합쳐진 순서 문자열은 `이전 필터 (행 전체 일치)`로 구분해 정확히 일치하는 행만 허용한다.
- `001`과 `1`은 서로 다른 값이다. 순서는 숫자 기준으로 나열하되 원문을 유지한다. 목록을 접고 펼치는 동작만으로 선택을 바꾸지 않는다.
- Ctrl을 누르고 서로 다른 사람·가구의 식종 셀을 선택한 뒤 선택한 셀을 우클릭하면 메뉴의 배송·일시중지·중지가 선택한 식종 전체에 적용된다. 선택하지 않은 셀을 우클릭하면 그 셀만 대상으로 바뀐다. 가구 전체 적용은 별도 선택한 경우에만 실행한다.
- Ctrl로 여러 사람의 식종 셀을 선택한 뒤 우클릭해 `배송담당 변경`을 선택하면 등록 기사 한 명 또는 미지정을 고른 적용일부터 선택한 셀에만 반영한다. 주소·배송순서·선택하지 않은 셀과 적용일 뒤의 예약은 유지하며, 하나의 revision과 자동 백업으로 저장한다. 변경 없음과 취소는 저장하지 않는다.
- 기사별 가구의 배송순서를 더블클릭하면 그 셀에서 순서 하나를 입력한다. 별도 수정창을 띄우지 않고 해당 표시 행의 실제 가구원·식종 모두에 같은 값을 적용한다. 합친 행에서도 식종별 가구원 범위를 유지하며, 분리한 행은 그 식종만 수정한다. 기존 순서가 여러 개이거나 순서가 없는 가구원이 섞여 있으면 빈 입력칸에 새 순서를 입력하도록 안내한다.
- 기사별 가구의 순서 입력은 Enter로 저장하고 Esc·다른 곳 클릭·포커스 이동으로 취소한다. 표 아래에 조작 안내와 저장 결과·오류를 표시한다. 취소·잘못된 값·저장 실패는 기존 표시를 유지하고, 변경 없음은 기록을 만들지 않는다. 저장은 하나의 revision과 기존 자동 백업 흐름을 사용하고 기사 배정은 유지한다. 자동 백업만 실패하면 저장 완료와 백업 실패를 함께 표시하고 저장된 순서를 유지한다.
- 기사별 가구 위쪽의 기사 선택 상자와 전체 검색창은 제공하지 않는다. 메인 화면에서 열면 전체 기사를 보여준다. 검색·값 선택은 각 열 제목의 필터로 한다.
- 기사별 가구는 기본으로 선택일의 명단 현재 상태가 `배송` 또는 `일시중지`인 식종만 표시한다. 중지·미가입·학교 일정이 없어 현재 상태가 없는 중식 등은 제외한다. 가입되어 정상 배송으로 판단되는 식종은 별도 상태 변경 이력이 없어도 포함하며, 반복 제공 요일과 실제 배송요일은 적용하지 않는다. 문서·배송·청구 계산의 실제 제공일 판단은 유지한다.
- 기사별 가구의 `숨긴 명단 포함`은 기본 해제 상태이며 장기 미배송 보관 대상자와 위에서 제외한 식종을 숨긴다. 선택하면 선택일에 가입했거나 식종별 배정이 있는 모든 식종과 보관 대상자를 함께 표시한다. 미래에 적용할 배정은 해당 적용일부터 반영하고 공통 배정만으로 미가입 식종을 만들지 않는다. 제외는 가구를 묶기 전에 사람·식종별로 적용해 숨긴 대상의 연락처·순서와 일괄 순서 수정 대상이 섞이지 않게 한다. 전환과 순서 저장 후에도 식종 분리·열 필터·정렬 상태를 유지한다.
- 저장 후 열린 기사별 가구와 명단을 함께 갱신하고 처음 연 기사 범위·열 필터·정렬·식종 분리 상태를 유지한다. 저장한 순서가 필터와 일치하지 않으면 그 행은 정상적으로 숨겨질 수 있다.

## 배송순서 입력 방식

- `설정 → 배송순서 입력 방식`은 청구서·확인서 양식과 독립된 운영 파일 설정이다. 기본값은 `식종별로 따로 입력`이며 설정을 바꾸는 것만으로 기존 배송순서를 다시 쓰지 않는다.
- `한 번 입력해 모든 식종에 적용`에서는 배송순서 수정창에 입력칸 하나를 둔다. 사용자가 새 값을 입력하고 저장한 경우에만 석식·조식·중식 순서를 한 revision으로 같은 값으로 저장하며 기존 배송담당은 유지한다.
- 통합 입력에서 현재 식종별 순서가 서로 다르면 식종 이름과 현재 값을 각각 보여주고 입력칸은 비워 둔다. 값을 입력하지 않은 채 저장하거나 취소하면 기존 식종별 값을 유지하고 revision을 만들지 않는다. 식종별 값이 같으면 현재 값을 한 번만 표시한다.
- `001` 같은 앞자리 0은 통합 입력에서도 그대로 보존한다. 기사별 가구의 표 안 순서 수정은 표시 행이 가리키는 기존 식종·가구원 범위에만 적용하며, 통합 입력 설정을 이유로 선택하지 않은 식종까지 자동 확장하지 않는다.

## 현재 명단 시트 Excel 내보내기

- `더보기 → 현재 시트 Excel 내보내기`는 선택한 명단 시트에서 화면에 보이는 칼럼만 사용한다. 사용자가 바꾼 칼럼 이름과 화면의 칼럼 순서, 검색·필터·정렬 결과의 행 순서, 셀에 표시된 문자열을 그대로 한 시트에 저장한다.
- `001` 같은 앞자리 0, 여러 줄 표시, `=`·`+`·`-`·`@`로 시작하는 값은 계산식이나 숫자로 바꾸지 않고 문자 그대로 보존한다. 행이 0개면 머리글만 저장할 수 있으며 표시 칼럼이 0개면 내보낼 수 없다고 안내한다.
- 현재 시트 내보내기도 설정된 생성 Excel 공통 비밀번호를 반드시 적용하고, 전체 DB Excel 내보내기의 덮어쓰기 확인과 원자적 파일 저장 규칙을 따른다. `DB 전체 Excel로 내보내기`의 전체 명단·민원·변경 이력 출력은 별도 기능으로 유지한다.

## 기사별 가구 Excel 내보내기

- 기사별 가구의 `Excel 내보내기`는 현재 화면에 표시된 칼럼과 행을 화면 순서 그대로 저장한다. 숨긴 명단 포함, 칼럼별 검색·값 선택, 정렬, 식종별 분리 상태를 반영하며 결과가 0행이면 머리글만 저장한다.
- 셀의 줄바꿈과 `001` 같은 앞자리 0, `=`·`+`·`-`·`@`로 시작하는 값은 문자 그대로 보존한다. 현재 명단 시트 내보내기와 같은 생성 Excel 공통 비밀번호, 덮어쓰기 확인, 원자적 파일 저장 규칙을 사용한다.
- `기사·식종별 Excel 내보내기`는 한 통합 문서 안에 `기사-식종`별 시트를 만들고 각 시트의 행을 배송순서 숫자 기준으로 정렬한다. 식종별 실제 가구원·연락처·배송순서를 사용하며 빈 순서는 뒤에 둔다.
- 기사·식종별 내보내기는 `숨긴 명단 포함`만 원본 범위에 반영한다. 기본으로 배송·일시중지 식종만 내보내며 중지·현재 상태 없는 식종은 체크한 경우에만 포함한다. 대상 행이 없는 기사·식종 시트는 만들지 않는다. 열 제목의 검색·값 선택, 화면 정렬, 식종별 분리 상태는 반영하지 않으며 기존 `Excel 내보내기`의 현재 화면 저장 동작은 유지한다.

## 가구 공용 칼럼

- 칼럼 제목 우클릭 또는 `더보기 → 가구 공용 설정`에서 항목별 공용 여부를 직접 켜고 끈다. 칼럼의 가구 공용 여부는 사용자가 직접 설정하며 기본값은 모두 해제다. 기본 항목과 사용자 추가 항목을 구분해 제한하지 않는다. 이 설정은 PC별 화면 설정이 아니라 운영 파일에 저장한다.
- 공용을 켤 때 같은 가구의 값이 모두 같으면 검토창 없이 설정만 저장한다. 일부 가구에 서로 다른 값이 있으면 그 가구만 검토창에 표시하며, 값이 같은 가구의 값과 날짜별 이력은 다시 쓰지 않는다. 검토창에서는 가구원별 현재 값을 확인하고 공용 값을 직접 입력·수정한다. 입력칸은 일반적인 복사·붙여넣기와 여러 줄 메모 입력을 지원한다. 값이 서로 다르면 임의로 하나를 고르거나 합치지 않고 사용자가 공용 값을 정하게 한다. 빈 값으로 지우는 조작도 명시적으로 지원한다.
- 공용 칼럼은 표시에서 구분하며 내부 칼럼 키와 사용자가 정한 이름은 유지한다. 도로명주소·상세주소의 공용 설정 묶음과 배송순서처럼 여러 값을 함께 설정하는 경우에는 구성 항목을 구분해 입력한다.
- 저장한 공용 값과 이후의 공용 칼럼 수정은 적용일의 같은 가구 전체에 반영한다. 검색·필터로 화면에서 숨긴 가구원도 포함하며 다른 가구와 공용으로 지정하지 않은 값은 변경하지 않는다.
- 공용 해제는 현재 가구원별 값을 유지하고 이후 수정부터 개별 적용한다. 취소·검증 실패는 기존 값과 설정을 유지한다. 설정과 값의 변경은 한 번의 저장과 변경 이력·자동 백업으로 처리한다.
- 한 번에 입력한 같은 가구의 공용 값이 서로 충돌하면 저장하지 않고 공용 설정에서 값을 결정하도록 안내한다. 식종 공용 변경 시 미가입 가구원 때문에 상태를 함께 적용할 수 없는 경우에도 가입 상태를 임의로 바꾸지 않고 설정에서 먼저 결정하게 한다.
- 검토 표는 편집이 비활성화된 상태에서도 휠·스크롤바로 이동할 수 있다. 긴 메모가 한 화면보다 길어도 가로·세로를 픽셀 단위로 이동해 중간과 끝 내용을 읽을 수 있게 한다.
